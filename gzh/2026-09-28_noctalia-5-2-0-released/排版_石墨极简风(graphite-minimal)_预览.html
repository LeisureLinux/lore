Noctalia 5.2.0 以「交互与日程」为主轴：重做窗口切换器、新增面板启动器与日历事件提醒。

—— Noctalia 官方 v5.2.0 Release / Changelog（2026-09-27）

Noctalia 5.2.0 是这款 Wayland 桌面壳的新版本，主轴是「交互与日程」：重做的窗口切换器（动画预览轮播 + 过滤）、面板启动器、Umbriel 概览 type-to-launch、可配置锁屏过渡、日历事件提醒（iCal/CalDAV/Google）、插件 UI 提示与主题角色取色，并新增日语支持。

01

FEATURES

新功能

窗口切换器（重做）

带动画预览轮播的全新窗口切换器，含紧凑布局，以及按当前输出或工作区过滤。

启动与概览

面板启动器 provider：直接打开内置与插件面板，包括 Control Center 各标签页；Umbriel 概览支持 type-to-launch（键入即启动）。锁屏支持可配置过渡。

日历 / 提醒（本版重点）

支持 iCalendar/CalDAV 报警与 Google Calendar 的事件提醒：可配置提前量、全天摘要、持久历史、实时倒计时、会议链接操作；可直接打开事件描述中的 Teams 会议链接。

插件

为 box/row/column/image 提供插件 UI 提示；插件可按颜色角色查主题色；设置里搜索已安装插件；监视器覆盖对话框；可默认展开所有设置分组。

本地化：新增日语支持。

02

FIXES

值得注意的修复

·

Secret Service / 加密存储：默认 keyring 启动时锁定、之后才解锁时能正确恢复。

·

音频：PipeWire 重启后重连、干净处理失效对象、无路由虚拟源正确静音。

·

托盘：对「检测到 watcher 才创建图标」的应用更早声明 watcher。

·

任务栏/停靠：无标题窗口、固定应用、运行时身份与 desktop 条目不一致的应用匹配更可靠。

·

Wi-Fi：使用 OWE 的开放增强网络不再误弹密码。

·

Sway / Hyprland：Sway 聚焦与 scratchpad 过滤正常；Hyprland 工作区 IPC 用稳定身份。

·

日历时长：libical 4 下日/周时长保持正确。

·

主题重载：Firefox 与 Ghostty 在 Nix / wrapper 环境下可靠重载。

READ

解读

1. 从「能跑」到「好用」

窗口切换器重做 + 面板启动器 + type-to-launch，都是高频操作路径升级；对一个纯 C++、零 Qt/GTK 的 Wayland 壳，这些正是它相对 GNOME/KDE 的短板。

2. 日历提醒是「生产力向」补齐

iCal/CalDAV/Google 事件提醒 + 全天摘要 + 倒计时 + Teams 链接，把桌面壳从「好看的状态栏」推向「能替代一部分 PIM 客户端」。

3. 插件生态横向铺开

UI tooltip、按颜色角色取主题色、可搜索插件、监视器覆盖对话框——都是给插件作者的「地基」，决定生态能长多大。

4. 修复清单透出成熟度

PipeWire 重启重连、托盘时序、无标题窗口匹配、OWE 误弹密码、libical 4 兼容、Nix/Ghostty 主题重载——多显示器/多合成器/多包管理下才暴露的边角，能持续收敛说明进入稳定打磨期。

版本节奏：5.1.0（09-20）→ 5.2.0（09-27）仅一周，功能密度不低，属快速迭代期；升级前留意 5.x 的破坏性变更。
