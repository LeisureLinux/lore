01

THE 16

译文：16 款工具（按字母序）

Collibra：AI Command Center 合一治理/隐私/agent 管理，给每个 agent 打「信任分」，接 Snowflake/Databricks。→ 大企业的数据质量。

Confident Security：OpenPCC 隐私云（开源内核+商业 SaaS），多层加密让推理在安全/匿名环境跑、通过测试才放行，按 token 计费。→ 医疗/金融。

Credo AI：集中式 agent/LLM 目录 + GAIA，覆盖模型→agent→应用→网络多层；内置 EU AI Act/SOC2/ISO-42001/GDPR 策略包。→ 跨国大企业。

F5 + CalypsoAI：收购补自动化红队，在推理层包裹 LLM、跟踪数据流、探测已知/未知弱点。→ 高流量公网应用。

Fiddler AI：AI 控制面，聚合 100+ 指标盯幻觉/毒性/PII 泄露/漂移，执行策略防越狱与提示注入；有免费档。→ 一堆预测型 ML 模型。

Guardrails AI：Snowglobe 合成数据模拟 + Guardrails OSS 校验器，套在任何 LLM 外挡 PII/越狱、修坏 JSON。→ 输出需固定格式的结构化应用。

Hidden Layer：从盘点最难找的深层模型入手，攻击模拟+自动化红队；AI BoM 直接挖权重与元数据。→ 保护自有模型。

IBM watsonx.governance：治理图谱跟踪所有模型风险，覆盖开发到部署，有 30 天试用。→ 多云合规大企业。

Lakera：守在用户与 LLM 间挡越狱/提示注入、做细粒度访问控制；赞助安全游戏 Gandalf，有社区免费档。→ 实时低延迟场景。

Lasso Security：先扫代码仓/CI 做全量 AI 资产普查，再据此红队与运行时强制。→ 鼓励实验的开放环境。

LogicGate：无代码 Risk Cloud，图数据库评全企业服务（含 LLM 放大风险），蒙特卡洛模拟估潜在风险值。→ AI+传统代码全栈治理。

Mindgard：定位「自动化红队」，持续发现→侦察→攻击→防御复评循环找风险。→ 高节奏警惕的安全研究者。

OneTrust：Continuous Governance 做全栈编目/监控/过滤，AI 只是其中一部分。→ 受监管大型跨国企业。

Prompt Security：LLM 前代理网关，深度审查进出数据流（LLM 无关，只看 IO），检 PII 泄露；有开源工具。→ 能撬开源的团队。

Protect AI：Guardian(CI/CD 扫描)/Recon(自动化红队)/Layer(融入通用网安) + LLM Security、ModelScan 开源。→ 复杂流水线/工作流。

Securiti.ai：把数据库共享规则也套到同平台 LLM（称 DSPM），用情境敏感防火墙/数据最小化/数据流治理控行为。→ 复杂自定义数据治理企业。

02

FOUR BUCKETS

解读：其实只回答两个问题

1. 横向分四类，对应四类痛点

·

资产盘点 / 可见性：Collibra、Lasso、Hidden Layer、Securiti、OneTrust、LogicGate——先搞清楚「我到底跑了多少个 AI」

·

运行时护栏 / IO 过滤：Lakera、Prompt Security、Guardrails AI、Fiddler——拦越狱、提示注入、PII 泄露

·

红队 / 对抗测试：CalypsoAI/F5、Mindgard、Protect AI、Hidden Layer——主动找弱点

·

合规与全生命周期治理：Credo AI、IBM、Confident、OneTrust——对齐 EU AI Act/SOC2/ISO-42001

选型第一个问题不是「用哪家」，而是你缺的是哪一格。多数团队最缺第①格——连自己生产里有几个 LLM agent 都数不清，后面全白搭。

03

LLM-ON-LLM

解读：一个绕不开的讽刺

原文点到位：这些工具不少「自己肚子里也藏着 LLM」。这既是能力来源（语义理解、生成攻击样本），也是新风险面——你的护栏本身是个模型，也会幻觉、误判。

别把它们当「可信黑盒」：护栏输出要可审计、策略要可解释，关键强制点最好留确定性的规则兜底（如 Guardrails AI 的 validator、Prompt Security 的内容检查），而不是全交给另一个模型拍板。
