硬件是你的、文件是你的、网络是你的，但鉴权在他那里。

—— 自托管服务的「中心化鉴权」问题

Plex 把远程串流的付费门槛扩展到了第三方客户端。据 Infuse 开发团队 Firecore 公告，他们收到 Plex 通知：「从本周晚些时候开始，所有 Plex 用户都需要 Remote Watch Pass 或 Plex Pass，才能从远程个人媒体服务器播放——包括使用 Infuse 这类第三方应用的用户。」 至此，「自己的服务器、自己的电影」在家庭网络之外播放，已无免费路径。本地网络内播放仍完全免费。

01

ROLLOUT

这不是突然袭击，是收网的最后一环

很多报道把这条新闻写成「Plex 又涨价了」，但准确地说，这是一条持续了 18 个月的收紧路线的终点。

·

2025-03-19：Plex Pass 从 4.99 涨到 6.99 美元/月；同时宣布远程播放不再免费，推出新的 Remote Watch Pass

·

2025-04-29：新规生效，移动端 App 首先需要订阅才能远程播放

·

2025-11：推进到 Roku 平台

·

2026-03-23：推进到智能电视与游戏主机（三星、LG、Vizio、PlayStation、Xbox 等）

·

2026-09 下旬：推进到第三方客户端（Infuse 等使用 Plex API 的应用）

·

2026 年底（预期）：覆盖所有电视平台

Plex 员工在 2025 年 11 月的论坛帖中已经预告了这个方向：「这项远程串流的规则变更，将扩展到所有其他 Plex TV 应用，以及任何使用 API 提供远程串流的第三方客户端。」所以 2026 年 9 月这一步，不是新政策，而是既有政策的补漏。

02

PRICE

新规之下：三选一，以及价格

要从 Plex Media Server 远程播放视频，以下任一条成立即可（不需要同时买两个）：

·

服务器管理员的账号有活跃的 Plex Pass —— 此时该服务器上的所有用户都能免费远程串流（一次付费、全家受益）

·

你自己的账号有活跃的 Plex Pass

·

你自己的账号有活跃的 Remote Watch Pass

价格对照

·

Plex Pass：6.99 美元/月；69.99 美元/年；249.99 美元终身。含远程串流 + 硬件转码、跳过片头/片尾、离线下载、家长控制等全套

·

Remote Watch Pass：1.99 美元/月；19.99 美元/年（无终身选项）。只有远程串流，不含其他 Plex Pass 权益

不受影响的部分

·

本地网络内播放：完全免费，不需要任何订阅。事实上 Plex 还取消了移动端的一次性激活费，所以「只在家里看」的用户比以前更省

·

音乐与照片：远程播放限制只针对电影/电视/视频。Plexamp（音乐）与 Plex Photos（照片）的串流不受限制

这里有个值得注意的反差：同一个远程访问动作，串流音乐免费、串流视频要钱。Plex 的理由是视频的带宽与转码开销远大于音频——技术上站得住，但用户是否买账是另一回事。

第三方客户端为什么被拉进来

在此之前，付费校验是构建在官方 Plex App 里的。第三方播放器（如 Apple 生态里口碑很好的 Infuse）走的是 Plex 的公开 API，自己实现播放逻辑——它们绕过了官方 App 里的那道校验。

关键在于补漏的方式：Plex 没有封杀第三方客户端，而是把校验从客户端挪到了服务端——由 Plex 的中心服务器在会话握手时判断「这个请求是不是来自家庭网络外」，并据此要求订阅。校验点不再在你可控的应用里，而在你必须连的 Plex 云服务上。

03

WORKAROUND

不想付费的话：三条现实路径

路径 1：Mesh VPN（Tailscale）—— 最省事

思路是让手机以为自己在家里。在服务器和你的设备上都安装 Tailscale、登录同一账号，两者就被放进同一个私有虚拟网络（设备会拿到 100.x.x.x 的固定地址）。此后 Plex 看到的连接被判定为本地，限制自然不适用。

·

优点：安装即用，官方包覆盖 Windows / macOS / Linux / Synology / TrueNAS；地址固定，适合做媒体服务器；流量走你自己的加密隧道

·

代价：每个要看的人都得装。给远方的父母或朋友分享库的场景，这条路很难走通

·

额外好处：可以继续用官方 Plex App（保住 Discover、Watchlist 等功能），只是把网络层修好

路径 2：Docker + 反向代理（Caddy）—— 门槛最高、体验最好

在 Docker 里跑 Plex，让流量经过 Caddy 这类反向代理。Caddy 会自动处理 TLS 证书，亲友访问时不需要装任何 VPN App。

·

优点：对最终用户零感知，体验和以前一样

·

代价：配置复杂；可能把服务器意外暴露到公网；后续每次网络变化或组件更新都要维护

路径 3：换客户端，或换平台

·

换客户端：Remote Watch Pass 是构建在 Plex 软件里的限制，不是协议层面的限制。不使用官方 App、改用不强制付费校验的开源客户端（社区常提到 Plezy），可直接连库播放，顺带还能免费拿到离线下载、跳过片头片尾等 Plex Pass 功能。但这等于再次利用同一个 API 缺口——而 Plex 已经证明它有能力在服务端补齐，所以这条路的长期稳定性存疑

·

换平台：Jellyfin 是最常被提起的去向——免费、开源、无订阅，硬件转码等 Plex 要收费的功能也包含在内。代价是远程访问要自己搭：没有 Plex 那套「帮你搞定网络」的中心服务，需要用反向代理或 Tailscale 自行配置

关键事实速查

KEY FACTS

Plex 关掉的不是「一个免费功能」，而是自托管用户以为自己拥有的控制权。校验点从客户端挪到服务端之后，硬件是你的、文件是你的、网络是你的，但「谁能远程播放」由 Plex 单方面决定。这件事真正的教训是：只要服务的可用性依赖第三方的鉴权服务器，你就交出了一部分控制权——这也正是 Jellyfin 在这轮事件里被反复提及的原因。
