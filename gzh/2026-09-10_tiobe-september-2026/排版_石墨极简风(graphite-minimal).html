02

PYTHON AND C

Python 跌破 18%，C 也在走弱

Python 9 月为 17.76% ，延续了 2026 年大部分时间里评分的逐步下滑。C 同样失守，降至 10.28%。尽管前两名都在走低，Python 仍握有可观的领先优势，短期内第一的位置无人能撼动。

注意：TIOBE 衡量的是搜索活动，不是代码量或生产使用。这一点在解读「Python 下滑」时至关重要。


03

THIRD PLACE

C++ 拉开了与 Java 的差距

第三名之争这个月看起来没那么胶着了。C++ 小幅升至 8.67%，而 Java 降至 7.54%，两者差距扩大到 1.13 个百分点 。8 月时两者仅差 0.37 个百分点，让排名互换看起来越来越可能。

C# 以 4.22% 位居第五，其后是 JavaScript 的 2.76% 和 Visual Basic 的 2.55%。三者本月评分份额均上升，其中 Visual Basic 增幅最大。


04

RUST

Rust 守住第 10，门槛依然很紧

SQL 以 2.16% 守住第八，R 以 1.69% 位列第九，两者评分都上升但位置未变。Rust 以 1.34% 稳居第 10 ，将其首次进入前十的纪录延长到第三个月。Fortran 紧随其后，以 1.24% 排在第 11，两者之间只差 0.1 个百分点，让最后一个席位对相对微小的变化都保持开放。


05

JULIA VS MATLAB

Julia 逼近前 20，MATLAB 再跌

Julia 以 0.74% 升至第 21，刚好排在第 20 的 COBOL 之后。MATLAB 再跌两位至第 27，延续了上月引发关注的下滑。

「Julia 在数值与科学计算、建模和数据处理领域夺取了 MATLAB 的部分地盘。」——TIOBE CEO Paul Jansen

但 Jansen 也指出，Julia 仍 集中在专业领域 ，尚未作为通用语言获得广泛使用。重返前 20 或许能说明：即使没有更广泛的突破，Julia 在这些技术领域的实力也足以支撑它在指数中占据更强位置。守住这个位置可能是更严峻的考验。


06

TAKEAWAYS

别误读这份榜单

Python 跌破 18% 值得关注，但别误读成「Python 在衰落」。在 AI 时代，Python 的实际使用几乎可以肯定是在增长的——它的搜索热度占比下降，是因为 你不再需要搜索「Python 怎么读 CSV」，因为你直接问模型了 。这是 TIOBE 这类基于搜索的指标在 LLM 时代面临的结构性失真。

Rust 守住第 10 的真正含义是： 前十的门槛正在降低 。Rust 首次进入前十已三个月，但绝对评分只有 1.34%——对比 Python 的 17.76%，差了 13 倍。「进前十」在今天的 TIOBE 里已不是「主流语言」的同义词，而是「长尾头部」的位置。

THE END

趋势可以看，决策不能靠

对信创与国产开发生态，三个观察：Python 在 AI 领域的默认地位短期不会被撼动，国产 AI 工具链的 Python 绑定是安全的长期选择；Fortran 以 1.24% 稳居第 11，说明 科学计算老代码的生命力极强 ，国产工业软件的 Fortran 编译器维护不能忽视；Julia 这类「专业强、生态弱」的语言，应作为技术储备而非主力选型。
