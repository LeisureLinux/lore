Phoronix 这次不比旗舰，反而把三套系统塞进一台 449 美元的入门轻薄本，看它们在 Intel 最入门的 Wildcat Lake 平台上能跑出什么差别。结论很直接：操作系统和发行版调校，在 8GB 内存的机器上每一分都掰得开。

机器是 CHUWI UniBook，出厂自带 Windows 11 Pro，另外装上滚动更新的 CachyOS 与 Ubuntu 26.04 LTS。三套系统都更新到最新、保持默认设置，不额外调优。

3

02

BENCHMARKS

性能数据对比

Phoronix 在这台机器上跑了接近 100 项基准测试，综合排名如下。换算一下：CachyOS 比 Ubuntu 26.04 快了大约 17%。

综合排名 系统 相对表现
第 1 名 CachyOS 比 Windows 11 高约 +6%
第 2 名 Windows 11 Pro 基准线
第 3 名 Ubuntu 26.04 LTS 比 Windows 11 低约 −10%

几个有代表性的分项：

1

视频编码（OpenAPV）：三系统速度基本持平，同一 preset 差异极小；个别 slow / medium preset 上 Ubuntu 略快。

2

7-Zip 压缩：Linux 发行版在压缩项明显占优；Windows 11 在解压上反超。

3

图形相关负载：Windows 11 凭更成熟的图形驱动保持领先——这也是它整体压过 Ubuntu 约 10% 的主要来源。

03

ANALYSIS

怎么解读这个结果

入门硬件上，选哪个系统比选哪颗 U 更敏感。同样的 Core 3 304，换套系统就能差出 17%。对信创、教育、办公这类预算敏感、机器长效服役的场景，发行版调校的回报很实在。

CachyOS 的领先来自为现代 x86 微架构专门调过的编译参数：基于 Arch、滚动更新，跟踪上游内核与工具链更激进，能更早吃到红利。Ubuntu 给 26.04 塞了 Linux 6.14 内核和面向混合架构的调度补丁，但仍没追上 Windows 的图形栈成熟度，这 10% 的落差大头在图形驱动。

对桌面 Linux 用户的现实建议：编码、压缩、开发等 headless 场景，Linux 已能打平甚至占优；若依赖图形密集型应用或外部 GPU 加速，Windows 11 暂时仍是更稳的那一个。Ubuntu 要收窄差距，大概率得等后续内核与 Mesa 驱动迭代。
