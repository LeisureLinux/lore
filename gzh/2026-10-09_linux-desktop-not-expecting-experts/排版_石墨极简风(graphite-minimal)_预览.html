QUOTE

一台电脑应该在你好奇时奖励你，而不是要求你好奇。

—— Scott Donaldson（LinuxLinks）

这篇文章的论证是对的，标题是错的。作者批评 Linux 社区对新用户那种「你搞不定就是你不行」的隐性门槛，这个批评我完全认同，而且他自己举的例子（用了多年 Linux，仍被 4K 分数缩放折腾很久）恰恰证明问题不在用户身上。但标题里的「永远不会成功」在 2026 年已经站不住了：Statcounter 显示全球 Linux 桌面份额已达 8.88%，美国 18.19%。它正在成功的路上，而且推手恰恰是那些「不要求用户是专家」的形态。

01

RIGHT

作者说对了什么

有些 Linux 爱好者似乎会给新用户做一项有点古怪的测试：如果一个人修不好坏掉的包、看不懂终端报错、或者说不清自己在跑哪个图形会话，那么也许 Linux 根本不适合他。**你停下来想想就会觉得，这是一种推广操作系统的方式吗？说实话挺蠢的。**

然后是那个我认为最有说服力的类比：

**大多数人并不想和自己的电脑谈恋爱。** 他们不想在一个下雨的周二晚上研究打印机协议栈的内情。他们想写一封信、整理几张照片、看部电影、发封邮件，然后去过今天剩下的日子。**这也完全正当。** 没有人会骄傲地宣布，他的洗衣机只有在能读懂诊断代码、会改配置文件时才能正常工作。

「没有人会这样宣布他的洗衣机」这句是全文最有力的地方，因为它把「技术门槛」这件事从「能力问题」重新定义成了「产品问题」。

接下来他给了两个很关键的自我限定，这让论证显得诚实而非情绪化。第一，他不主张干掉终端：

我们应该把**能力**和**没必要的复杂**区分开。一个能干的终端是真正的优势，没有哪个明理的人建议我们去掉它。我经常用终端，往往因为它比层层点菜单更快。**但麻烦始于命令行绕行方案变成了修复图形体验粗糙边缘的替代品。**

第二，他不主张把 Linux 变成 Windows 的仿制品：「我不是建议 Linux 应该变成 Windows 的一个苍白仿制品。绝对不会。Windows 有很多东西我宁愿 Linux 离得远远的。但『不一样』不给我们一个免费通行证，去把简单的事情变得没必要地困难。」 然后是他最精准的一句观察：「一台电脑应该在你好奇时奖励你，而不是要求你好奇。你应该可以自由地折腾、试验、弄坏再装回去。那是 Linux 最大的乐趣之一。但你不该仅仅为了打印一份文档就得去捅管道。」

最后那句反问收得也好：「如果 Linux 真的想吸引普通的电脑用户，为什么它仍然期望他们中那么多人像系统管理员一样思考？」

02

DATA

标题错了：2026 年的数据不支持「永远不会成功」

这是我要跟作者分歧的地方，而且分歧在数据上。

·

全球 Linux 桌面份额 8.88%（Statcounter，2026 年 9 月初）；2026 年 7 月 7.53%，6 月 5.59%

·

北美 10.65%；美国 18.19%（8 月初还只是略高于 10%）；日本 7.78%

·

Steam 平台 Linux 占比 3.90%（Valve 8 月调查）

Steam 调查里的 Linux 内部结构更能说明「谁在推动」：SteamOS Holo 占 22.83%（Steam Deck 的系统）、CachyOS 占 14.03%、Bazzite 占 7.28%。CachyOS 甚至登上了 DistroWatch 的 12 个月点击榜第一。 这些都不是「给专家用的发行版」，而是为游戏或开箱即用体验优化的发行版。

顺带说一个我认为最讽刺的事实：Linux 桌面份额这轮明显上涨，最主要的推手是 Valve 和 Steam Deck。而 Steam Deck 恰恰是一个用户根本不需要知道自己在跑哪个图形会话、也不需要修包就能玩游戏的东西。所以在某种意义上，作者是对的，只是结论写反了：Linux 桌面正在成功，而且成功的正是那些「不要求用户是专家」的形态。它还是靠某些人终于把它做成了产品。

当然也要把测量本身的限度说清：Statcounter 的统计中机器人流量占 23.44%（已从主统计剔除），Valve 的调查是自愿参与的。GamingOnLinux 报道时也提醒「按你一贯的尺度打个折扣看」。但方向上全球与区域数据一致。

03

GAP

文章没讨论的角度：谁来为「不需要专家」付钱

作者在文末做了一个我认为很值得肯定的动作：他挂了一个投票，直接问读者「一个普通桌面 Linux 用户应该需要多少终端知识？」四档从「无」到「相当多」。把自己的判断交出去让大家投票，而不是替读者下结论，这是评论文章里少见的克制。

但文章有一个角度没有触及，而我认为它才是问题的核心：谁来为「不需要专家」这件事付钱。

·

Steam Deck 能做到开箱即用，是因为 Valve 有商业动机（卖游戏）养活了一支工程团队

·

RHEL、Ubuntu LTS 的企业桌面版能做得比较稳，是因为有人在为支持付费

·

大量面向消费者的社区发行版，没有人在为「把 4K 分数缩放修好」这种工作付钱。这类问题不性感、费力、又难被表扬

所以作者批评的「社区态度」只是表层。 更根本的是：修复粗糙边缘需要持续的、有报酬的工程投入，而 Linux 桌面长期缺少这种投入的商业模式。这解释了为什么 GNOME 和 KDE 都投入多年打磨，某些边缘场景仍然会咬人。

04

VERDICT

我的判断

第一，作者的批评成立，而且他的论据比他的论点强。 他其实证明了「这不是新手不会用，而是产品有这个缺陷」，只是最后把它写成了对新用户态度的抱怨。

第二，标题的「永远不会成功」在数据面前应该改为「不该用专家门槛来定义自己」。 8.88% 的全球份额、美国 18.19%、Steam 上 SteamOS 占 Linux 内部 22.83%，这些数字说的是一个正在增长的平台。「成功」的定义可以争论，但「永远不会」这种表述已经不成立了。

第三，最值得记住的一条来自作者自己，也最能回答他自己的问题：「一台电脑应该在你好奇时奖励你，而不是要求你好奇。」 这句话恰好解释了 Linux 最近为什么在涨：Steam Deck 的用户不需要好奇就能玩游戏，等他们真的好奇了，桌面就在那里。这条路子是「先把门槛降到零，让好奇心自己长出来」，而不是「先要求门槛，再筛选用户」。

第四，如果要给作者的文章补一句话，我会补这个：问题的解法不在说服社区态度变好，而在让修复粗糙边缘这件事有人付钱。Valve 证明了这条路可行。剩下的问题是，除了游戏，还有谁会为「普通人在 Linux 上顺畅地写一封信、整理照片、看部电影」付费。
