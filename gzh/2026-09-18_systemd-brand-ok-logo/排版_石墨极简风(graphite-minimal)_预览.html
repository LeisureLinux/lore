01

WHAT THE PAGE SAYS

译文：品牌页讲了什么

logo 的来历

systemd 以 PID 1 运行、拉起整个系统。它的视觉身份直接取自传统文本终端启动时的标志性画面——组件逐个成功启动、用绿色 ==[ OK ]== 标注。很多人已把 [ OK ] 和 systemd 划等号，从这儿派生标识顺理成章。方括号里的抽象形状，象征启动画面的「OK」、跑在 systemd 里的各服务，以及团队整体的乐观态度。logo 由 GNOME 的 Tobias Bernard 在 2019 年设计，授权 CC BY-SA 4.0。

logo 的形态

·

全彩横版（首选；没颜色时可用单色版）

·

深色背景版（full color / monochrome 各一套）

·

竖版替代 logo（横版放不下时用）

·

独立 logomark（头像、图标等小尺寸、文字读不清的场景）

配色与字体

品牌色就两个：systemd 绿 ==#30D475==、systemd 黑 #201A26。品牌字体是 Heebo（Oded Ezer 设计），logotype 用 Bold 字重。

拼写执念

写成 systemd，别写 system D / System D / SystemD / system d。原因：它是「系统守护进程 system daemon」，Unix/Linux 下守护进程全小写、后缀小写 d。要是觉得太简单，可管它叫（但别拼出来）System Five Hundred——D 是罗马数字 500，顺便点明它和 System V 的关系。唯一被勉强接受的大写，是拿 systemd 开头写句子。

02

MY TAKE

解读：一个开源项目把自己「品牌化」到什么程度

1. 把启动日志变成 logo，是极少见的诚实设计

大多数项目 logo 是凭空画抽象图形；systemd 直接把用户每天看见、已产生情感认同的画面（绿色 [ OK ]）提炼成标识。你不需要被教育「这是 systemd 的标」，开机几千次早认得了。做内部平台、基础软件的同学可借鉴：你产品的视觉符号，往往藏在用户每天忍着没骂的那块输出里。

2. 配色只有两个、字体只认一款，是可维护性思维外溢到品牌

#30D475 + #201A26 加一套 Heebo，把品牌资产压到极简。这跟 systemd 工程上「少依赖、明确边界」的口味一致：资产少，别人 fork、二次创作、做衍生物料几乎不会跑偏，CC BY-SA 4.0 又给了法律自由。最简的规范，反而是最稳的规范。

3. 那套拼写 rant，本身也是一种品牌运营

专门写一节教你怎么拼 systemd，甚至搬出罗马数字 500 的梗，看似玩笑，实则是用强一致对抗长期侵蚀——社区里 SystemD、system D 天天冒头，官方不较真，搜索、文档、包名就会慢慢分裂。把「怎么写我名字」写进品牌页，是把命名纪律当成身份的一部分。
