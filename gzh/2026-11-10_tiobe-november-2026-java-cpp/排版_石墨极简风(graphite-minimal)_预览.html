二、Java 反超 C++ 这件事，被讲大了

10 月：C++ 领先 Java 0.46 个百分点。11 月：Java 反过来领先 0.54 个百分点。

两次名次交换，加起来不到一个百分点。 而 TechRepublic 的原文也写着：两者在 2026 年频繁交换排位，11 月只是又一次。

更值得看的是 Rust 与 Go：Go 1.69%，Rust 1.63%，差 0.06 点。而且 Rust 的 rating 从 1.44% 涨到 1.63% —— 它涨了，却掉出了前十。Rust 是 7 月首次进前十、待了四个月，11 月离开。TechRepublic 自己也写了：两者只差 0.06 个百分点，下一次反转完全可能。

「涨了却掉名次」这件事，本身就说明这个榜的边界有多脆。 名次是排序后的离散输出，而底层 rating 是连续量；当相邻两名差 0.06 点时，名次的语义几乎为零。

Dart 那一跳也一样：从第 27 位到第 20 位，看着像大事件，实际是 0.74% 附近的一小步。而 Julia 上个月刚重返前 20，这个月已经又掉出去了 —— 官方博客和 TechRepublic 都提到这点，正好说明边界附近的进出有多容易。

三、TIOBE 到底在量什么（这才是该带走的知识）

官方站把定义写得很明确：

官方站把定义写得很明确：TIOBE Programming Community Index 是编程语言流行度的一个指标，每月更新；rating 基于全球熟练工程师、课程、第三方供应商的数量，用 Google、Amazon、Wikipedia、Bing 等 20 多个热门网站的搜索结果数计算。并且明确声明：这个指数不是关于「最好的编程语言」，也不是关于「用哪种语言写的代码行数最多」。

It is important to note that the TIOBE index is not about the best programming language or the language in which most lines of code have been written.

（这一句是全文我唯一想原样保留的英文 —— 因为它是整份榜单最该被读到的免责声明：这个指数既不是关于「最好的语言」，也不是关于「写得最多代码的语言」。）

三个关键词：搜索结果数、可见度、不是采用率。

也就是说：

·

它量的是「在搜索引擎里，提到某语言 + 熟练工程师 / 课程 / 供应商 的页面有多少」；

·

不等于有多少开发者在用、不等于写了多少代码、不等于生产部署规模；

·

它是兴趣与曝光度的代理指标，不是技术采用率。

TechRepublic 在结尾给了一句很克制的建议，我认为比榜单本身更值得引用：

对开发者和 IT 团队来说，这些月度变动更适合当作「兴趣在变」的指标，而不是语言长期相关性的定论。选型时，生态支持、可用人才、项目需求这类因素更重要。

这句话和官方定义是一致的。 把 0.54 点的反超写成「Java 复兴 / C++ 衰落」，是把一个搜索可见度指标误读成了产业趋势。

四、几处值得单独记的背景

① C 同比 +1.80 点，是这份表里最扎实的一个变化。 Jansen 此前把 C 的长青归因于嵌入式系统 —— 那里速度与底层控制仍然值钱。和 0.06 点的名次交换相比，同比 1.80 点才是真正有量级的信号。

② Python 20.86% 仍是第一，但「回升 ≠ 复原」。 报道明确写了：尽管近几个月在涨，它还没回到一年前的水平。第一名的位置没有变，份额的缺口还在。

③ Dart 的上升被归因于 Flutter，不是语言本身。 Jansen 的原话大意：谈 Dart 绕不开 Flutter，它是 Dart 流行度增长的主要驱动力，已成为跨平台移动应用开发的主要技术之一；Dart 语言本身并不特别独特，虽然吸收了不少现代语言特性，成功主要来自 Flutter 生态和「一套代码多平台」的便利。

这条和 Darling 那篇正好互为印证：一个语言的排名可以被一个框架的生态推着走 —— 生态与规模的变化，比技术优劣更能决定一个项目的位置。

④ 官方 Headline 没提 Java 反超 C++，提的是 Dart。 这是个挺有意思的细节：TIOBE 自己认为当月最值得写的是「Dart 首次进前 20」，而媒体标题写的是「Java 反超 C++」。同一个榜单，选哪个变动当 headline，本身就是一次编辑判断。

05

SECTION

五、结论

把月度名次当趋势读，是把搜索可见度指标误当成了技术采用率。

这份榜能告诉你「这个月大家在搜什么、讨论什么」，不能告诉你「该用哪门语言重写系统」。0.54 点的反超、0.06 点的进出、27→20 位的跳跃，都发生在指标自身的噪声量级里。

真要从里面读点什么，我建议读同比而非环比：C 的 +1.80 点、Python 仍未回到一年前、Dart 靠 Flutter 进前 20 —— 这些比「谁第三谁第四」有信息量得多。
