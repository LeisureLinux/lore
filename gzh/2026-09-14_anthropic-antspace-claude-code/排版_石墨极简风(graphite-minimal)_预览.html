01

FIRECRACKER RUNTIME

运行环境：Firecracker 微虚拟机

Claude Code Web 跑在一台 Firecracker 微虚拟机 里，规格相当实在：4 vCPU、16GB 内存、252GB 磁盘、Linux 内核 6.18.5。进程树极简到近乎苛刻—— PID 1 不是 systemd ，而是一个自定义 init 二进制 /process_api ，同时兼任 WebSocket 网关（监听 2024 端口）。没有 sshd、没有 cron、没有 journald，只保留运行所需的最小集。

4 vCPU

16GB 内存

252GB

磁盘 · 内核 6.18.5

核心二进制 /process_api 是一个 3.1MB 的 Rust/tokio 程序，作者用 Ghidra 反编译了它（3599 个函数、44.6 万行 C 伪代码），负责进程生命周期、cgroup 管理、OOM killer、mount/pivot_root 初始化，以及面向会话的 WebSocket 协议。


02

UNSTRIPPED BINARY

没剥离的 Go 二进制，露出完整包结构

容器里核心二进制 /usr/local/bin/environment-runner 是 27MB 的 Go 可执行文件， 未剥离调试符号 ，完整保留了 Anthropic 私有仓库 api-go/environment-manager 的包结构与函数名。

一把 go version -m 梭出全部构建元数据：版本串 staging-68f0dff496 、Go 1.25.7、完整依赖。因为没剥离， objdump -t 直接给全限定函数名，过滤路径就重建出整棵架构树——从会话管理、MCP 配置、Git 代理，到 WebSocket 隧道与部署动作。

THE HIDDEN PaaS

最精彩的部分：两套部署客户端

在 tunnel/actions/deploy/ 包里，作者发现两套部署客户端：已知的 VercelClient ，以及此前从未出现过的 AntspaceClient 。后者实现了一套完整的三阶段部署协议。

版本串前缀是 staging- ，说明还在早期内部阶段，但部署协议已成熟、达到生产级。全网搜「Antspace」——官网、博客、GitHub、招聘页， 零记录 。

连带挖出的 Baku 与 BYOC

同一份二进制还泄露了内部代号 Baku ——claude.ai 网页版应用构建器，用 Vite + React + TypeScript 模板，自动提供 6 个 Supabase MCP 工具（按需建库、迁移管理、Edge Function 部署），默认部署目标正是 Antspace 而非 Vercel。代码里还有企业级 BYOC （自带云）支持：企业可在自有基础设施跑 environment-runner，由 Anthropic API 做会话编排。

SECURITY GUARDRAILS

安全护栏：该有的都有

逆向揭示出的运行时安全护栏相当到位，只是二进制本身没藏住—— 典型的「沙箱设计优秀、产物纪律翻车」 。

SECURITY MEASURES

措施 目的
init_on_free=1 会话间清零释放内存页
丢弃 CAP_SYS_RESOURCE 限制 PID 1 能力
CRNG 重新播种 防快照 fork 后随机可预测
JWT 鉴权 WebSocket 连接校验
Token 擦除 使用后移除配置中的密钥

此外，Firecracker 的 Snapstart 模式也被还原：极简模板 VM 做快照，恢复时热插拔块设备。dmesg 证明模板启动与会话恢复之间存在 48.5 小时 时间差；块设备分配为 vda=ext4 可写 rootfs、vdb/vdc=squashfs 只读层。


05

METHODOLOGY

七步把生产环境逆向了个底朝天

作者把全过程公开成标准 Linux 工具七步法： dmesg 指纹 hypervisor → cat /proc/1/cmdline 识 PID 1 → go version -m 取元数据 → objdump -t 重建包树 → 定向字符串/结构体 tag 提取 → 符号表驱动功能映射 → strace -p 1 看运行期行为 。

「把一个带着完整调试符号、没剥离的二进制发到生产环境，是个……选择。」


06

MY TAKE

解读：这事儿意味着什么

1. 「安全优先」实验室的运维反讽

Anthropic 对外主打安全优先，可整套内部架构以可读明文发到每个用户会话。作者也承认攻击者没拿到任何东西——这些信息本就在用户自己的进程空间可见，不算漏洞。但「把私有仓库路径、内部代号、部署协议完整暴露」是工程纪律上的低级失误。

2. 垂直整合闭环已成雏形

Antspace + Baku + BYOC 拼起来，是从 模型 → 运行时 → 托管 的完整闭环：Claude 写代码，Baku 用 Supabase MCP 拼全栈应用，Antspace 直接托管上线，BYOC 再补「企业想自己跑」的场景。Vercel / Netlify、Replit、Supabase 各自的饭碗，Anthropic 一家全包了。

3. 给 AI 工程与信创的启示

最值得抄作业的是它的 沙箱设计 ：Firecracker 微虚拟机 + 极简 PID 1（Rust/tokio，3.1MB）+ 严格能力裁剪 + 内存清零 + CRNG 重播种 + 快照恢复。对在不可信输入（AI 生成代码、Agent 自动执行）下要保证隔离强度的场景——无论是信创桌面里的 AI 助手沙箱，还是云端 Coding Agent 平台——都是一份现成的生产级参考架构。反过来说，它也是个反面教材：面向用户的二进制，产物分级与符号剥离这种基本功不能省。

一句话收尾：Anthropic 想拥有「应用被说出来的那一刻」起的每一层栈——而一份没剥离的二进制，让他们想藏的那层先被看穿了。
