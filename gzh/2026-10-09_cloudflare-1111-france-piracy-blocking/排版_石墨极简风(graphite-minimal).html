QUOTE

同一套法律框架、同一个法庭、同一个核心事实（都没封自己的 DNS 解析器），但结果可能完全不同。差别只在于一方恰好还经营着一项更容易封锁的业务。

—— Cloudflare 与 Quad9 的处境差别

Canal+ 要求巴黎法院对 Cloudflare 处以 每个站点每天 5 万欧元的罚款，理由是它只通过 CDN 封禁、根本没动 1.1.1.1 公共 DNS。九月十七日，三名法官组成的合议庭驳回了罚款请求，理由是四月那份封禁令本来就「不指定手段、只要求有效」。但这个判决比它看起来窄得多：它确认的是「你有权选择用什么手段」，而不是「DNS 解析器可以豁免封禁义务」。同一个月、同一个法庭，没有任何 CDN 可退守的 Quad9 正面临最高每天 58 万欧元的罚款。

01

CASE

一份不指定手段的封禁令

过去两年，法国法院把封禁义务的对象从 ISP 一路扩展下去：常规 ISP 之外，现在还包括公共 DNS 解析器、VPN 服务、搜索引擎和 CDN 提供商。理由都一样，这些都是能帮用户绕过既有封锁的环节。

2026 年 4 月，巴黎司法法院命令 Cloudflare 封锁 21 个与盗版 F1 直播相关的域名和 16 个 MotoGP 相关域名。 关键细节在这里：命令覆盖了 Cloudflare 的 DNS 解析器和它的 CDN，但没有规定该怎么封锁，只要求「以防止从法国访问」，措辞是「以任何有效手段」。

申请封锁的法国付费电视提供商 Canal+ 认为 Cloudflare 做得不够，于是回到法院，在五月要求追加每日罚款：每个仍然可访问的站点每天 5 万欧元，媒体监管机构 ARCOM 每上报一个新站点，同样金额。

Canal+ 的主张是 Cloudflare 故意不遵守。按判决书的概述：Cloudflare「通过仅在其 CDN 服务上实施该判决来规避措施，这意味着法院列出的 21 个域名中只有三个被封锁」。MotoGP 案类似，是16 个里封了 3 个。两个案子它还都补了一句：被封的三个里有两个一周后重新上线，一个换了 CDN，另一个用了镜像站。

02

RULING

法院为什么判 Cloudflare 赢

九月十七日，三名法官组成的合议庭对两份罚款请求一并裁定。Cloudflare 的答辩有两条：技术约束使得它只能通过 CDN 履行；法院明确让它自行选择使用哪些服务，只要对打击体育盗版有实质性贡献。

法院先确认了事实层面没有争议：「Cloudflare 仅在站点使用其 CDN 服务时，通过该服务实施所命令的措施，这一点没有争议。」

然后关键一步来了。Cloudflare 告诉法院，CDN 封禁比 DNS 封禁有效得多，并补充说其公共 DNS 解析器的架构不允许封锁，因此这类措施是不合理的。法院接受了这个立场。

而这里有一个反直觉的转折：Canal+ 曾主张 Cloudflare 只封锁了法院要求它封锁的域名中的 72.6%。但法院把这个数字视为「有诚意协助制止侵权」的证据。

判决书没有解释这个百分比与 Canal+ 先前所说的「21 个里只封了 3 个」之间是什么关系。 这两个数字差了二十多倍，而判决没有给出任何调和。最可能的解释（这是本文推断，判决书未给出）是分母不同：72.6% 的分母可能是 Cloudflare 实际提供 CDN 服务的域名集合，而 3/21 指的是那 21 个域名里仍能从法国访问的数量。如果法院是在「Cloudflare 已经尽力」这个前提下判它免罚的，那这个前提本身建立在一个未经解释的数字上，而这个数字恰好是 Canal+ 自己提供的。

法院还划了一条责任边界：站点换成另一个 CDN、或者设置跳转到镜像站，不能归咎于 Cloudflare。 那该谁负责？法院说，该由 Canal+ 去要求新的中间商封锁这些站点，并把镜像站上报给 ARCOM。

最后是 Canal+ 援引的欧盟法院先例。它主张按 UPC Telekabel Wien 判决，中间商必须有效封锁。巴黎法院不同意这个读法：在它看来，同一份判决只要求中间商采取「合理措施」，而 Cloudflare 通过 CDN 封禁做到了这一点。

结果：罚款请求被驳回，理由是「既不必要也不相称」。Canal+ 另外要求的 2 万欧元诉讼费用也被驳回。

03

ASYMMETRY

真正的不对称：Quad9 没有 CDN 可以退

这才是这个判决最该被读出来的部分。把 Cloudflare 和 Quad9 并排放：

·

Cloudflare：没封自己的 DNS 解析器，但有 CDN 可封，法院驳回了罚款请求（请求规模 5 万欧元/站点/天）

·

Quad9：也没封自己的 DNS 解析器，但没有其他可封锁的服务，面临最高 58 万欧元/天的罚款，公开拒绝，并表示可能退出法国，结果本月待定

同一套法律框架、同一个法庭、同一个核心事实（都没封自己的 DNS 解析器），但结果可能完全不同。差别只在于一方恰好还经营着一项更容易封锁的业务。

这就是这个先例的真实边界：它不是「DNS 解析器不必封禁」，而是「如果你有一个更有效的替代手段，法院可以接受你用那个替代手段」。对没有第二项业务的纯解析器来说，这个判决提供不了任何保护。

这套封禁体系在法国是怎么一步步铺开的（本文补充）

·

·

2024：扩展到替代 DNS 解析器

·

·

2026 年 7 月 15 日：法国行政法院判决 ARCOM 有权强制 Cloudflare 封锁基于欧盟制裁的俄罗斯媒体地址，并拒绝将 DSA 第 9 条问题提交欧盟法院

·

2026 年 9 月 17 日：本篇判决，驳回 Canal+ 对 Cloudflare 的罚款请求

·

已在进行：Canal+ 称包括 IP 封锁在内的更多措施正在逐步部署，已在罗兰·加洛斯期间做过首次试验

3 月那次上诉判决里法院驳回的几种论证方式值得记下来，因为它们以后还会被反复引用：Cloudflare 和 Cisco 主张服务「中立且被动」，法院说中立性不是重点，重要的是「技术上有能力封锁」，而不是服务的性质；Google 主张 DNS 封锁无效、一个 VPN 就能绕过，法院驳回的理由是任何过滤系统都能被绕过，但这不代表它没用；Cisco 提出成本是 64 人周，也未能说服法官。注意这与 9 月判决不矛盾：9 月裁的是「要不要罚款」，不是「要不要封」。义务没被推翻，被推翻的只是「你必须用 DNS 这个手段」这个隐含要求。

04

TAKEAWAY

对从业者意味着什么

如果你运营 DNS 解析器或任何基础设施服务，这个判决给出的最实际的信息是业务形态决定了你的法律风险敞口：

·

只有一项业务的服务最脆弱。Quad9 的处境说明，一个纯粹的非营利解析器，在同样的事实基础上可能面临致其破产的罚款，而拥有 CDN 的对手可以主张「我用别的手段更有效」并因此免罚。这不是法律原则的差别，是架构的差别

·

「不指定手段」的措辞是你的朋友。Cloudflare 能赢的关键前提是四月那份命令让它自行选择服务。如果命令明确指定「通过你的解析器封锁」，这个先例就不适用

·

行政法院和司法法院是两条线，结论可能相反。七月那份行政法院判决里，Cloudflare 是输的：结论是必须履行。同一家公司，两条轨道，两种结果，不要用这一份判决推断另一条轨道的走向

一个难得的窗口：封锁实际发生在哪一层

Cloudflare 的透明度报告能看出封锁的真实分布：2025 上半年在 CDN 层面于法国地理封锁 662 个域名（7 份命令）；下半年 1,238 个域名（1 份命令）。封锁量集中在一份大规模命令上，而不是分散在很多小案子。同时 Cloudflare 反复声明：「截至目前，Cloudflare 尚未通过 1.1.1.1 公共 DNS 解析器封锁任何内容。」

这句话本身就是这个案子里最有争议的事实：法院判了它封锁 DNS 解析器（命令覆盖了解析器），但公共解析器至今未封，而且这次没被罚款。另外值得留意两点：Canal+ 明确表示可以上诉，这不是终局；以及这套体系正在继续向下一层扩展，从 ISP 到 DNS 到 VPN 到 CDN 再到 IP，这是一条把可执行点逐层填满的路径。

Cloudflare 提的替代方案，恰好和监管方向一致

Cloudflare 在给欧盟委员会「假冒与盗版观察名单」磋商的意见书里说明立场：全球公共 DNS 解析器不应被用来封锁或限制访问。它提出了自己认为更好的做法：实时中断盗版流。经审核的权利人可以标记流经其网络的盗版流，这些流会「在数秒内」被中断，而不需要任何 DNS 或 IP 地址封锁。

这个思路与 DNS 封锁有本质区别：DNS/域名封锁作用于名字、是静态清单、可能误伤共享 IP 或整个 CDN 边缘；实时流中断作用于内容流、是实时检测、针对具体流。有意思的是欧盟自己的研究也指向同一个方向：一项受欧盟委托的研究指出反盗版「不够有效」，目标应该是「30 分钟内实时封锁」。也就是说，监管方和平台方对「更快、更精准」的方向判断是一致的，分歧在于该不该把 DNS 解析器当成执行点。

三条判断。第一，「Cloudflare 赢了」这个框架有误导性：它赢的是一份不指定手段的命令，而不是「DNS 解析器免于封禁义务」这个原则，判决书甚至明确承认命令覆盖了解析器和 CDN，只是没规定用哪个。第二，也是最值得警惕的一点：这个案子的结果取决于被告有没有第二项业务。用一个与合规义务无关的商业事实，去决定一个法律义务的履行方式和后果，这在制度设计上是有问题的。第三，那个 72.6% 值得被追问：法院用 Canal+ 自己提供的统计证明了 Cloudflare 有诚意，而这个统计与它自己另一处「21 个里封了 3 个」的指控之间没有调和，这是可以上诉的实质理由。
