专业图形的跨平台平等，还远没到。

—— 释读 SPECviewperf 15.0.1 for Linux（Phoronix，2026-09-22）

SPEC 在 2025 年 5 月推出 SPECViewPerf 15（业界标准工作站显卡基准），首发只给 Windows。今天 Linux 终于追上：发布 15.0.1 原生构建，同时给 x86_64 与 AArch64。但 Windows 版已支持 DX12 + Vulkan，Linux 版 只给 OpenGL 4.5——跨平台数字不能直比。

解读：补上短板，但仍是二等公民

1. Linux 平等补上了，但留了 API 代差

Linux 版从 2020 直接跳到 15.0.1，对只在 Linux 做图形评测的人是迟到的补丁。但同一张卡两 OS 渲染路径不同（OpenGL vs DX12/Vulkan），跨平台数字不可直接比，评测须显式标注 API 口径，否则会得出误导性结论。

2. AArch64 是实打实的好消息

Arm 工作站（Ampere、富士通 MONAKA 144 核）与 Apple Silicon（Asahi/Linux 或虚拟机）此前没有官方专业图形基准；官方 AArch64 构建让「Arm 工作站跑标准图形负载」从凑合变可复现。

3. 为什么总慢半拍：视图集依赖 Windows 应用

SPECViewPerf 的视图集本质是回放 ISV 应用（Maya/SolidWorks/CATIA）真实渲染流，这些专业应用重心仍在 Windows，Linux 版需重适配。基准代差只是表象——专业图形生态重心仍在 Windows。

4. 对谁有用：GPU 厂商的 Linux 驱动验证工具

游戏玩家基本无感（有 3DMark/游戏内 benchmark）；但对 NVIDIA / AMD / Intel 的 Linux 工作站驱动验证与回归测试，这是必要且权威的工具，AArch64 让 Arm 平台驱动团队有了对标基准。
