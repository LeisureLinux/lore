# Ubuntu 26.10 改主意了：内核从 Linux 7.2 跳到 7.3，十月发布前先吃上最新主线

> 原文：[Ubuntu 26.10 Switches To The Linux 7.3 Kernel](https://www.phoronix.com/news/Ubuntu-26.10-With-Linux-7.3)（Phoronix，2026-09-18，作者 Michael Larabel）。本文由 LeisureLinux 翻译整理并加注解读；文内事实与日期均来自原文，未作改动。

一个挺意外的好消息：即将发布的 **Ubuntu 26.10「Stonking Stingray」** 所用的内核，从原本计划的 **Linux 7.2** 改成了 **Linux 7.3**。

今年 5 月，Canonical 内核团队曾宣布 Ubuntu 26.10 将随 7.2 内核发布——这是他们按当时的发布节奏定的：在十月这次更新里随上游最新主版本内核走。但到了今天，通过读者邮件和我在几台测试机上跑的 `sudo apt dist-upgrade`，Linux 7.3 已经悄悄出现了。

## 为什么临时改主意

事情源于我之前漏看的一篇 Discourse 公告（月初发的）：Canonical 内核团队宣布**重新对齐到 Linux 7.3**。

原因很直接：Linux 7.1 和 7.2 这两个发布周期**上游都没有延期**，节奏稳得很，以至于 7.3 的 `-rc1` 都已经放出来了。团队觉得既然主线这么顺，干脆一步到位上 7.3，而不是停在 7.2。原话大意是：

> 基于上游 Linux 的开发节奏——7.1、7.2 周期均无延误，且 7.3-rc1 已经发布——我们很高兴地把目标上调：Ubuntu 26.10 将改为瞄准 Linux 7.3 内核，而非 7.2。这让我们与最新的上游能力保持一致，尤其是**最新的硬件支持**，同时不会偏离既定的发布里程碑。团队正在 7.3-rc1 上游内核之上启用所有 Ubuntu 专属特性，很快会在 `-proposed` 通道放出供早期测试。

这对用户是好事——Linux 7.3 带来了一批[新特性与改进](https://www.phoronix.com/review/linux-73-features)。

## 时间线：节奏很紧，但赶得上

几个关键节点：

- Linux 7.3 之前已经在 Stonking Stingray 的 `proposed` 归档里，现在正向 Ubuntu 26.10「Stonking」归档推送，**赶在下周 beta 发布之前**。
- Ubuntu 26.10 计划 **10 月 15 日** 正式发布；**内核冻结（kernel freeze）在 10 月 1 日**。
- 也就是说，正式 ISO 在稳定版更新之前，会落在一个**预发布内核状态**。
- 如果 Linux 7.3 按时发布，就是 **10 月 18 日**；若还需要额外的 release candidate，则推迟到 **10 月 25 日**。

由于这不是 LTS 版本，Canonical 在「追最新上游内核」这件事上表现得相当激进。

## 解读：一个被低估的好信号

**1. 这不是「随便跳版本」，而是上游节奏顺到让发行版敢追。**

内核团队敢于在 freeze 前一个月把目标从 7.2 抬到 7.3，前提是 7.1、7.2 都没延误、7.3-rc1 已出。换句话说，**主线开发健康度的提升，直接缩短了「发行版能追到的内核版本」与「上游最新」之间的差距**。对普通用户，这意味着你买的新硬件、新平台，在 Ubuntu 26.10 上更可能直接被内核认出来，不用等 HWE 或手动装新版内核。

**2. 对「非 LTS」的 Ubuntu，追新内核是既定策略，但有代价。**

文章点明：因为不是 LTS，他们才会「vigorously pursuing the latest upstream kernel」。这把双刃剑——你拿到最新硬件支持，但正式 ISO 会停在「预发布内核状态」，稳定版出来前那一阵子的内核是 RC。生产环境若要可预期的内核行为，通常等 26.10.1 之类的小版本补丁或更稳的 HWE 栈更合适；尝鲜和稳态，得自己掂量。

**3. 对工程师的实操提醒：beta 之前就能在 `-proposed` 里摸到真东西。**

想提前验证你的驱动 / 硬件在 7.3 上的表现，不必等 10 月。Canonical 明确说 7.3-rc1 之上的 Ubuntu 专属特性启用完就会进 `-proposed` 通道——这才是「提前测试」的正确入口，而不是去 main 归档里硬追 dist-upgrade。
