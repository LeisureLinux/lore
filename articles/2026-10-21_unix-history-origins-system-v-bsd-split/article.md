> 本文是**第一篇**，讲 1969 到 1993 的起源与分裂。第二篇会讲「今天还活着的 Unix 全表」以及各家的最新版本与支持截止日。
> 本文为**解读**。第一节关于「三份法律文件塑造了 Unix 史」的框架、第五节的判断是笔者补充的部分。

## 一句话结论

**关于「Unix 为什么有两大阵营」，最常见的解释是技术路线的分歧：BSD 有 socket，System V 有 STREAMS；BSD 偏学术，System V 偏商业。**

**这些都对，但它们都是**结果**，不是**原因**。**

**我认为真正的原因是三份法律文件，而它们在时间上相隔三十九年**：

1. **1956 年的一份反垄断同意令**，让 AT&T 在法律上**不能卖** Unix，只能送源码。**这一份造就了 Unix 的传播。**
2. **1983 年 AT&T 被拆分**，同意令解除，AT&T **终于可以卖** Unix。**这一份造就了阵营的分裂。**
3. **1995 年 Novell 卖 Unix 业务时的一份版权排除条款**，**这一份造就了后来十八年的诉讼。**

**而这条线索有一个非常具体的物证。USENIX 那篇论文把第一份文件说得很清楚**：

> **「1956 年同意令让 Unix 成了『开放的』，但是被授权的（licensed）。这在今天看来确实就是我们认为的『开源』。」**
>
> **「按照同意令的规则，AT&T 在法律上被要求把 Unix 提供给任何来问的人。Murray Hill 的技术授权办公室就是这么做的，费用是 150 美元的磁带复制费。这个费用只覆盖 AT&T 购买、写入和邮寄磁带的成本。」**

**「150 美元的磁带复制费」。** **这个数字是整部 Unix 史的起点，而它不是商业定价，是一个成本补偿。** **AT&T 靠 Unix 一分钱没赚，而正因为如此，Unix 走遍了全世界的大学。**

**而当你读完这条线索，会发现一个很大的讽刺**：**Unix 之所以成为 Unix，是因为它的主人没法拿它赚钱。而当它的主人终于可以拿它赚钱时，它已经不属于任何一个人了。**

## 一、1969：一个被关上的门，和一台没人用的机器

**标准叙事是这样开始的**。

**1965 年，贝尔实验室加入了 MIT 和通用电气合作的 Multics 项目**（**Multiplexed Information and Computing Service**，多路信息与计算服务）。**AT&T 在这上面投了五年、几百万美元，买了一台 GE-645 大型机，把 Thompson、Ritchie、Ossanna、Feldman、McIlroy、Morris 这批人放进去。**

**然后 1969 年 3 月，AT&T 退出了。**

**IEEE Spectrum 的记述很直白**：

> **「1969 年 3 月，一扇门对 Thompson 和 Ritchie 关上了：他们的雇主美国电话电报公司退出了一个与 MIT 和通用电气合作创建交互式分时系统 Multics 的项目。」**
>
> **「在 AT&T 退出 Multics 项目之后，贝尔实验室（位于新泽西州 Murray Hill）的管理者变得不愿允许任何进一步的计算机操作系统工作，这让那里的一些研究者非常沮丧。」**

**于是 Thompson 在一台「放在角落里、少有人用的 PDP-7」上开始写东西。Unix.org 的历史页就用了这个说法**：**「1969 年，Ken Thompson、Dennis Ritchie 等人开始在一台『放在角落里少有人用的 PDP-7』上工作。」**

**而那台 PDP-7 是什么？Warner Losh 的史料给了具体参数**：**18 位的小型计算机，从 PDP-4 到现在机型之间基本二进制兼容。** **而 PDP-7 之前的产品线密度很有画面感**：**PDP-1（1959）约 10 台，PDP-4（1962）约 25 台，PDP-7（1964）就是那个「角落里」的型号。**

**至于名字，IEEE Spectrum 给的解释是一个玩笑**：

> **「Unix 这个名字来自 Thompson 一位同事开的玩笑：因为这个新系统只支持一个用户（Thompson 自己），他把它看作是 Multics 的一个被阉割的版本，于是叫它『Un-multiplexed Information and Computing Service』，或者 Unics。这个名字后来演变成了 Unix。」**

**「Un-multiplexed」。** **这个命名很有信息量，因为它是一个**减法**的命名**：**不是「我做出了一个更好的多用户系统」，而是「我把多路复用拿掉了」。**

**而第一版手册的时间点是**：**内部 1971 年 11 月出版，1973 年 10 月对外公布。**

### 版本的演进，以及一个关键转折

**Warner Losh 把早期版本的重写过程整理成了一条清晰的线，而这条线比「V1、V2、V3」这种编号有信息量得多**：

| 版本 | 时间 | 做了什么 |
|---|---|---|
| **第 0 版（PDP-7 汇编）** | **1970** | **PDP-7 汇编器** |
| **第 1 版（PDP-11/20 转译）** | **1971** | **把 PDP-7 汇编器转译成 PDP-11 汇编器（不是 MACRO-11）** |
| **第 3 版（PDP-11/45 移植）** | **1972** | **开始使用 MMU** |
| ⭐ **第 4 版（C 重写）** | **1973 年 11 月** | **用 C 重写内核** |

**而第 4 版那一条是整部 Unix 史上最重要的技术决定**。**Losh 的原话是**：

> **「内核保持用 C 编写，而从根本上是同一个东西，一直到 System III（1982）。」**

**「一直到 System III 都是同一个东西」。** **也就是说，1973 年那次 C 重写之后，Unix 的内核在近十年里只是被改，没有被重写。**

**而这次重写为什么重要，我认为可以这样理解**：**Unix 之前也有操作系统，但它们是用汇编写的，所以逻辑上不可移植。而 C 让「同一个内核跑在不同机器上」成为一件工程上可行的事。** **而这一条恰恰是「Unix 能传播」的技术前提**，**因为没有它，150 美元的磁带寄到另一所大学也没用。**

**第 4 版还有一个值得记的细节**：**它是「第一个发布给大学的版本」**（**Losh：第一个发布给大学的版本，4 到 5 所大学**），**也是第一次有了商业授权**（**「RAND 拿到了第一份商业授权」**）。

**而这里的传播机制值得注意**：**Losh 提到第 6 版（1975）和「Unix 进入野外、移植开始」**，**而 PWB/UNIX（1977）是基于第 6 版的第一个发行版**。

## 二、1983：当 AT&T 终于可以卖 Unix，它发现自己要和自己的衍生物竞争

**这一节是整篇文章的核心，而它的因果链非常清楚。**

**1956 年的同意令是怎么来的？USENIX 那篇论文把背景交代了**：

> **「1949 年，司法部提起了反垄断诉讼，目标是强制拆分西部电气。这场诉讼在七年后以 AT&T 同意把它的产品和服务限制在公共运营商电信领域、并向『所有感兴趣的各方』授权其专利而达成和解。」**
>
> **「这一条的一个关键效果是**禁止 AT&T 销售**（不是电信相关的产品）。」**

**而这个禁令有一个副作用，是当时谁也没想到的**：**AT&T 既然不能卖 Unix，就只能按「专利授权」的方式给人源码。而这个「不能卖」的状态持续了二十七年。**

**然后 1982 年，AT&T 被拆分了。**

**USENIX 那篇论文的说法是**：**「1982 年的拆分允许 AT&T 激进地把 Unix 变现（System V）。」**

**而 Unix.org 的时间线给了具体的商业动作**：

| 年份 | 事件 |
|---|---|
| **1982** | **AT&T 的 UNIX System Group（USG）发布 System III，这是贝尔实验室之外第一个公开发行版**；**SunOS 1.0 出货**；**HP-UX 问世**；**Ultrix-11 问世** |
| ⭐ **1983** | **AT&T 宣布 UNIX System V，第一个有支持的发行版**；**装机量 45,000 套** |
| **1984** | **System V Release 2 推出**；**此时全世界有 100,000 套 Unix 安装**；**OSF 和 UNIX International 成立** |
| **1989** | **System V Release 4 出货，统一了 System V、BSD 和 Xenix**；**装机量 120 万套** |

**注意 1984 年那一行里的「OSF 和 UNIX International 成立」。** **这两个组织就是「Unix 战争」的双方，而它们的性质需要说清楚**：

- **UNIX International（UI）**：**AT&T 和 Sun 领头的阵营，推 System V Release 4**。
- **OSF（Open Software Foundation）**：**IBM、DEC、HP 等组成的对抗阵营**，**因为它们的 Unix 都是基于 System V 前几版的，而 SVR4 的出现让它们面临「要么跟着 AT&T 走，要么另起炉灶」**。

**而这场战争的技术表现，HandWiki 的总结很准确**：

> **「这场争执有多个层次，一些是技术的（socket 对 STREAMS，BSD tty 对 System V termio），一些是文化的。分歧大致在『长发』和『短发』之间；程序员和技术人员倾向于伯克利和 BSD，更偏商业的人倾向 AT&T 和 System V。」**

**「长发和短发」（longhairs and shorthairs）。** **这个说法很有意思，因为它承认了一件事：这场技术分裂同时是一次文化分裂。**

**而这场战争的结局是什么？Unix.org 的答案是**：

> **「1996 年，Open Group 作为 OSF 和 X/Open 的合并体成立。」**

**「Open Group 是 OSF 和 X/Open 的合并」。** **也就是说：两个阵营最终合并成了一个标准化组织，而那个组织今天还在，就是发放「UNIX 认证」的那个 Open Group。** **而这是一条很重要的线索，我在第二篇会回到它**：**今天「是不是 Unix」这件事，法律上由 Open Group 的商标决定，而不是由代码血统决定。**

### 而 BSD 那条线，起点不是「反对 AT&T」

**这里需要纠正一个常见的误读。** **BSD 不是因为「有人不同意 System V」而诞生的，它的起点更早、更自然。**

**Unix.org 的时间线**：

> **「1984 年，加州大学伯克利分校发布 4.2BSD，包含 TCP/IP、新的信号机制以及更多东西。」**

**而 4.2BSD 之前是 4.1BSD（1980），再往前是 3BSD、2BSD、1BSD。** **CSRG（Computer Systems Research Group）拿的是 AT&T 授权的源码，做了大量改进，然后把改进免费发布。**

**而 4.2BSD 那条「包含 TCP/IP」是关键**：**它意味着**互联网的协议栈是从 BSD 长出来的**。** **而这件事对后续所有操作系统的影响，比 Unix 战争大得多。**

**而 Berkeley 那条线有一个结局，Unix.org 写得很简洁**：

> **「1993 年，4.4BSD，伯克利的最终发布。」**
> **「1994 年，BSD 4.4-Lite 消除了所有被声称侵犯 USL/Novell 的代码。」**

**「4.4-Lite 消除了所有被声称侵犯 USL/Novell 的代码」。** **这句话背后是一场诉讼，而它是理解「版权问题」的入口。**

## 三、版权：Unix 到底是谁的，以及为什么这件事打了十八年

**这一节我按法院文书的时间线整理，因为这是唯一能讲清楚的部分。**

### 第一层：Unix 的版权是怎么流转的

**2005 年的一份法院意见（SCO v. Novell）把背景说得很清楚**：

> **「在 1960 年代末，AT&T 开发了 UNIX，一个计算机操作系统，并开始向客户授权 UNIX 源代码。」**
>
> **「1993 年，Novell 以超过 3 亿美元从 AT&T 购买了 UNIX 程序开发和授权业务。它继续授权旧版本的 UNIX 源代码（称为 SVRX，X 是授权的发行编号），并开发了自己的定制 UNIX 平台 UnixWare。」**

**「超过 3 亿美元」。** **AT&T 当年靠 150 美元的磁带送出去的 Unix，二十四年后以三亿多美元卖掉了业务。**

**然后就是关键的一步**：

> **「两年后，Novell 决定卖掉这个业务。」**

### 第二层：1995 年那笔交易，以及一个排除条款

**同一份法院意见记录了交易的结构，而这一段是整件事的技术核心**：

> **「最初版本的 APA（资产购买协议）没有把版权列入转让资产清单。事实上，它明确**排除**了『[a]ll copyrights and trademarks, except for the trademarks UNIX and UnixWare』。」**
>
> **「在交割之前，双方签署了 APA 的第 1 号修正案。」**

**「明确排除了所有版权和商标，除了 UNIX 和 UnixWare 这两个商标」。**

**我认为这句话是理解整个十八年诉讼的唯一钥匙。** **因为这次交易卖掉的是**业务**（授权合同的应收款、UnixWare 产品线、客户关系），而**留住了版权**。** **在法律上，「业务」和「版权」是可以分开卖的，而 1995 年那笔交易恰好把它们分开了。**

**而法院对交易实质的描述更直接**：

> **「Novell 在庭审中提交了充分证据，显示这笔交易中只卖了两样东西：（1）UNIX 授权业务，SCO 将代表 Novell 继续经营，以换取总版权费的 5%，而 Novell 保留版权和 95% 的版税费流；（2）UnixWare 以及使用底层 UNIX 的许可。」**

**「Novell 保留版权和 95% 的版税费流」。** **也就是说：SCO 拿到的是一个「代收版税的生意」，而不是「Unix 本身」。**

### 第三层：2003 年的引爆点，以及 2007 年的判决

**2003 年 3 月，SCO 起诉 IBM**，**指控 IBM 把属于 SCO 的 Unix 代码贡献给了 Linux。** **而它的法律基础是「我在 1995 年买到了 Unix 的版权」。**

**Novell 的回应是 2003 年 5 月 28 日的一份新闻稿。法院意见引了它的原文**：

> **「重要的是，与 SCO 的断言相反，SCO 不是 UNIX 版权的所有者。不仅快速查一下美国版权局的记录就能揭示这个事实，而且审阅 Novell 与 SCO 之间的资产转让协议也能确认它。据 Novell 所知，1995 年那份管辖 SCO 从 Novell 购买 UNIX 的协议，并没有把相关版权转让给 SCO。」**

**而 2007 年 8 月 10 日，犹他州联邦地区法院法官 Dale A. Kimball 做出了判决。Ars Technica 的报道是**：

> **「联邦地区法院法官 Dale A. Kimball 在周五做出裁决，宣告 Novell 拥有 UNIX 版权。Kimball 的裁决意味着 SCO 旷日持久的诉讼列车脱轨即将终结。」**
>
> **「Kimball 法官认定，Novell 从未在 1995 年协议期间或之后把 UNIX 版权的所有权转让给 SCO。」**

**而后果立刻出现**：

> **「在 2007 年 8 月 10 日的不利裁决之后不久，SCO 在特拉华地区申请破产。」**

**然后 2010 年 3 月，陪审团再次确认 Novell 拥有版权**。**CRN 的报道**：

> **「犹他州美国地区法院审理 SCO 集团与 Novell 之间案件的陪审团做出了有利于 Novell 的裁决。」**
>
> **「Novell 发布声明说：『Novell 非常满意陪审团的决定，确认了 Novell 对 Unix 版权的所有权，而 SCO 曾在其对 Linux 的攻击中主张拥有这些版权。』」**

**而 2010 年 6 月，法官 Ted Stewart 驳回了 SCO 的重审请求，并指示书记员立即结案。CRN 引了原话**：**「书记员被指示立即关闭本案。」**

### 第四层：2021 年的收尾，以及 2026 年的最后一枪

**这部分很多人不知道，而它是这条线的真正结局。**

**2021 年 8 月，SCO 的破产受托人（TSG Group）与 IBM 达成和解。ZDNET 的报道**：

> **「特拉华地区美国破产法院宣布，代表 SCO 债务人的 TSG 集团已与 IBM 和解，并解决了 TSG 与 IBM 之间所有剩余的索赔。『根据和解协议，双方同意以向受托人（代表各遗产）支付 14,250,000 美元的方式解决它们之间的所有争议。』」**
>
> **「作为回报，TLD 放弃对 IBM 和 Red Hat 的所有诉讼索赔的全部权利和利益，无论是已提起的还是未来可能主张的，以及任何关于 Linux 侵犯 SCO 的 Unix 或 UnixWare 知识产权的指控。」**

**「1425 万美元」。** **这是十八年诉讼的最终价格。**

**而 Xinuos 那条线更曲折。** **2011 年，Xinuos 从 SCO 破产中买走了 OpenServer 和 UnixWare 产品线，而法院意见记载了价格和排除条款**：

> **「SCO 与 Xinuos 于 2011 年 1 月 19 日签订了资产购买协议。该 APA 授予 Xinuos 某些『取得的资产』，但**剔除**了『SCO 对 IBM 的所有待决诉讼索赔以及未来可能提出的所有权利和利益』，以及『SCO 已经或可能对 Red Hat 主张的任何性质的每一项索赔，无论已知或未知』。」**
>
> **「Xinuos 为取得的资产支付了 60 万美元现金。」**

**「60 万美元」。** **从 3 亿美元（Novell 买业务）到 60 万美元（Xinuos 买资产），而最重要的是那个排除条款：** **Xinuos 买到了产品，但没有买到「起诉 IBM 和 Red Hat 的权利」。**

**然后 2021 年 3 月 31 日，Xinuos 还是起诉了 IBM 和 Red Hat**（**在美属维尔京群岛**）。**而 IBM 的回应很直接**（**Ars Technica 引述**）：

> **「Xinuos 的版权指控只是重复其前任的陈旧主张，而那些版权是 Xinuos 从破产中买来的，毫无价值。」**

**而 2026 年 8 月的结局，Slashdot 引 The Register 的报道**：

> **「这场关于 Linux 所有权的长期法律战『比以往任何时候都更接近结束』，此前一个三人法官合议庭裁定针对 IBM 和 Red Hat 的一项索赔无效，并且进一步行动的时间已经过期。」**

**而那个裁定的理由值得完整引用，因为它是双重的**：

> **「问题是即使 Xinuos 成功证明了这一点，在法律上也毫无意义。正如地区法院和上诉法院所指出的，**Xinuos 没有诉讼资格**。Xinuos 在 2011 年从 SCO 集团购买的资产明确排除了与 IBM/Project Monterey 相关的索赔。那些索赔已在 2021 年由 SCO 集团与 IBM 和解。Xinuos 试图在 SCO 集团的破产法院辩称他们有份额，而法院驳回了。」**
>
> **「第二个原因是诉讼时效限制。」**

**「没有诉讼资格」加「诉讼时效过期」。** **这就是那条从 1995 年排除条款开始的线索，在三十一年后的终点。**

## 四、所以「Unix 的版权」现在在谁手里

**这一节给结论，因为这是你的粉丝最可能问的问题。**

**答案分三层，而每一层对应不同的东西**：

**① 源代码的版权**：**历史上分散在 AT&T → Novell（1993）这条线上，而 1995 年卖给 SCO 的那笔交易**没有**转让版权。所以按 2007 年和 2010 年的判决，**版权留在 Novell**。**而 Novell 在 2011 年被 Attachmate 收购，2014 年又被 Micro Focus 收购，2023 年 Micro Focus 被 OpenText 收购。** **所以如果你要问「Unix 系统 V 的版权现在归谁」，法律上的答案指向 OpenText（通过 Micro Focus）这条链。** **⚠️ 但我需要标注：这条公司收购链我没有逐笔核实过原始公告，它是我根据公开的并购历史推的，如果要写进正式材料请再核。**

**② 「UNIX」这个商标**：**1993 年底，Novell 把「UNIX」商标和 Single UNIX Specification 的权利转给了 X/Open。** **Unix.org 的原话是**：**「1993 年底，Novell 把『UNIX』商标和 Single UNIX Specification 的权利转给 X/Open。」** **而 X/Open 1996 年与 OSF 合并成 **The Open Group**。** **所以今天「UNIX」是 Open Group 的注册商标，而「一个系统是不是 Unix」在法律上由它的认证决定，不由代码血统决定。**

**③ 那些具体的产品线**：**AIX 在 IBM 手里，Solaris 在 Oracle 手里，HP-UX 在 HPE 手里，OpenServer 和 UnixWare 在 Xinuos 手里，macOS 在 Apple 手里，FreeBSD/OpenBSD/NetBSD 在各自基金会手里。** **而它们之间的**代码**关系，有些已经很淡了**（**OpenServer 10 是 FreeBSD 10 基座**，**而 macOS 的内核是 Mach + BSD 的混合体**）。

**而这里有一个我认为很值得强调的区分**：**「Unix 血统」和「Unix 认证」是两个独立的维度。** **一个系统可以「有 Unix 代码血统但没认证」（Linux 严格说没有，因为它没买认证），也可以「有认证但血统复杂」（macOS 就是这样，它的 UNIX 认证是真的）。** **而这个区分在下一篇会很重要，因为它是理解「今天还有哪些 Unix」的关键。**

## 五、我的判断

**第一，Unix 的历史之所以必须讲法律史，是因为 Unix 的每一次形态变化都是由一个外部约束触发的，而不是由技术判断触发的。** **1956 年的同意令让 AT&T 不能卖，所以 Unix 被送出去；1983 年的拆分让它能卖，所以 System V 出现了，而分裂也随之出现；1995 年的排除条款让版权和业务分离，所以有了十八年诉讼。** **这三件事里没有一件是「工程师决定的」。** **我认为这一点对今天的读者仍然有现实意义**：**开源项目的命运，往往由它所在法域的竞争法、公司法、以及一份合同的具体措辞决定，而不是由它的代码质量决定。**

**第二，那个「三家分层」（代码版权 / 商标 / 产品线）的结论，是这一篇最该被记住的东西。** **因为绝大多数关于「Unix 是谁的」的讨论，都在混用这三层。** **「Linux 是不是 Unix」这个问题的答案取决于你问哪一层**：**血统上不是（它没拿 AT&T 源码），认证上不是（没买 Open Group 认证），商标上不是（那是 Open Group 的），但它**实现了** POSIX 和 Single UNIX Specification 定义的接口。** **所以严格的回答是：Linux 是 Unix-like，不是 Unix。而这个区分不是学究，它在法律和采购上都有后果。**

**第三，SCO 那场官司的真正遗产，不是判决结果，而是「它让整个行业学会了一件事：审计代码的来源」。** **因为 SCO 的指控迫使 Linux 社区、各家发行版、以及大企业做了一次全面的代码来源审查。** **而这次审查的结果是：Linux 没有抄 Unix 的代码，但它确实在接口和行为上跟着 Unix。** **我认为这个区分（**实现**相同 vs **代码**相同）是那场官司唯一的技术产出，而它被后来的开源许可证讨论反复使用。**

**第四，如果只能从这一篇里带走一个时间点，我会选 1994 年的 4.4BSD-Lite。** **因为「消除了所有被声称侵犯 USL/Novell 的代码」这句话，是 Unix 史上最重要的一次**减法**。** **它意味着：从那一刻起，BSD 的代码在版权上干净了。** **而正是这次减法，让 FreeBSD、OpenBSD、NetBSD 三家有了合法的基础，也让后来的 macOS 敢用 BSD 的代码。** **换句话说：今天所有活着的 BSD，都是那次「重写以脱钩」的产物。**

> **下一篇要讲什么**：**我会把「今天还活着的 Unix」列成一张全表，而且每一个都给出最新版本和状态。**
>
> **而这里面有几条会让你意外**：
> - **HP-UX 已经在 2025 年 12 月 31 日彻底停止支持**，那条从 1982 年开始的线断了。
> - **AIX 还在积极开发**，**7.3 TL4 是 2025 年 12 月发布的，支持到 2028 年底**，**而 TL2 在 2026 年 11 月就到期**。
> - **Solaris 11.4 的最新 SRU 是 2026 年 9 月 21 日的 SRU95**，而**它的支持期标到 2037 年**。
> - **macOS 的版本号在 2025 年改成了年份制**，**所以现在叫 macOS 26 Tahoe，而 2026 年 9 月已经出了 macOS 27 Golden Gate**，**而它不再支持 Intel**。
> - **Xenix 的最后版本是 2.3.4，而它在 1996 年 1 月 1 日就停止了**（这个我在下一篇会展开，因为它的死和 IBM PC 的崛起有关）。
> - **还有一个你可能没听过的分支：illumos**，它是 Solaris 在 Oracle 关掉 OpenSolaris 之后的开源延续，**而 OpenIndiana 在 2026 年 5 月还发了新版**。

| ⭐ **Unix 起点** | **1969 年，Ken Thompson、Dennis Ritchie 等人在贝尔实验室一台「角落里少有人用的 PDP-7」上开始** |
| **直接触发原因** | **1969 年 3 月 AT&T 退出 Multics 项目**，**贝尔实验室管理者随后不愿再允许操作系统工作** |
| **PDP-7 是什么** | **18 位小型计算机**（**PDP-1 约 10 台，PDP-4 约 25 台，PDP-7 是 1964 年型号**） |

| ⭐ **1956 年同意令的背景** | **1949 年司法部起诉要求拆分西部电气；七年后和解，AT&T 同意把产品服务限制在公共运营商电信领域，并向「所有感兴趣的各方」授权专利** |
| ⭐ **同意令的效果** | **禁止 AT&T 销售非电信产品 → Unix 只能「授权源码」不能卖**；**「按照同意令的规则，AT&T 在法律上被要求把 Unix 提供给任何来问的人」** |
| ⭐ **那个价格** | **150 美元的磁带复制费，只覆盖 AT&T 购买、写入和邮寄磁带的成本** |
| ⭐ **最早的商业授权** | **RAND 拿到了第一份商业授权** |
| **第 4 版的关键** | **1973 年 11 月用 C 重写内核**；**「内核保持用 C 编写，直到 System III（1982）都是根本上的同一个东西」** |
| **第一个给大学的版本** | **第 4 版，给了 4 到 5 所大学** |
| **PWB/UNIX** | **1977 年，基于第 6 版的第一个发行版** |
| ⭐ **1982 年的转折** | **AT&T 被拆分，同意令解除**；**「1982 年的拆分允许 AT&T 激进地把 Unix 变现（System V）」** |

| **SVR2** | **1984 年；此时全世界 100,000 套 Unix 安装**；**同年 OSF 和 UNIX International 成立** |
| ⭐ **SVR4** | **1989 年，统一了 System V、BSD 和 Xenix；装机量 120 万套** |
| **Unix 战争的文化层面** | **「分歧大致在『长发』和『短发』之间；程序员和技术人员倾向伯克利和 BSD，更偏商业的人倾向 AT&T 和 System V」** |
| **技术分歧的具体内容** | **socket 对 STREAMS；BSD tty 对 System V termio** |
| ⭐ **战争结束** | **1996 年，Open Group 作为 OSF 和 X/Open 的合并体成立** |
| **BSD 关键版本** | **4.2BSD（1984，含 TCP/IP、新信号机制）；4.4BSD（1993，伯克利最终发布）** |
| ⭐ **4.4BSD-Lite** | **1994 年，消除了所有被声称侵犯 USL/Novell 的代码** |

| ⭐ **1995 年交易的排除条款** | **APA 明确排除了「所有版权和商标，除了 UNIX 和 UnixWare 这两个商标」** |
| ⭐ **法院对交易实质的认定** | **「只卖了两样东西：① UNIX 授权业务（SCO 代营，拿 5% 版税，Novell 保留版权和 95%）；② UnixWare 及使用底层 UNIX 的许可」** |
| **SCO 起诉 IBM** | **2003 年 3 月** |
| **Novell 的反驳** | **2003-05-28 新闻稿：「SCO 不是 UNIX 版权的所有者」** |
| ⭐ **2007-08-10 判决** | **法官 Dale A. Kimball 认定 Novell 从未转让版权给 SCO** → **SCO 随即申请破产** |
| **2010-03 陪审团** | **确认 Novell 是 UNIX 版权的合法所有者** |
| **2010-06 结案** | **法官 Ted Stewart 驳回重审请求，「书记员被指示立即关闭本案」** |
