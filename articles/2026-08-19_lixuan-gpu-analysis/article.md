# 砺算 LX 7G100 GPU 深度评测：国产显卡性能对标与生态建设现状

> **发布日期**：2026 年 8 月 19 日 | **技术解读**：FreeLamp 社区  
> **核心亮点**：CPU-Z 2.21 官方支持 + 3DMark 2040 分 + 100+ 游戏适配

---

## 一、技术概览：砺算 LX 7G100 正式亮相

2026 年 8 月 17 日，硬件检测工具 **CPU-Z 2.21 版本**正式发布，首次对**国产显卡砺算 LX 7G100**提供完整硬件信息识别支持。这标志着国产显卡正式融入全球主流硬件检测与调试生态，继兆芯之后又一款被 CPU-Z 官方收录的国产 GPU。

### 核心规格

| 参数 | 规格 | 说明 |
|------|------|------|
| **代号** | LX 7G100 | 砺算自研型号 |
| **架构** | TrueGPU 天图 | 完全自研图形指令集与核心架构 |
| **制程工艺** | 6nm | 采用台积电/中芯国际先进制程 |
| **显存配置** | 12GB GDDR6 | 高带宽消费级显存 |
| **位宽** | 192-bit | 平衡性能与成本 |
| **纹理单元** | 192 个 | 负责纹理处理与采样 |
| **光栅化单元** | 96 个 | 负责像素渲染与输出 |
| **核心频率** | 1420MHz | 典型运行频率 |
| **功耗 (TDP)** | 225W | 需独立供电方案 |
| **输出接口** | 4× DisplayPort 1.4a | 支持 4K/8K 多屏输出 |
| **API 支持** | DirectX 12, Vulkan 1.3 | 完整主流图形 API |
| **超分辨率** | NRSS (Native Real-time Super Sampling) | 自研 AI 升频技术 |
| **认证** | WHQL | 通过微软硬件兼容性认证 |
| **操作系统** | Windows, 统信 UOS, 银河麒麟 | 全平台兼容 |
| **游戏适配** | 100+ 款主流游戏 | 含 3A 大作 |

### 价格策略

- **创始版（2026 年 5 月）**：3299 元
- **零售版**：2688 元
- **目标市场**：中高端消费级游戏与专业图形应用

## 二、性能基准测试：3DMark Steel Nomad 分析

### 2.1 测试成绩

**3DMark Steel Nomad (1080p 物理渲染)**：
- **砺算 LX 7G100**：2040 分
- **NVIDIA RTX 3060**：约 2000 分（基准测试参考）
- **对比结果**：LX 7G100 **小幅领先 RTX 3060**

### 2.2 技术解读

Steel Nomad 测试模拟了物理渲染、光照计算与纹理采样，是衡量 GPU 综合图形性能的重要指标。LX 7G100 能够跑分 **2040**，说明其：

1. **纯性能超越 RTX 3060**：在不依赖光线追踪（RTX 核心）的情况下，传统光栅化处理能力已优于 3060。
2. **6nm 制程优势**：高频率与低功耗平衡，核心效率优于 14nm-12nm 老旧工艺。
3. **自研架构优化**：TrueGPU 天图针对中国游戏场景进行优化，指令效率更高。

> **注意**：此分数为传统光栅化性能，未包含光线追踪等高级特性。

## 三、游戏渲染能力：100+ 游戏适配清单

### 3.1 支持游戏范围

截至目前，LX 7G100 已适配 **超过 100 款主流游戏**，覆盖：

- **3A 大作**：《赛博朋克 2077》《黑神话：悟空》《艾尔登法环》《原神》等
- **竞技网游**：《英雄联盟》《CS2》《DOTA 2》《绝地求生》
- **国产独立游戏**：《戴森球计划》《鬼谷八荒》《暖雪》等

### 3.2 渲染性能表现

| 分辨率 | 画质设置 | 平均帧率 | 适用场景 |
|--------|---------|----------|---------|
| **1080p** | 高画质（High） | 60-90 FPS | 流畅运行主流 3A |
| **1440p** | 中画质（Medium） | 45-60 FPS | 轻度电竞/独立游戏 |
| **4K** | 低画质（Low） | 30-45 FPS | 视频输出、专业应用 |

### 3.3 NRSS 超分辨率技术

砺算自研的 **NRSS (Native Real-time Super Sampling)** 技术，通过 AI 算法提升画面渲染效率：

- **效果**：提升 20-40% 帧率，同时保持画面质量
- **类似 NVIDIA DLSS / AMD FSR**
- **优势**：针对国产游戏引擎深度优化，兼容性更好

## 四、横向对比：LX 7G100 vs AMD/Intel/景嘉微

### 4.1 与 AMD Radeon 系列对比

| 参数 | 砺算 LX 7G100 | AMD RX 7600 | AMD RX 6600 |
|------|--------------|------------|-----------|
| **制程** | 6nm | 6nm | 7nm |
| **显存** | 12GB GDDR6 | 8/16GB GDDR6 | 8GB GDDR6 |
| **位宽** | 192-bit | 128-bit | 128-bit |
| **纹理单元** | 192 | 128 (64 CU) | 64 (40 CU) |
| **光栅化** | 96 | 64 (32 CU) | 40 (25 CU) |
| **TDP** | 225W | 165W | 132W |
| **3DMark 分** | 2040 | ~1950 | ~1750 |
| **API** | DX12, Vulkan | DX12, Vulkan | DX12 |
| **驱动支持** | WHQL, 自研 | 成熟驱动 | 成熟驱动 |
| **价格** | 2688 元 | 2200-2600 元 | 1500-1800 元 |

**结论**：LX 7G100 在纯光栅化性能上已超越 RX 7600，显存容量更大（12GB vs 8GB），但功耗较高（225W vs 165W），需优化散热。

### 4.2 与 Intel Core 集成显卡对比

| 参数 | 砺算 LX 7G100 | Intel Arc A770 | Intel Iris Xe (iGPU) |
|------|--------------|----------------|--------------------|
| **类型** | 独立显卡 | 独立显卡 | 集成显卡 |
| **核心** | TrueGPU 天图 | Xe HPC | Xe-LP |
| **显存** | 12GB GDDR6 | 16GB GDDR6 | 共享系统内存 |
| **位宽** | 192-bit | 256-bit | 128-bit |
| **3DMark 分** | 2040 | ~1900 | ~500-800 |
| **价格** | 2688 元 | 2500-3000 元 | 集成无价 |
| **适用场景** | 游戏/渲染 | 游戏/创做 | 办公/轻游戏 |

**结论**：LX 7G100 远超 Intel 集成显卡，与 A770 性能相当，但在驱动成熟度上仍有差距。

### 4.3 与国产景嘉微 JH-9 系列对比

| 参数 | 砺算 LX 7G100 | 景嘉微 JH-9621 | 景嘉微 JH-720 |
|------|--------------|---------------|-------------|
| **定位** | 消费级游戏 | 军工/航天 | 桌面办公 |
| **制程** | 6nm | 14nm/28nm | 28nm |
| **显存** | 12GB GDDR6 | 4GB GDDR5 | 2GB DDR3 |
| **性能** | 2040 分 (3DMark) | ~300-500 分 | ~100 分 |
| **API** | DX12, Vulkan | OpenGL | OpenGL |
| **游戏支持** | 100+ 款 | <10 款 | 无游戏支持 |
| **价格** | 2688 元 | 5000-8000 元 | 1000-2000 元 |

**结论**：LX 7G100 性能是景嘉微 JH-9 的 4-6 倍，且全面兼容 Windows 游戏生态，景嘉微仍聚焦军工/特定行业。

## 六、核心架构解析：TrueGPU 天图技术

### 6.1 架构特点

- **完全自研**：从计算核心、指令集到整体架构均为自主研发，无依赖
- **6nm 先进制程**：高晶体管密度，性能/功耗比优秀
- **统一内存架构**：12GB GDDR6 大显存，支持高纹理渲染
- **高并行度**：192 个纹理单元 + 96 个光栅单元，适合大规模并行计算

### 6.2 Shader Core 设计

- **自定义 Streaming Multiprocessor**：优化 CUDA 兼容（通过兼容层）
- **指令级并行**：支持 VLIW + SIMD 混合架构
- **深度学习加速**：内置 AI 指令，支持 NRSS 超分
