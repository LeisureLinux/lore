01

WHAT IT IS

它到底是什么

项目身份

ghgrab 是 [abhixdd]{mono="mono" px="px"} 维护的终端优先 Git 仓库选择性下载工具。它解决的核心问题：

「你只想拿一个文件 / 一个目录 / 一个 release 二进制，为什么要 clone 整个仓库？」

GitHub / GitLab 这类平台默认推送的「完整仓库 zip」对少数文件场景极不友好------几百 MB 解下来只为了取一个 JSON 配置。

ghgrab 通过直接调 Git forges 的 [HTTP API + Git LFS API]{mono="mono" px="px"}，让「按需下载」成为默认。

支持哪些 Git forge

Forge 仓库浏览 路径下载 TUI 搜索 Release 下载

GitHub ✅ ✅ ✅ ✅ GitLab ✅ ✅ ❌ ❌ Codeberg ✅ ✅ ❌ ❌ Gitea ✅ ✅ ❌ ❌ Forgejo ✅ ✅ ❌ ❌

⚠️ LIMITATION

TUI 仓库搜索 + release 下载目前只支持 GitHub------其他 forge 只能做 path download。

关键能力

- Selective downloading------只下你需要的文件 / 目录

- Interactive TUI------交互式终端 UI，fuzzy match 导航

- 预览源文件------下载前能看文件内容

- GitHub LFS 支持------大文件走 LFS 拉取

- CLI 模式------除了 TUI，也能命令行直接跑

- Release asset 自动选------按 OS + arch 自动挑对的那个二进制

02

WHY IT MATTERS

为什么这件事重要

clone 整个仓库的成本

场景 git clone ghgrab

拿 1 个 JSON 配置 几十 MB + 几秒到几十秒 KB 级 + \< 1 秒 拿 release 的 Linux x86_64 二进制 完整仓库 zip（几百 MB） 直接拉那一个 asset 浏览仓库结构 必须 clone 看 tree TUI 直接看

对 CI / 容器构建 / 离线环境，ghgrab 的优势更明显------少下几十 MB 就是[构建时间 + 镜像体积]{b="b" solid="solid"}。

跟其它下载方式对比

工具 一次性下 TUI LFS 多 forge

git clone --depth=1 整个仓库历史 ❌ ✅ ✅（Git 协议） curl raw.githubusercontent.com 单文件 ❌ ❌ 只 GitHub gh release download release asset ❌ ❌ 只 GitHub ghgrab 文件 / 目录 / release ✅ ✅ ✅（除搜索）

ghgrab 的差异化在于三者合一：单文件、目录树、release asset 都能用同一个工具拉。

LFS 是个分水岭

GitHub LFS（Large File Storage）用来管理[模型权重 / 数据集 / 视频源]{b="b" solid="solid"}这些 GB 级文件------普通 [git clone]{mono="mono" px="px"} 不会自动拉 LFS 对象（只下指针文件）。ghgrab 明确支持 LFS，意味着对机器学习 / 数据工程场景也友好。

git 是版本控制工具，ghgrab 是按需获取工具------两件事不冲突。

HOW TO USE

怎么用

安装

按你顺手的包管理器：

.        .        .        bash

# Node.js 生态

npm install -g \@ghgrab/ghgrab

# Rust

cargo install ghgrab

# Python（推荐 pipx，避免污染全局）

pipx install ghgrab

# Nix（用最新版）

nix run github:abhixdd/ghgrab

# Arch Linux AUR

yay -S ghgrab-bin

[pipx]{mono="mono" px="px"} 推荐用------Python 全局包污染是常见痛点，pipx 给每个工具独立 venv。

几种典型用法

下载单个文件

.        .        .        bash

ghgrab grab https://github.com/owner/repo/blob/main/path/to/file.json

下载整个目录

.        .        .        bash

ghgrab grab https://github.com/owner/repo/tree/main/docs

下载 release 二进制（自动按 OS/arch 选）

.        .        .        bash

ghgrab release abhixdd/ghgrab

进入 TUI 模式浏览

.        .        .        bash

ghgrab tui abhixdd/ghgrab

# 或者直接

ghgrab

用法哲学

ghgrab 不是要取代 git------[git 是版本控制 + 协作工具]{b="b" solid="solid"}，ghgrab 是[按需获取工具]{b="b" solid="solid"}。两件事的取舍：

选 git 选 ghgrab

你要参与项目 / 提 PR 你只要拿一个文件 你要完整历史 / blame 你只要最新版 你在写代码 你在集成 / 引用 你能 clone 几百 MB 你网络 / 磁盘预算紧

常见问题（FAQ）

Q1：ghgrab 解决什么痛点？ A1：你只想拿仓库里「一个文件 / 一个目录 / 一个 release 二进制」，它让你按需下载，不用 clone 整个几百 MB 的仓库。

Q2：支持哪些 Git forge？ A2：GitHub / GitLab / Codeberg / Gitea / Forgejo 都支持路径下载；交互式 TUI 搜索和 release 下载目前仅 GitHub 支持。

Q3：和直接 git clone 比有什么优势？ A3：按需选择性下载，省流量省时间；支持 GitHub LFS 大文件，release 资产按 OS + arch 自动挑对的那个二进制。

Q4：怎么用？ A4：提供交互式 TUI（fuzzy 导航）和 CLI 两种模式，下载前还能预览源文件内容。
