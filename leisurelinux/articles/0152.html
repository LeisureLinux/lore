一、引言：一场范式革命正在发生

当全球具身智能赛道都在追逐 VLA（视觉-语言-动作）端到端大模型时，一位来自清华和哈佛的学者，带着9位清华博士，用8年时间走出了一条截然相反的路。

这条路，叫「本能驱动」。

橡木果机器人（Acorn Robot），2024年底成立于北京。创始人姜峣博士------清华大学机械工程博士、哈佛大学神经科学博士后、现任清华大学机械工程系副研究员------在长达9年的研究中发现了一个被业界长期忽略的关键事实：

操作有先天本能，语言没有本能。两者底层机制截然不同，不应共用同一套框架。

这个看似简单的认知差异，可能正在重塑整个具身智能行业的底层逻辑。

二、公司背景：清华+哈佛的学术传承2.1 创始人：姜峣博士

  • 教育背景：南京理工大学机械工程及自动化学院学士（2011），清华大学机械工程系博士（2016），哈佛大学神经科学博士后
  • 现任职务：清华大学机械工程系制造工程研究所副研究员
  • 研究领域：机器人交互感知与自主化操作

姜峣的学术轨迹极为独特------在清华机械工程完成博士学业后，他没有继续走传统机械臂操控路线，而是远赴哈佛，在神经科学实验室从事博士后研究。这段经历让他在人类操作行为的神经机制层面有了极其深刻的认知，也成为后来「操作本能」理论的直接起源。

2.2 团队构成

橡木果核心团队号称「9位清华博士」，由清华大学机械工程博士与哈佛大学神经科学博士后领衔，融合机械工程、神经科学、触觉传感、机器人控制等多个交叉学科背景。

团队自2011年起深耕机器人操作领域，2017年率先提出「本能驱动」具身智能这一非共识技术路线，并于2018年搭建实验室团队。2025年正式启动商业化，2026年3月完成近亿元种子轮融资。

资金将主要用于核心技术迭代、产品商业化落地及团队扩建。

值得关注的是，姜峣团队的第一位博士生从2016年就开始参与，2018年回国后正式搭建团队。在长达8年的技术积累中，团队并未追逐热点，而是专注于被主流忽视的「操作本能」路线。

三、核心立论：语言无本能，操作有本能

这是整个理论的原点，也是最具颠覆性的判断。

3.1 语言 vs 操作：二元底层割裂

维度 语言 物理操作

习得方式 全后天数据驱动，隔绝人类教育就学不会 先天内置，婴儿无教学即本能抓握 通用性 不同语言间差异巨大 全球人类抓取动作底层逻辑高度一致 约束来源 文化约定 物理规律约束 核心机制 符号拟合与统计概率 神经-肌肉-触觉闭环反射

姜峣在哈佛神经科学实验室期间，通过研究人类和灵长类动物的抓取行为，发现操作行为背后存在一套与生俱来的神经回路------它不依赖后天学习，而是生物进化的底层能力。

3.2 对VLA的彻底否定

当前主流的 VLA 架构，本质上是用大语言模型的范式套在物理操作上，认为「只要数据够多、模型够大，机器人就能学会操作」。

姜峣的结论：这是根本性错误。

\"不能用大模型符号拟合的逻辑来套物理操作。机器人要先预装生物级操作本能，再靠环境交互后天练出技能。\"

四、技术架构：任务-操作双层解耦

橡木果的技术架构完全围绕「本能驱动」理念设计，与业界 VLA 大一统架构形成鲜明对比：

4.1 架构总览

┌─────────────────────────────────────┐
│  上层（大脑）：任务规划             │
│  ─── 沿用大模型做语义理解           │
│  ─── 任务指令拆解、输出语义约束     │
│  （如：「不要洒水」）               │
└────────────────┬────────────────────┘
                 │ 标准化接口
┌────────────────▼────────────────────┐
│  下层（躯体）：本能执行引擎 Natus   │
│  ─── 内置原生操作本能库             │
│  ─── 零训练样本、零场景预训练       │
│  ─── 收到指令自主适配物理环境       │
└─────────────────────────────────────┘

4.2 Natus：三大原生底层本能

① 定向本能------视觉联动躯体，自动追踪、趋近目标物体（对标婴儿追视行为）

② 滑移自适应本能------这是橡木果最核心的技术壁垒。通过自研触觉传感器实时感知滑移、形变等触觉信息，以「滑移最小化」为目标自动调节抓力：

  • 抓豆腐时自动松力，不捏碎
  • 抓铁块时自动加力，不掉落
  • 物体在手中打滑时，毫秒级响应调增夹力
  • 触碰硬物时自动减力

③ 探索本能------面对未知物体，自主微调姿态，无需预设参数即可适配异形物料。

4.3 Magis：通用操作技能模型

在 Natus 产生大量真实触觉交互数据后，Magis 利用这些带有精准触觉语义的数据（不仅仅是「成功/失败」，而是「120g、质心偏左、表皮粗糙、硬度中等」），训练出跨本体、跨任务的通用操作技能模型。

一句话概括：Natus 解决「能不能抓住」，Magis 解决「抓得好不好」。

4.4 自研触觉传感器

一切根基始于本能，而本能的构建需要完备的触觉输入。橡木果历时7年迭代，自研第三代视触觉传感器，可捕获三类关键触觉信息：

  1. 交互属性：软硬度、摩擦系数、质心分布（视觉无法获取）
  2. 接触事件：接触刚度、阻抗等
  3. 表面分布：纹理、粗糙度等

橡木果的核心观点：触觉信息的完备性是第一原则------缺任何一类，都无法构建真正的操作本能。

五、技术落地：零数据冷启动，已跑通工业产线5.1 0预训练数据的奇迹

在实测中，橡木果机器人面对全新陌生工件、非标物料：

  • ✅ 不用采集数据集
  • ✅ 不用微调模型
  • ✅ 开箱即用抓取

这与 VLA 路线形成鲜明对比：VLA 换一个物料就要重新采数据、重新训练，泛化能力极差。

5.2 工业落地实绩

已落地于3C电子、快消品等自动化产线：

  • 消费电子精密零部件抓取
  • 日化产品（化妆品瓶罐等异形物料）的抓取、旋拧、放置
  • 食品行业易碎品（豆腐、鸡蛋等）的安全抓取

在全球头部化妆品 ODM 厂商的 POC 验证中，仅用 2个月时间即完成验证并实现商业营收。机器人被要求抓取形状、材质各异的化妆品瓶罐，快速适配能力获得高度认可。

5.3 路线定位

全球首个自下而上本能型具身智能，区别于全行业自上而下的数据模仿路线。

六、行业价值与讨论6.1 是否真正具有颠覆性？

从理论层面看，确实是颠覆性的。

当前具身智能行业的主流做法是「数据越多越好、模型越大越好」。姜峣团队提出的是一个完全反向的路线：回归物理世界的第一性原理，先赋予机器人类人本能，再让它在交互中自我进化。

这种思路如果成立，将：

  • 破除海量标注数据依赖，降低通用机器人落地门槛
  • 适配国产算力、机械臂硬件，成为国产具身智能的差异化技术底座
  • 填补人机操作神经-机械交叉空白，开辟「本能AI」新赛道

但也存在明显的争议点：

  1. Natus 本能引擎的设计是否真正通用？在面对超复杂任务（如手术缝合、精密装配）时是否足够？
  2. Magis 技能模型的训练效能有多大？目前公开数据有限，难以独立评估
  3. 与 VLA 路线是否存在融合可能？还是必须二选一？

6.3 潜在风险

  • 商业化时间尚短：公司2024年底成立，商业化仅1年，规模化还需验证
  • 工业场景有限：目前仅在3C和快消品领域有实际部署，更复杂的工业场景（汽车制造、航空航天等）尚未涉足
  • VLA 路线也在进化：以Google、OpenAI为代表的VLA路线也在快速迭代，不能排除未来VLA克服当前瓶颈的可能性
  • 触觉传感器成本：自研传感器能否在规模化后保持成本优势，仍有不确定性

七、结论

橡木果机器人和姜峣博士团队提出的「本能驱动」路线，在理论层面确实为具身智能行业开辟了一个全新的思考方向。它挑战了「用大模型解决一切」的主流叙事，回归到物理世界的第一性原理。

但客观来说，这并不是一个「谁对谁错」的问题，而是一个「两条腿走路」的问题。

VLA 路线擅长从宏观层面积累知识，适合任务规划和语义理解；橡木果的本能路线擅长底层物理交互，适合精细操作和实时控制。两者的长期关系更可能是互补而非取代。

不过无论如何，在一个被大模型叙事统治的时代，能有一个中国团队基于扎实的学术根基提出完全不同的底层理论，并已开始商业化落地，这本身就值得高度关注。

一枚橡果，既是收获的果实，更是孕育无限可能的种子。
