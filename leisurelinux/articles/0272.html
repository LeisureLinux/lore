告别性能焦虑：Niri 26.04 如何通过 ext-background-effect 重新定义毛玻璃效果

未知日期 编程/开发 阅读原文（微信）↗

Niri 26.04 终于在 2026 年 4 月 25 日正式发布，这次更新最受关注的无疑是Blur（毛玻璃效果）的引入。作为目前最热门的滚动平铺式 Wayland 窗口管理器，Niri 这次在美化和性能之间找到了一个非常巧妙的平衡点。

以下是针对 Niri 26.04 的深度技术解读：\

1. 核心亮点：双模 Blur 方案

Niri 这次实现的模糊效果并不是简单的"性能杀手"，它提供了两种模式，兼顾了低功耗和高视觉质量：

  • •X-Ray Blur（默认模式）：极致性能
    • •原理：它只计算一次壁纸的模糊版本并将其作为静态图像缓存。当你开启窗口透明时，它直接显示这张缓存的模糊壁纸，而不去实时计算窗口下方复杂的窗口内容。
    • •优势：极低开销，对于笔记本用户和追求流畅度的开发者非常友好。
  • •Normal Blur（全模糊）：动态渲染
    • •原理：传统的毛玻璃效果，实时采样当前窗口下方所有的图层内容。
    • •适用场景：通常建议在 top 或 overlay 图层（如弹出菜单、浮动窗口）上开启，以获得更真实的视觉层次感。

2. 协议支持：ext-background-effect

Niri 26.04 原生支持了 ext-background-effect Wayland 协议。

  • • 这意味着像Foot、Kitty、Ghostty这种现代终端，以及Noctalia、Dank Material Shell等组件，可以自动向 Niri 请求模糊效果，无需在 Niri 配置里手动写规则。

  • •针对老应用：你依然可以通过 window-rule 手动开启。例如：

    window-rule {
    match app-id="^Alacritty$"
    background-effect { blur true }
}

3. Screencasting（录屏/分屏）重大改进

在 Linux 桌面，录屏时的光标显示一直是个痛点。26.04 引入了基于 PipeWire 的光标元数据传输：

  • •精准光标渲染：在录屏时，光标不再是生硬地画在视频流里，而是作为元数据发送。OBS 等软件可以更智能地处理光标，甚至在光标被遮挡时自动隐藏。
  • •IPC 强制停止：新增 niri msg action stop-cast 命令，可以通过脚本或快捷键强行关闭正在进行的录屏会话，增强了隐私安全性。

4. 其他值得关注的技术细节

  • •Pointer Warping：滚动操作时支持指针自动跟随。
  • •配置热切换：新增 --path 参数，支持在运行时切换不同的 Niri 配置文件，方便开发者调试。
  • •DMA-BUF 支持：Niri 在嵌套运行（Nested mode）时现在支持硬件加速，性能大幅提升。
  • •VRAM 泄露修复：解决了关闭应用后部分显存无法释放的老大难问题。

总结

Niri 26.04 的发布标志着它从一个"极简滚动器"向"全功能精致桌面"的跨越。其X-Ray Blur的设计思路非常符合 Linux 极客的审美：既要颜值，也不允许为了颜值牺牲哪怕 1% 的性能。\ 对于 Vim 用户和终端爱好者来说，这次更新配合 Kitty 或 Foot 终端开启 X-Ray Blur，可以获得极其丝滑且不掉帧的编码环境。
