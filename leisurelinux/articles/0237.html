腾讯混元新架构：模型能力跨越式升级，得益于 Anthropic 生态启发

未知日期 AI/Agent 阅读原文（微信）↗

\ 腾讯在 2026 年 4 月底发布的旗舰模型Hunyuan-Hy3-Preview（混元 Hy3 预览版）引发了技术圈的高度关注。这一版本不仅是腾讯 AI 架构重组后的首个重大成果，更在"智能体（Agentic）"能力上实现了跨越式提升，这背后的核心因素之一确实与Anthropic及其倡导的技术生态密切相关。

\

\

1. 核心技术升级：从"大力出奇迹"到"效能至上"

Hy3-Preview 的参数量为295B，相比去年的 Hy 2.0 在规模上有所缩减，但性能却反超。

  • •MoE（混合专家模型）架构优化：采用了 192 个专家（Experts）的 MoE 架构，单 token 激活参数仅为 21B。这意味着腾讯转向提升计算效率和专家选择的精准度。
  • •思维链的三级跳：Hy3 引入了类似 Anthropic 理念的推理模式，支持no_think / low / high三种推理模式，允许在推理时通过增加计算量（Compute-over-time）来换取更深的思考能力。

2. 与 Anthropic 的深度联动：MCP 协议与 Agent 生态

市场传闻的"受益于 Anthropic"并非指代码级的复制，而是腾讯全面拥抱了 Anthropic 主导的MCP (Model Context Protocol)协议。

  • •连接器革命：腾讯的 Agent 工具原生集成了 Anthropic 的 MCP 层。这使得腾讯的模型可以无缝调用全球开发者为 Claude 编写的数千个工具插件，极大地扩展了其在现实任务中的执行能力。
  • •智能体工作流（Agentic Workflows）：Hy3 在SWE-bench Verified测试中表现优异，其稳定性足以支持复杂的多步 Agent 工作流。

3. 人才与架构的关键变量：姚顺雨（Shunyu Yao）

此次提升的另一个关键变量是姚顺雨。

  • •背景重组：姚顺雨是原 OpenAI 推理和长文本研究的核心成员，也是 ReAct 框架的作者。他于去年底加入腾讯担任首席 AI 科学家后，主导了混元管线的"底座重构"。
  • •方法论转型：腾讯从过去的产品导向转向了"系统化能力"建设，强调强化学习（RL）与预训练的并行规模化，这与 Anthropic 强调的"自动化对齐"理念异曲同工。

4. 商业与生态位：腾讯的"窄路快跑"

相较于其他厂商重资产投入基础设施，腾讯走的是一条以产品带模型的道路：

  • •全场景植入：Hy3 在发布当日即同步接入元宝（Yuanbao）、ima、CodeBuddy 等。
  • •成本杀手：Hy3 预览版的推理效率大幅提升，极具竞争力的 Token 价格意在通过 B 端开发者反馈快速迭代。

总结

腾讯 Hy3 的这次"逆袭"，本质上是**模型算法（MoE+推理增强）与全球标准化协议（MCP）**双轮驱动的结果。借力 Anthropic 开拓的生态标准，腾讯成功将微信积累的庞大私域数据转化为 Agent 的执行力，而不再仅仅是一个"聊天机器人"。
