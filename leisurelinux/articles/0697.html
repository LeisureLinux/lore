笔记本续航焦虑？Linux 性能调优神器 auto-cpufreq 3.0 正式发布！

发布于 · 分类 Linux/运维

摘要： 告别繁琐设置，让你的 Linux 笔记本在高性能与长续航之间丝滑切换。\ 对于 Linux 笔记本用户来说，如何平衡"性能"与"续航"一直是个让人头疼的问题。虽然市面上有很多系统监控工具，但手动调整 CPU 频率、监控功耗实在太麻烦。

\ 今天，备受好评的自动调频工具 auto-cpufreq 正式发布了 3.0 版本！这次更新带来了更智能的电池管理、全新的 Turbo Boost 手动控制，以及对华硕（ASUS）用户的专属福利。\ \

什么是 auto-cpufreq？\ 如果你还不了解它，简单来说：auto-cpufreq 是一个专为 Linux 设计的 CPU 速度和功耗自动优化工具。\ 它能够实时监测系统状态：\ * 插电时： 自动切换到高性能模式，确保流畅体验。\ * 用电池时： 自动切换到节能模式，大幅延长续航时间。\ 它不仅能优化功耗，还能通过智能调频有效降低笔记本在高负荷下的发热量。\ \

3.0 版本有哪些重磅新特性？\ 1. CPU Turbo Boost 手动控制\ 在之前的版本中，Turbo Boost（睿频）通常由软件自动决定。但在 3.0 版本中，用户拥有了更大的话语权！\ * 你可以在命令行或 GUI 界面中手动将 Turbo 设置为：Auto（自动）、Never（从不）或 Always（始终）。\ * 这样即使在插电状态下，如果你想让电脑更安静、更凉快，也可以一键禁用睿频。\ \

2. 更精准的电池检测\ 如果你的笔记本拥有双电池（比如一些 ThinkPad 系列），或者系统误报了电池设备，3.0 版本允许你手动指定需要监控的电池设备，解决了以往"电量监测不准"的痛点。\ \

3. 华硕（ASUS）笔记本专属优化\ 新版本增加了对**华硕笔记本电池充电阈值（Charge Thresholds）**的支持。你可以设置电池充电上限（例如 80%），这对于长期插电办公的用户来说，能极大延长电池的使用寿命。\ \

4. 稳定性与修复\ * 修复了 --monitor 监控模式下显示错误频率的问题。\ * 解决了 NixOS 平台上 "awk: command not found" 的报错。\ * 优化了 Pop!_OS 的安装过程，修复了 PyGObject 失败的问题。\ \

如何安装与使用？\ 如果你想体验这款神器，推荐通过源码安装（这是最稳妥的方式）：\ # 克隆仓库\ git clone https://github.com/AdnanHodzic/auto-cpufreq.git\ \ # 进入目录并执行安装脚本\ cd auto-cpufreq && sudo ./auto-cpufreq-installer\ \ 安装完成后，输入 sudo auto-cpufreq 即可查看命令行菜单。如果你更喜欢图形界面，也可以在应用菜单中搜索并启动它的 GUI 程序。\ Ubuntu 用户也可以通过 Snap 快速安装：\ sudo snap install auto-cpufreq\ \

\

结语\ auto-cpufreq 3.0 的发布，让 Linux 笔记本的电源管理变得更加简单且强大。无论你是想让老设备焕发第二春，还是想在新款高端笔记本上获得更持久的续航，这都是一款不容错过的工具。\ \
