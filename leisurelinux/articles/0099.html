ImmortalWrt vs OpenWrt：同源异路的两个路由器系统

未知日期 Linux/运维 阅读原文（微信）↗

TL;DR： ImmortalWrt 是 OpenWrt 的一个第三方分支（fork），由中国社区维护，专注本地化体验和更广泛的设备支持。两者底层共用一个内核，但在软件包、设备支持、社区生态上各有侧重。

一、历史渊源：为什么会有 ImmortalWrt？

OpenWrt 是全球最知名的嵌入式 Linux 发行版，生于 2004 年，已经活跃了二十多年。它让无数家用路由器「脱胎换骨」，从封闭的制造商固件变成了完全可定制的网络系统。

但 OpenWrt 毕竟是国际社区主导的项目，有一些「中国用户痛点」长期得不到解决：

  1. 软件源缺少国内常用软件——某些梯子、内网穿透、DDNS 插件在官方源里找不到
  2. 热门国产设备支持滞后——新款 MTK/RTL 设备、软路由平台在新品发布后迟迟没有官方支持
  3. 编译门槛高——想要自编译固件加几个包，新手往往卡在搭建环境的步骤

于是，ImmortalWrt 应运而生。

二、ImmortalWrt 的核心差异① 本地化软件包

ImmortalWrt 最直观的区别就是软件源。官方 OpenWrt 的软件包数量和种类已经很多，但 ImmortalWrt 额外移植了大量国内常用的软件包：

  • PassWall、SSR-Plus、V2Ray、Xray 等代理相关插件
  • 阿里云 DDNS、DNSPod、腾讯云 DDNS
  • 内网穿透客户端（frp、ZeroTier、Tailscale 等）
  • 网易云音乐解锁、广告过滤等特色功能包

这些包在 OpenWrt 官方源里要么没有，要么需要从第三方源额外添加，而 ImmortalWrt 直接内置。

② 设备支持

ImmortalWrt 覆盖的设备比 OpenWrt 更广，包括：

  • 更多国产路由器（红米、小米、华为某些型号）
  • 新款软路由平台（Intel N100/N305、N5105、J4125 等 x86 平台）
  • EdgeRouter 等企业级设备
  • 部分原 OpenWrt 不再维护的老旧设备依然保留支持

可以说，如果你买了一个新款国产路由但 OpenWrt 官方还没出固件，ImmortalWrt 很可能已经有版本了。

③ 编译与定制

OpenWrt 官方提供 Image Builder 可以定制固件，但对新手来说不算友好。ImmortalWrt 则：

  • 提供更丰富的在线编译选项（类似 LEDE 时代的风格）
  • 社区有大量现成的固件预编译版可以直接刷入
  • 编译脚本针对国内网络环境优化，下载依赖更快

④ 更新节奏

OpenWrt 保持一贯的稳重节奏，版本更新周期偏长，测试充分。ImmortalWrt 则更激进一些：

  • 快跟主线——OpenWrt 主线一更新，ImmortalWrt 往往在一周内跟进
  • 合并修补更快——新的安全补丁、驱动更新会更快地合入
  • 内核版本更新速度更快——某些场景下比官方主线早几个小版本

⑤ 包管理器演进

两者都在同步进化。从早期的 opkg，到现在的 apk（Alpine Package Keeper）——ImmortalWrt 25.12 版本起也转向了 apk。包管理体验和 Alpine Linux 一致，依赖解析更可靠。

三、技术对比一览

维度 OpenWrt ImmortalWrt
项目性质 官方主线 社区分支（fork）
目标用户 全球用户 中文用户为主
软件源 官方精选包 额外内置大量国内常用包
设备覆盖 官方支持列表 更广，含更多国产设备
更新频率 稳重，测试充分 跟进更快，节奏更激进
社区语言 英文为主 中文社区活跃
文档 英文文档成熟 中文资料更多，但零散
内核版本 通常偏保守 更新更快

四、如何选择？

选择并不复杂，取决于你的场景：

选 OpenWrt 如果：

  • 你是国际社区爱好者，习惯英文文档
  • 你的设备在官方支持列表内
  • 你需要「最干净」的官方体验
  • 你更看重稳定性和长周期支持

选 ImmortalWrt 如果：

  • 你的主力语言是中文，习惯中文社区讨论
  • 你用的是新款国产路由器或软路由（N100/N305 等）
  • 你需要的插件在 OpenWrt 官方源里找不到
  • 你希望「开箱即用」，减少折腾编译的功夫

五、能否共存？

同一个路由器，不能同时刷两个系统。但你可以：

  • 从 ImmortalWrt 的软件源安装它的特色包到 OpenWrt（手工配置源）
  • 把 ImmortalWrt 编译出的内核模块移植到 OpenWrt
  • 在两个系统中切换刷机（注意配置会清空）

其实 ImmortalWrt 的很多改动（如驱动补丁）最终也会反向贡献回 OpenWrt 主线。这也是开源社区的魅力——分支不是分裂，而是试验田。

六、一句话总结

OpenWrt 是正统，ImmortalWrt 是本地化加强版。

前者说「我给你工具，你自己造」，后者说「工具给你了，常用的也帮你装上」。

在中国路由器玩家圈里，ImmortalWrt 的地位介于「官方亲儿子」和「魔改固件」之间——它保留了 OpenWrt 的内核纯净度，又提供了国内用户喜欢的那种\"到手就能用\"的便利感。

对于普通玩家，下载体验官网的固件包，看看能不能覆盖你的设备，可能是最好的开始。
