爷青结！ifconfig、scp 都要退场？2026年，这些 Linux 命令别再用了！

未知日期 安全/漏洞 阅读原文（微信）↗

你可能不相信，但你现在日常使用的某些 Linux 命令，其实早已被官方列入"弃用（Deprecated）"名单了。\

这并不全是你的错。很大程度上是因为习惯使然，或者是被网上那些陈旧的教程误导了。尤其是在网络管理领域，许多经典命令正逐渐被更强大、更安全的新型工具取代。

作为一名紧跟技术潮流的 Linux 用户，了解哪些命令正在淡出舞台至关重要。

1. scp ------ 潜在的弃用对象

scp 是基于 SSH 协议的经典传输工具。由于其底层协议已有数十年历史且存在无法修复的安全漏洞，OpenSSH 官方已建议转向更全能的工具。

* 建议替代方案： rsync 或 sftp

2. egrep 和 fgrep ------ 已被 grep 选项取代

这是目前最紧迫的更替之一。

* egrep：支持扩展正则表达式（ERE）。

* fgrep：用于固定字符串搜索。

注意： 从 grep 3.8 版本开始，如果你继续使用 egrep 或 fgrep，系统可能会向你发出警告。它们的功能已完全集成到 grep 的参数中。

* 建议替代方案： 使用 grep -E 代替 egrep，使用 grep -F 代替 fgrep。

3. netstat ------ 网络统计的新选择

netstat 隶属于已停止维护的 net-tools 工具包。现代发行版通常不再默认安装它，取而代之的是效率更高的 ss。

* 建议替代方案： 使用 ss 命令。

4. ifconfig ------ 时代的眼泪

这是最让人不舍的命令。但在现代系统中，它的功能已经被更强大的 ip 系列命令完美替代。

* 建议替代方案： 使用 ip addr（或简写为 ip a）。

5. arp, route, iptunnel ------ 随 net-tools 一起消亡

这些命令在 2010 年后的系统中基本已不复存在，它们现在全部收归到了 ip 命令的各个子选项中：

* arp \rightarrow ip n

* route \rightarrow ip route

6. iwconfig ------ 还在坚持吗？

类似于无线版的 ifconfig，目前已被 Red Hat 等发行版移除。

* 建议替代方案： 使用 iw 命令。

7. iptables ------ 正在被"亲爹"取代

开发团队 Netfilter 已经推出了继任者：nftables。它将 iptables、ip6tables、arptables 等混乱的工具统一到了一个高效的框架下。

* 建议替代方案： 使用 nftables 命令。

\

结语

技术在不断进步，为了让你的脚本在未来的系统中依然稳健，建议大家逐步在笔记和脚本中更新这些替代方案。
