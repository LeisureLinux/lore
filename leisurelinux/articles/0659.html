只要一个 URL，挖穿对方网站的所有底细！OSINT 神器 web-check

发布于 · 分类 安全/漏洞

\

如果你是一名开发者、安全研究员，或者单纯想知道某个网站背后到底用了什么技术、服务器设在哪里，那么这款名为 web-check 的开源项目绝对值得收藏。

\ 1. 项目简介\ web-check 是一个功能极其强大的 全能型网站分析工具 (OSINT)。它通过一个简洁的 Web 界面，让你只需输入一个 URL，就能深度挖掘出该网站的各类公开情报（Open Source Intelligence）。\ 目前该项目在 GitHub 上已获得超过 30k 的 Star，足见其受欢迎程度。\ * GitHub 地址：Lissy93/web-check\ * 在线体验：web-check.xyz\ 2. 核心功能：它能查到什么？\ web-check 几乎涵盖了你对一个网站所有能想到的维度分析：\ * 基础架构：IP 地址信息、物理位置（服务器在哪）、托管商、ASN 信息。\ * 技术栈分析：识别前端框架、后端语言、服务器类型、CMS 平台等。\ * 安全信息：SSL 证书链详细信息、DNSSEC、端口扫描（常见端口）、security.txt 检测。\ * SEO 与合规：robots.txt 内容、Sitemap 抓取规则、网站性能指标（Lighthouse 分数）、Carbon Footprint（碳足迹计算）。\ * 域名相关：详细的 DNS 记录（A, MX, TXT, NS 等）、Whois 信息。\ * 其他细节分析：Cookie 详情、HTTP 响应头（Headers）、第三方追踪器（Trackers）、关联的主机名等。\ 3. 项目亮点\ * 一站式服务：不再需要开几十个网页（查 IP 的、查 SSL 的、查 Whois 的），一个输入框搞定一切。\ * 交互式仪表盘：扫描结果以模块化展示，视觉效果非常清晰。\ * 隐私友好：工具本身不收集你的分析数据。\ * 自托管支持：你可以通过 Docker 或 Vercel/Netlify 轻松部署一套属于自己的 Web 检查工具，甚至可以绕过官方演示版的一些速率限制。\ 4. 部署与使用\ 如果你想在本地运行，非常简单：\ 使用 Docker (推荐):\ docker run -p 3000:3000 lissy93/web-check\ \ 运行后访问 localhost:3000 即可开始使用。

\ 5. 总结\ web-check 不仅仅是一个技术工具，它更像是一个"网站透视镜"。对于网络安全从业者来说，它是前期信息收集的利器；对于开发者，它是学习优秀站点配置、排查线上问题的助手。
