架构预警：Microsoft 将强制禁用 WDS 自动化部署功能 (CVE-2026-0386)

未知日期 安全/漏洞 阅读原文（微信）↗

技术背景：未授权 RPC 带来的零点击风险

近期，Microsoft 披露了一个编号为CVE-2026-0386的关键远程代码执行（RCE）漏洞。该漏洞的根源在于 Windows 部署服务（Windows Deployment Services, WDS）在处理自动化安装配置文件（Unattend.xml）时的不当访问控制（CWE-284）。

在传统的 PXE 网络启动流程中，WDS 服务器通过未经验证的 RPC 通道传输敏感的配置信息。攻击者可以利用邻近网络（Adjacent Network）发起中间人攻击或流量拦截，从而：

  1. 获取敏感凭据：拦截Unattend.xml中明文或简单加密的本地管理员密码及域加入凭据。

  2. 执行任意代码：通过注入恶意脚本到部署任务序列，在操作系统安装完成前的系统上下文（SYSTEM privilege）中执行代码，导致整个基础设施的镜像污染。

Microsoft 已经明确了针对 Windows 11 24H2/25H2 以及 Windows Server 2025 的两阶段处置策略：

深度分析：IT 架构的重构压力

从 IT 咨询顾问的角度看，这一举措标志着 Microsoft 正在加速淘汰基于旧版 RPC 协议的网络部署架构。

  • 攻击向量分析：该漏洞的 CVSS 评分虽然受限于"邻近网络"属性，但在数据中心或企业局域网内部，其**低复杂度（AC:L）和无需用户交互（UI:N）**的特性使其成为横向移动的绝佳入口。

  • 兼容性陷阱：对于依赖 WDS +Unattend.xml实现大规模裸机（Bare Metal）部署的传统数据中心，4 月份的更新将直接导致现有的自动化流水线断裂。

  • 安全加固路径：

1.  **临时规避**：若必须维持现状，需通过注册表设置`AllowHandsFreeFunctionality = 1`{index-in-node="22" path-to-node="15,2,1,0,0"}（注意：这将使服务器持续处于暴露状态）。

2.  **架构迁移**：建议全面转向**Microsoft Endpoint Manager (Intune)**、**Autopilot**或基于**HTTPS/WinRM**的现代部署工具，彻底摒弃不安全的 TFTP/RPC 明文传输。
