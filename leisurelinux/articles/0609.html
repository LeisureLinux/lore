一个号称比 homebrew 快20倍的 zerobrew ，由 rust 语言编写

发布于 2026-01-27 06:53 · 分类 安全/漏洞

zerobrew是一个由开发者 Lucas Gelfond 开发的开源项目，旨在作为 macOS 包管理器Homebrew的高性能替代品。

以下是该项目的详细介绍：

1. 项目定位

  • 目标：成为 Homebrew 的"即插即用"（drop-in）替代方案。

  • 核心优势：速度极快。根据项目描述，在冷启动（首次安装）时比 Homebrew 快5 倍，在热启动（重新安装/更新）时甚至快20 倍。

  • 开发语言：主要使用Rust编写（约 91.9%），利用 Rust 的并发能力和安全性来实现极致性能。

2. 为什么它这么快？

zerobrew 采用了类似现代包管理器（如 Python 的uv）的设计思路：

  • 内容寻址存储（Content-addressable store）：包通过 SHA256 哈希值存储在/opt/zerobrew/store/下。如果该版本的包已存在，重新安装几乎是瞬间完成。

  • APFS Clonefile：利用 macOS APFS 文件系统的特性，通过写时复制（copy-on-write）技术实现文件的快速链接，几乎不占用额外的磁盘空间。

  • 并行化操作：下载、解压和链接过程是并发执行的，大幅减少了等待时间。

  • 激进的 HTTP 缓存：对下载请求进行了深度优化，避免重复下载。

3. 主要特性

  • 兼容性：它直接从 Homebrew 的 CDN 拉取资源，因此用户可以直接用zb命令（zerobrew 的 CLI 名称）代替brew，并沿用现有的 Homebrew 配方（Formulas）。

  • 轻量化：相比于 Homebrew 庞大的 Ruby 运行环境和复杂的依赖，zerobrew 更加精简。

  • 现代工具链：作者提到在开发过程中大量使用了 Claude 4.5 等大型语言模型辅助编写代码，是典型的"AI 辅助开发"项目。

4. 当前状态

  • 实验性（Experimental）：目前该项目仍处于早期阶段（Stage 0），虽然支持大多数核心 Homebrew 包，但某些复杂的 Formula 可能会出现问题。

  • 社区关注：该项目在 GitHub 上发布不久就获得了超过 1.4k 的 Star，在 Reddit 的 Rust 社区也引起了广泛讨论。

5. 如何尝试？

你可以通过其提供的在线脚本进行安装（需自行承担风险，建议在测试机尝试）：

[Bash]{ngcontent-ng-c2411640571=""}

curl -sSL https://raw.githubusercontent.com/lucasgelfond/zerobrew/main/install.sh | bash

安装后，原来的brew install <package>就可以改为zb install <package>。
