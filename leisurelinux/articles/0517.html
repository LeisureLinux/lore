PeaZip 10.2 发布：全面拥抱 Qt 6，性能与安全性双重进化

发布于 · 分类 安全/漏洞

PeaZip 10.2 正式发布，这一版本不仅优化了用户体验，更在底层技术架构上进行了深度迭代，特别是针对 Linux 用户的环境适配做了大量工作。

1. 技术底座升级：Qt 6 与 Wayland 原生支持

对于 Linux 用户而言，本次更新最核心的变化是 Qt 6 软件包正式取代了旧有的 Qt 5 版本。

  • 图形引擎优化：源码现基于 Lazarus 3.6 构建，提供了更好的图形渲染效率和高分屏支持。

  • Wayland 适配：Flatpak 版本现在默认原生支持 Wayland 合成器，并保留了 X11 后备方案（fallback），显著提升了在现代 Linux 桌面（如 GNOME 47+, Plasma 6）下的操作流畅度与视觉稳定性。

  • GTK 3 实验性支持：此版本还引入了 Alpha 质量的 GTK 3 二进制包，为不同桌面环境的整合提供了更多可能。

2. 核心后端更新：7z 24.09 与算法压榨

PeaZip 的强大源于其对底层工具链的高效调度：

  • 7z 后端升级：同步更新至 7z 24.09，对 LZMA/LZMA2 算法的默认字典大小进行了调整，优化了压缩比与内存占用之间的平衡。

  • 极限压缩支持：GUI 现在支持 Brotli (-q 11) 和 Zstandard (--ultra -22) 的最高等级压缩参数设置，让追求极致压缩率的技术老鸟们可以一键"压榨"硬件性能。

3. 安全加固：Hybrid KDF 混合加密重构

在安全性方面，PEA 格式更新至 1.22：

  • 混合密钥派生（Hybrid KDF）：引入了 PBKDF2 + Scrypt 的级联加密模式。这种混合 KDF 机制大幅提升了针对暴力破解（Brute-force）和字典攻击的防御成本，即便是面对昂贵的硬件加速（如 GPU 集群或专用 FPGA），其安全性也得到了质的飞跃。

4. 用户体验与文件管理微调

  • 归档异常检测：增强了对损坏包或加密问题的预警，状态栏新增"COMMENT"标记，可直接显示 RAR/ZIP 等格式的注释内容。

  • 任务逻辑优化：在任务进度对话框中，支持在压缩完成后手动选择删除源文件，逻辑更加严谨。

  • UI 统一：更新了全平台统一的应用图标，且 Linux 下的 Tux 主题 现在完美适配所有显示模式。
