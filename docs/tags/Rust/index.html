    译介 LWN 报道（Jonathan Corbet，2026-09-18）：Git 2.56 RC 已就绪（约 700 非合并 commit，主要是易用性微调与常规修复，9 月底发布）。新增 git history drop（删指定 commit 并重放后续，仍不支 merge）、git status 建议 pull、git refs create/delete/update/rename、git branch --delete-merged、git add --resolved（只加已解决冲突且扫描残留冲突标记）、配置锁失败重试等。真正重点是身后可能的 Git 3.0：一组兼容性破坏——默认 SHA-256（取代 SHA-1）、默认 reftable（替代 .git/refs 文件，解决 Android 80 万 ref 的低效）、只接受小写对象 ID（消歧义 bug/漏洞）、3.0 起把 Rust 变为构建硬要求（无 Rust 工具链平台无法升级，2.99.x 长期维护线不含 Rust）。卡点：GitHub 是最后一个缺 SHA-256 支持的 forge，但 git-merge 已演示 SHA-256 仓库。Hamano 称「既不是人气竞赛，也不是民主」。
