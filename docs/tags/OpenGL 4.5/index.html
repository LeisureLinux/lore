    SPECviewperf 15 终于出 Linux 原生版：x86_64 / AArch64 都有，但只给 OpenGL 4.5
    译介 Phoronix 报道（Michael Larabel，2026-09-22）：SPEC 在 2025 年 5 月推出 SPECViewPerf 15 作为业界标准工作站显卡基准最新大版本，首发仅 Windows；今日发布 SPECViewPerf 15.0.1 的 Linux 原生构建，相比上一个 Linux 版本（SPECViewPerf 2020）是大更新，同时提供 x86_64 与 AArch64。但 Windows 版 15 已支持 DirectX 12 与 Vulkan，Linux 版 15.0.1 仅支持 OpenGL 4.5。Larabel 将用其做后续工作站 GPU/驱动评测。解读：Linux 短板被补上但仍是二等公民（跨平台数字不可直接比，须标注 API 口径）；AArch64 官方构建让 Arm 工作站/Apple Silicon 有可复现标准图形基准；滞后根因是视图集回放 ISV 应用（Maya/SolidWorks/CATIA）真实渲染流、重心在 Windows，反映专业图形生态重心仍在 Windows；对普通用户无感，但对 NVIDIA/AMD/Intel 的 Linux 工作站驱动验证与回归测试是权威必要工具。
