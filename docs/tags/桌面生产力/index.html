    LibreOffice 26.8 正式发布：206 位贡献者合力，重点死磕排版质量、复杂文字与文档交换
    The Document Foundation 于 2026-08-26 正式发布 LibreOffice 26.8，206 位贡献者（其中 155 位志愿者）合力打磨半年。三条主线：排版质量（Writer 全新段落排版器、OpenType 变量字体原生支持、基线网格修正）、复杂文字（段落方向自动检测、RTL/CJK 调整手柄、Calc 单元格方向自适应、N'Ko/Adlam 公式支持）、文档交换（OOXML 新图表类型 box-and-whisker/funnel/Pareto/sunburst/treemap/waterfall 的保留式 round-trip、Calc 引用单元格换行修正）。同时这是首个在 Start Centre 显示捐赠横幅的版本，并明确宣布 26.8 不含任何生成式 AI 特性、零远程网络请求。
