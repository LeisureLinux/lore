    从 PSK 提取到私有引擎逆向：一次 Goodix 27c6:501d 指纹 Linux 适配的完整失败复盘
    一台 H3C 笔记本上的 Goodix 27c6:501d 指纹传感器，三天里我们把协议层完全打通：从驱动家族误判、PSK 哈希与密钥本体的区分，到用 Win11 虚机 SPICE 直通重新 provision、DPAPI 解封拿到 32 字节明文 PSK；从 usbmon 抓 Windows 真实流量修好 FDT 阈值常量，到录入成功。最后卡在匹配算法——SIGFM 分数无法区分真假手指（真 554~1845 / 陌生 1067~1091 重叠），NBIS 只有 0.38 细节点/帧。绕过它的两条路：Wine 里逆向 GoodixEngineAdapter.dll（29 导出 + 23 vtable 全解，但缺 WBDI 宿主，7 个设备接口虚函数无处实现），虚机里调 WinBio API（Windows Hello 完美工作，但 WinBioCaptureSample 被 Win11 安全策略 ACCESS_DENIED）。80×64 @ 500dpi 只有 13mm²，任何 host 侧匹配器都不可靠。这是一个有原因的、明确的放弃。
