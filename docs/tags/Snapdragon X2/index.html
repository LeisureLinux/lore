    高通在夏威夷谈 Snapdragon X2 的 Linux：早期开发者预览，Debian 13 用户态，HP/华硕承诺 2027 H1 官方支持
    译介 Phoronix 报道（Michael Larabel，2026-09-23）：高通在夏威夷 Snapdragon Summit 高调谈 Snapdragon X2 系列笔记本 Linux 支持。近月高通工程师向上游提交 X2 Elite Linux 支持、做 Device Tree 的活跃度较 X1 显著提升；高通在 Summit 宣布 X2 的 Linux 早期开发者预览(early developer preview)，用定制 Linux 内核+Debian 13 用户态，初始使能已上游化，更多工作在 Hexagon NPU 与 Mesa 的 Freedreno/Turnip(甚至 Rusticl)；电源/散热/可靠性仍有更多工作。高通博客称伙伴 HP/ASUS/HUMAIN 计划在 2027 H1 提供 X2 的 Linux 支持。解读：从社区 hack 到厂商 early preview+伙伴承诺(敢承诺=固件/驱动/电源长期维护责任)；技术栈正统开源(内核上游+Debian13+Freedreno/Turnip/Rusticl)，与 Google Android16 用 AVF/pKVM 跑 Debian VM 是笔记本原生 Linux vs 手机 Linux VM 两条线；真正考题仍是 s2idle/PCIe ASPM/调制解调器固件等最后一公里；2027 H1 可能第一次接近「买 Arm 笔记本无脑装 Linux」，此前早期预览别指望日常可靠。
