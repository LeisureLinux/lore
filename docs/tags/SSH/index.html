    万物皆隧道（续）：给香橙派接上 Cloudflare 零信任 SSH，每个访问端一张 3 分钟证书
    《万物皆隧道》续集。上一篇假设你有个公网可达入口（我家是 IPv6），这一篇解决更硬的约束：登进光猫发现 WAN 地址是 100.69.89.58，落在 100.64.0.0/10 —— 运营商 CGNAT，公网 IPv4 根本不归你，DDNS 和端口映射全部无意义。改用 Cloudflare Tunnel 出口-only 隧道 + Access 短时 SSH 证书：同一台机器三条路并存（CF 隧道 / IPv6 直通 / LAN）；每个访问端现场签一张证书，3 分钟后自动失效，没有可长期窃取的凭据。文中记录 mTLS 为何在 Free 套餐走不通（且 cloudflared 不带客户端证书参数）、用 cloudflared tunnel login 绕开 API token 权限、ingress 必须写 ssh:// 且必须配 originRequest.access.audTag（否则卡在 banner exchange）、Cloudflare 证书 principal 是邮箱前缀与本地用户名不匹配需 AuthorizedPrincipalsFile 映射、以及一个非技术坑：本机设备级过滤器专拦 Go 二进制导致 cloudflared WebSocket 卡死（python/curl 正常）。
