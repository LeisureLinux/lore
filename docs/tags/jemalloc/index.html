    省下 100 TB 内存：Cloudflare 怎么把 1.1.1.1 的 DNS 缓存条目砍到一半
    Cloudflare 的 Big Pineapple 平台同时存着 2500 亿条 DNS 缓存，1 字节/条的小浪费就是 250 GB。文章详细讲了他们用 5 步把单条内存从 953 字节压到 420 字节（−56%），整集群释放约 100 TB 内存，插入吞吐 +43%、查询延迟 −19%。改动涉及 Vec→Box<[T]>、合并三个 record 列表、CNAME 时再存 owner、按 record 类型大小拆 enum、最后用 wire format 字节存 record——每一步都顺带让 CPU cache line 更友好。本文逐条复盘 + 点评。
