# Autoconf 删除

    X.Org Server 26.1 RC1：五年来第一个特性发布，把 Xwayland 拆出去、砍掉 Autoconf、加 meson-only 构建
    X.Org Server 26.1 RC1（tag: xorg-server 26.0.99.901）是 21.1 以来第一个特性发布。本文详解五项结构性变化：Xwayland 拆分到独立仓库、Autoconf/Automake 完全删除改为 meson-only（最低 1.0.0）、约 2.1 万行遗留代码（DMX/EXA/shadow pixmap 等）清理、安全默认收紧（byte-swapped clients 与 font server 默认禁用）、项目重命名为 xorg-server；以及 Xvfb 多 CRTC + 13 按键鼠标、DPMS 1.2 DPMSInfoNotify、XFixes 6.1 AllowForceTerminate、BSD DRM platform、XDG_STATE_HOME/xorg 日志路径等具体新特性，并按打包者 / 系统管理员 / 开发者三类用户给出升级影响清单。
