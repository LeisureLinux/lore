    rspamd 把 46% 的合法邮件丢进了垃圾箱：一次从配置文件体系开始的排查
    自建邮件网关（Debian 12 + postfix + dovecot + rspamd 4.2）误判排查实录：归档统计显示合法邮件被误投 Junk 的比例达 46%。根因是五个叠加问题，前三个属于「配置体系被破坏」而非「规则不够多」：①/etc/rspamd/options.inc 被替换成 25 行精简版（原件 93 行），丢掉了 filters = "chartable,dkim,regexp,fuzzy_check" 一行；rspamd 官方文档明确 C 模块仅由 filters 属性启用，未定义则全部禁用，于是 DKIM 这个静态编译进 librspamd-server.so 的 C 模块从未注册，R_DKIM_ALLOW/NA/REJECT 不存在，导致 WHITELIST_DKIM、WHITELIST_SPF_DKIM、WHITELIST_DMARC、TRUSTED_NEWSLETTER_PASS、DMARC_CHECK、NO_AUTH_SPOOF 六条规则静默失效（configtest 仍报 syntax OK）。同一文件还丢失 dns{timeout/sockets/retransmits} 与 local_addrs，实测 rspamd 日志每天 1304 次 query timed out，扫描耗时 4136ms。②override.d/policies_group.conf 是 priority=10 严格覆盖语义（整段替换而非逐键合并），28 行版本漏掉全部 6 个 R_DKIM_* 符号权重。③FORGED_SENDER（envelope 与 header From 不同即 +5.0）对 ESP 正常行为开枪：语料中 1785 封「信封域与信头域不同但同源」的邮件全部合法、零垃圾，而 rspamd 内置的 ENVFROM_PRVS 只认 prvs=/btv1==/msprvs1= 三种格式、实测 0 命中。④force_actions 的 BLOCK_SPOOFED_LOCAL_DOMAIN 表达式 FORGED_SENDER & !DMARC_POLICY_ALLOW & !R_SPF_ALLOW 完全不含本地域判断，硬拒 22 封合法 lists.debian.org 邮件（freelamp.com 只是 VERP 标签）；且 force_actions 不认 enable=false，只能整块注释。⑤Dovecot Sieve 用 X-Spam: Yes 判据，而该头由 milter_headers 依据「动作不是 no action/greylist」生成，实际阈值是 actions.conf 的 add_header=6 而非 reject=15，6~15 分区间被压成二元判断。修复后误判 46%→6%，扫描 4136ms→611-1236ms。附回归方法论：dovecot-keywords 每文件夹独立映射（同一字母 INBOX 为 NonJunk、.LinkedIn 为别的含义）、重扫破坏 DKIM 签名（Maildir 是 LF 非 CRLF）、rspamd 重扫会读到自身上次写入的 X-Spam 头触发 SPAM_FLAG 再 +5.0。
