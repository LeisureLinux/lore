    libzmq 支持了 VSOCK：ZMQ 应用从此可以跑进 Hypervisor 通信面
    AF_VSOCK 是专为 guest 与 hypervisor/host 通信设计的套接字地址族（Linux 4.8+，前身 VMware VMCI），AWS Nitro Enclaves 靠它通信。Rémi Jouannet 给 libzmq 提交 PR #4822 补上 vsock 传输（照 VMCI 代码复制粘贴级别），并 fork pyzmq 提供 pyzmq-vsock 轮子。所有 ZMQ 绑定语言由此解锁 AF_VSOCK，req/rep、pub/sub 与 Curve 认证全部继承。本文为原文译文，附 loopback Hello World 与 Curve+asyncio 实操，以及通信面隔离、传输与语义解耦、国产虚拟化 guest agent 参照的解读。

    Broadcom 下架 VDDK 下载：离开 VMware 的退路被堵，企业需要哪些 Plan B？
    2026 年 9 月 7 日，Broadcom 悄然停掉了 VMware VDDK（Virtual Disk Development Kit）的公开下载，原链接全部 404，且无任何官方公告、弃用声明或替代方案。VDDK 看似小众，却是 Azure Migrate、Red Hat MTV、Nutanix Move、virt-v2v、nbdkit 等几乎所有第三方迁移工具的核心依赖。本文梳理 ShapeBlue、Red Hat、Microsoft、Nutanix、Platform9 的连锁反应，点评这一举动背后的供应商锁定（vendor lock-in）信号，并给出分场景的 Plan B 与企业选型建议。
