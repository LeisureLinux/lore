    一条被污染的 strip：为什么可复现构建挡不住它
    Ken Thompson 1984 年图灵奖演讲提出的「信任的信任」攻击，长期被默认是编译器的专利。这篇论文用 GNU strip——一个既不读源码也不生成源码的普通构建工具——证明事实并非如此：在 NixOS 的 bootstrap 里，只需替换二进制种子中的一个 strip，就能让后门逐代自我传播，最终在真实 nixpkgs 上后门掉 3790 / 3799 个 ELF 二进制，而源码自始至终保持干净。本文翻译解读论文，并重点回答两个反直觉的问题：为什么 reproducible builds（可复现构建）防不住工具链自身被污染？以及攻击者如何产出一个「通过可复现验证」却已被污染的二进制。
