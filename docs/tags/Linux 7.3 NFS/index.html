# Linux 7.3 NFS

共 1 篇文章

    Linux 7.3 NFS 改进：客户端 / 服务端双向发力——服务端目录委派、客户端 I/O 优化、NFSv4.2 缓存控制
    Linux 7.3 合并窗口接近关闭，NFS 客户端与服务端 pull request 都已合入。服务端（NFSD）这一波最重磅：支持 NFSv4.1 目录委派（CB_NOTIFY 回调 + FSNOTIFY），同时把传统服务线程池换成 per-node 模型；客户端（NFS）这一波以 bug fix 为主，亮点是 NFS/localio 的 I/O 提交优化与 NFSv4.2 新增'禁止客户端缓存'语义。本文详解服务端 200+ 文件 / 6000+ 新增行、客户端 100+ 修复的所有具体改动、运维升级建议与下一个版本的关注点。
