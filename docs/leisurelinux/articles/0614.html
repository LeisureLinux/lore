2026年第4周（1月19日至25日） - Linux 和开源新闻周报

发布于 · 分类 AI/Agent

核心内容摘要：\

1. 重点发行版更新

* MX Linux 25.1：发布了新的 ISO 镜像，支持双初始化（Dual Init）系统。

* CachyOS 2026年1月版：重构了安装程序，并默认采用 Wayland 协议。

* GNU Guix 1.5：带来了 Plasma 6.5、GNOME 46 以及"无根模式"（Rootless Mode）等多项更新。

* Deepin 25.0.10：对文件管理器和安装程序进行了改进。

\

2. 软件及内核工具

* GIMP 3.0.8：主要针对核心功能、工具和插件进行了错误修复。

* COSMIC Desktop 1.0.3：System76 开发的新桌面环境，更新了文件管理器的多项改进。

* Wine 11.1：发布了首个开发版，包含 22 个针对应用和游戏的修复。

* Bottles 61：引入了名为 \"Eagle\" 的新功能，将其转型为分析工具。

* Glibc 2.43：发布并支持 ISO C23 特性，提升了性能。

* 其他更新：包括 Hyprland 0.53.2（改进插件处理）、Raspberry Pi Imager 2.0.5（提升 CLI 易用性）以及 Ntfy 2.16 等。

\

3. 值得关注的新闻与深度内容

* Windows 转 Linux 推荐：文章推荐了适合从 Windows 迁移过来的 Linux 发行版。

* 安全警示：提醒 Snap 用户注意，有攻击者利用旧的信任应用推送恶意软件。

* ReactOS 30周年：庆祝这个旨在兼容 Windows 的开源系统走过了 30 年。

* AerynOS 抵制 AI：出于伦理和环境成本考虑，该发行版宣布禁止在其开发中使用大语言模型（LLM）。

* DAXFS：提议将一种新的零拷贝共享内存文件系统引入 Linux。

\

4. 硬件动态

* Slimbook Executive：一款仅重 1.2kg 的轻便 Linux 笔记本，搭载了 Intel Core Ultra 7 处理器。

* Arduino UNO Q：一款结合了 Linux 和实时微控制器的混合单板机（SBC）。
