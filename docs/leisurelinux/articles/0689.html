🤯 技术冷思考：PID 0 到底是谁？

热度：👍 551 | 👁️ 3.1万+

技术圈今天因为 \@IceSolst 的一个讨论炸开了锅：为什么有的 Linux Oops（系统惊恐）进程显示 PID 为 0？

大家都知道 PID 1 是 init，那 PID 0 呢？其实它是 swapper（或称 idle 进程）。它不由内核启动，而是内核的一部分。当 CPU 闲得发慌时，就是它在维持呼吸。这场关于底层进程的"技术趣谈"，让不少老架构师都直呼：基础知识该复习了！
