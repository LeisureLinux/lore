网络神器更新！Wireshark 4.6.3 发布：修复多项崩溃，协议支持再进化

发布于 · 分类 Linux/运维

🚀 概述\ 作为全球最受欢迎的网络协议分析工具，Wireshark 近日正式发布了 4.6.3 稳定版。这是 4.6 系列的第三个维护版本，重点在于提升软件稳定性、修复严重的崩溃风险，并进一步扩展了对现代网络协议的支持。

\ 🛠️ 核心更新要点\ * 协议支持深度优化：\   新版本对大量现有协议进行了精准修复。包括互联网通用的 HTTP3、DNS、TCP、SSH，以及移动通信领域的 5G NAS (NAS-5GS)、LTE RRC。此外，针对工业与车载协议如 SOME/IP-SD、ISObus VT 也做了重要改进。\ * 捕获文件兼容性增强：\   提升了对多种第三方抓包格式的支持，包括 3GPP TS 32.423 Trace、BLF (Binary Logging Format) 以及 NetScreen 等，跨平台协作更加顺畅。

\ * 关键 Bug 修复：\   解决了在解析 BLF 文件和 IEEE 802.11 协议时可能导致的崩溃问题，并修复了 HTTP3 解析中的死循环 Bug。

\ 💻 平台与下载\ * Linux 用户： 建议通过所属发行版的官方仓库更新，或从源码编译安装。\ * macOS 用户： 提供 Universal Installer，原生支持 Intel 及 Apple Silicon (M1/M2/M3) 芯片。\ * Windows 用户： 默认搭载最新的 Npcap 1.83（注意：官方已不再支持旧版 WinPcap）。
