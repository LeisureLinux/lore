2026 年了，做视频还要充 700 块的剪映会员？

发布于 · 分类 AI/Agent

这 6 个开源工具，每个都能把你的 AI Agent（Claude Code、Cursor、OpenClaw）变成视频生产线。免费。

今年做视频这件事彻底不一样了。

以前想做个像样的片子：先写脚本、找素材、剪半天、调色、加字幕、导出......一套下来半天没了。不想折腾？剪映 VIP 一年 700 多，pro 会员更贵。

但现在，你只需要装 6 个东西。把它们接到你的 AI Agent 上，说一句「帮我做个产品介绍视频」，它自己就干了。

我把链接和安装命令都整理好了。拿走照着装就行。

━━━ ━━━ ━━━

🤖 什么是 AI Agent 做视频

先简单说一下这玩意儿怎么用。

你平时写代码可能会用 Claude Code、Cursor 或者 OpenClaw。它们本质上是能听懂人话的编程助手（Agent）。现在这些 Agent 不仅能写代码，还能装插件（Skills）来剪辑视频。

流程就是：

你说一句话 → Agent 拆解成任务 → 调用视频工具 → 出片

不用自己打开剪辑软件、不用拖拽时间线、不用背快捷键。

━━━ ━━━ ━━━

1️⃣ HyperFrames --- 说一段话，出来一个 MP4

GitHub： heygen-com/hyperframes

⭐ 31,978

官方文档： hyperframes.heygen.com

这玩意的工作方式很直接：你的 Agent 写完 HTML + CSS/JS 动画代码，它负责渲染成 MP4 视频。

它不是「录屏」，是把代码跑出来的动画一帧帧合成视频文件。没有分辨率损失，没有编码兼容问题，出来的就是干净的视频。

适用场景：产品介绍视频、动态数据展示、motion graphics、演示动画。

安装

# 在 OpenClaw / Claude Code / Cursor 中执行
npx skills add heygen-com/hyperframes

# 想一次性装全部 19 个子 skill
npx skills add heygen-com/hyperframes --all

装完之后跟你的 Agent 说：「用 HyperFrames 做一个 30 秒的产品发布视频，风格简洁科技感。」它就会自动写代码、渲染、输出 MP4。

━━━ ━━━ ━━━

2️⃣ FFmpeg --- 底层王者，所有视频工具都靠它

官网： ffmpeg.org

严格来说 FFmpeg 不是一个「功能」，而是每个视频工具底层都在用的命令行引擎。

剪辑、格式转换、压缩、提取音频、加字幕、拼接、调分辨率......你说得出来的视频操作，它都能干。HyperFrames、Video-Use 这些工具内部都依赖它。

安装

系统级安装（推荐先装这个，后面装其他工具才不会报错）：

# macOS
brew install ffmpeg

# Windows
winget install Gyan.FFmpeg

# Debian/Ubuntu
sudo apt install ffmpeg

Agent Skill（让 AI 直接调用）：

npx skills add fabriqaai/ffmpeg-analyse-video-skill

装完后你可以跟 Agent 说：「把这个 4K 视频压到 1080p，去掉前 5 秒的黑场，加硬字幕。」

━━━ ━━━ ━━━

3️⃣ OpenMontage --- 把你的 Agent 变成一整个视频制作团队

GitHub： calesthio/OpenMontage

⭐ 27,034

自称「世界上第一个开源的 agentic 视频生产系统」。这话听着有点大，但看它吹的配置------12 条 pipeline、52 个工具、500+ agent skills------确实有点东西。

它做的事是：把你的 Agent（比如 Claude Code）变成一个从研究到产出全包的视频制作团队。

具体来说，你丢一个主题进去，它自动：

  1. 做调研，找资料
  2. 写脚本、画分镜
  3. 生成所需素材（图片、插图、BGM）
  4. 剪辑、拼接、合成
  5. 输出最终视频

安装

git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
pip install -r requirements.txt

然后在你的 Agent 配置中指向 OpenMontage 的 workdir，剩下就是告诉它：「帮我做个 3 分钟的 Vlog，主题是今天写的代码。」

4️⃣ Remotion --- 用 React 写视频，开发者狂喜

官网： remotion.dev

GitHub： remotion-dev/remotion

⭐ 51,547

Remotion 的思路跟前面的不太一样------它让你用 React 组件来写视频。

每一个帧都是一个 React 组件的截图。你写 、、，它渲染成视频。

这对开发者来说太自然了。想做个批量出片的模板？写一个 React 组件，传不同的 props 进去，一次渲染 N 个版本。适合：产品 Demo 批量生成、课程视频、数据可视化视频。

安装

# 安装 Remotion Skills 到 Agent
npx skills add remotion-dev/skills

# 创建项目
npx create-video

装完之后跟 Agent 说：「用 Remotion 帮我生成 10 个产品介绍视频，数据从这个 JSON 读。」

━━━ ━━━ ━━━

5️⃣ Video-Use --- 把 raw footage 丢进去，跟 Agent 聊天就能出片

GitHub： browser-use/video-use

⭐ 11,093

Browser Use 团队出品。如果你用过 browser-use（那个让 AI 操控浏览器的项目），Video-Use 的体验应该很熟悉。

用法简单粗暴：

  1. 把原始素材丢进一个文件夹
  2. 打开 Agent，跟它聊天
  3. 出来一个 final.mp4

它能自动去 filler words（呃、那个、然后这种语气词）、加字幕、调色、配 BGM。如果要叠加动画效果，还能调用 HyperFrames、Remotion 或者 Manim 来做 overlay。

安装

git clone https://github.com/browser-use/video-use.git
cd video-use
pip install -r requirements.txt

然后跟你的 Agent 说：「Video-Use 文件夹里放了今天录的 3 段素材，帮我剪成一个 2 分钟的教程，自动去掉废话，加中文硬字幕。」

━━━ ━━━ ━━━

6️⃣ Manim --- 数学动画引擎，3Blue1Brown 同款

官方社区： manim.community

GitHub： 3b1b/manim

如果你是搞技术科普或者知识类视频的，Manim 你应该知道。3Blue1Brown 那些让人看呆的数学动画，就是用 Manim 写的。

现在有 Agent 专用的 Manim Skill，你描述一个概念，它自动生成对应动画。

安装

# Agent Skill
npx skills add adithya-s-k/manim_skill/skills/manimce-best-practices

装完之后跟 Agent 说：「用 Manim 做一个二分查找的动画演示，从数组中间开始找，每一步高亮当前元素。」

后记： 我写这个不是为了说服你别用剪映。剪映很好用，它的模板库和智能抠像确实能打。但如果你发现自己每次都在做重复的操作------加同样格式的字幕、同样的转场、同样的调色方案------那也许到「写脚本出片」的时候了。这 6 个工具，不需要全装。从你最常做的那种视频开始，装一个对应的，试一次，你就知道值不值。
