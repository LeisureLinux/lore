【新版发布】轻量级代码托管神器 Forgejo v14.0 来袭！告别 JS 依赖，告别数据库死锁

未知日期 Linux/运维 阅读原文（微信）↗

各位开发者、自托管爱好者们：就在刚刚，备受期待的轻量级、社区驱动自托管协作平台[Forgejo v14.0]{textstyle=""}正式发布了！作为 Gitea 的社区分支，Forgejo 一直在"社区优先"和"轻量可靠"的道路上硬核迭代。这次 v14.0 版本不仅提升了日常开发的爽感，更在底层稳定性上动了大手术。[想了解更多 Linux 与开源硬核技巧？记得关注 B 站同名频道：LeisureLinux！]{textstyle=""}下面我们来看看这次更新有哪些绝对不能错过的亮点。

1. 搜索进化：Issue/PR 搜索支持"极简语法"

以前在海量 Issue 中找东西全靠肉眼？现在 Forgejo 引入了简单的[行内过滤语法]{textstyle=""}。 你可以直接输入 is:open author:administrator 来精准定位。配合原本的下拉筛选，效率直接起飞。

2. 编辑器大换血：告别笨重的 Monaco

虽然微软的 Monaco 编辑器功能强大，但对于网页单文件编辑来说太重了。[v14.0 正式切换到了更轻量的 CodeMirror。]{textstyle=""}加载更快、性能更强、对移动端更友好。手机临时改个 Bug，再也不用担心浏览器卡死了。

3. 极客精神：更强大的"无 JS"体验

在 JS 膨胀的时代，Forgejo 坚持对隐私和极致简洁的追求。 新版本进一步增强了[无 JavaScript 模式]{textstyle=""}下的功能：现在不开启 JS 也能正常发布评论。导航栏的用户菜单、各种功能省略号菜单，在禁用 JS 的情况下依然能丝滑操作。

4. Actions 自动化：更细、更强、更智能

Forgejo Actions 在此版本迎来了史诗级增强：[信任管理：]{textstyle=""}针对外部 PR 的 Actions 执行，新增"批准一次"、"始终批准"或"拒绝"选项，安全尽在掌握。[并发控制：]{textstyle=""}支持 concurrency 配置，防止重复任务浪费你的服务器资源。[排队可见性：]{textstyle=""}如果任务在等待特定的 Runner，界面会直接显示原因，告别盲目等待。

5. 数据库大扫除：告别"负数 PR"玄学

很多老用户遇到过 repo 显示有 "-1" 个 PR 的奇葩 Bug。[v14.0 彻底优化了底层逻辑，将死锁概率降到了近乎零。]{textstyle=""}同时官方提供了 forgejo doctor cleanup-commit-status 工具。在大型实例测试中，它清理了高达[97%]{textstyle=""}的冗余记录，大幅缩减数据库体积。

6. 安全加固：无状态 CSRF 防护

新版采用了全新的无状态 CSRF 防护方案。[好处是什么？]{textstyle=""}你可以把 Forgejo 页面挂在浏览器里好几天，回来直接提交依然有效，再也不会因为 Token 超时导致辛苦写的代码丢失。

⚠️ 升级指南（必读）

[备份先行：]{textstyle=""}升级前请务必按照官方指南进行全库备份。[数据库迁移：]{textstyle=""}升级到 v14 会自动建立"外键约束"，Forgejo 会自动识别并清理数据库中的脏数据，无需人工干预。[SSH 校验：]{textstyle=""}如果你使用 authorized_keys 文件，Forgejo 启动时会进行安全扫描，发现异常 Key 会自动停机报警。
