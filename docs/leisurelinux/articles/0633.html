30岁、夜班、月薪过万：我是如何用4个月实现薪资 2.5 倍逆袭的？

发布于 · 分类 Linux/运维

\ 作者：Akhilesh Mishra\ 编译：LeisureLinux

01 舒适区，正在杀死我的职业生涯几年前，30 岁的我，正陷在一种"体面的贫穷"里。我在一家美资跨国公司做 Linux 技术支持（Support）。听起来名头响亮，实则是一场慢性自杀：常年黑白颠倒的夜班，拿着远低于行业水平的薪水（工龄 9 年，年薪仅 13 LPA，约合 11 万人民币）。每当看到同龄人在职场阶梯上快步攀升，而我却在枯燥的工单中打转，这种反差让我感到窒息。更糟糕的是，常年的熬夜让我的身体彻底垮了：

  • 严重的胃食管反流
  • 长期抑郁
  • 甚至出现了恐慌发作（Panic Attacks）

那时我才意识到：所谓的舒适区，其实是一座温水煮青蛙的坟墓。

02 命运的临界点转折点出现在我结婚后。身份的转变带来了巨大的财务压力：家庭的担子、贷款的重压、妻子对未来的期待。我开始陷入更深的焦虑------我害怕裁员，因为除了基础的运维支持，我几乎没有拿得出手的硬技能。那天深夜，在又一次失眠后，我对着镜子告诉自己：

"If you change nothing, nothing will change."\ （如果你不改变现状，现状就永远不会改变。）

我锁定了当时的职业红口：DevOps 工程师。\

\

03 破釜沉舟：我的 4 个月通关计划DevOps 的学习路线图极其复杂，各种工具层出不穷。我没有选择盲目乱抓，而是选择了**"极简主义学习法"**：第一步：精简清单，只学核心我强制自己只关注这几个关键技术栈：

  • 云平台：AWS
  • IaC（基础设施即代码）：Terraform
  • 容器化：Docker & Kubernetes
  • CI/CD：Jenkins / GitHub Actions
  • 配置管理：Ansible
  • 脚本：Python & Bash

第二步：断绝社交，卸载所有 App为了挤出时间，我卸载了 Instagram 和所有社交软件。

"想要得到以前得不到的东西，就必须付出以前从未付出的努力。"

我每天下班后强迫自己学习 4-5 小时，经常在桌前坐到凌晨 6 点。第三步：模拟实战，复刻经验我深知面试官不看理论，只看解决问题的能力。我亲手完成了 5 个实战项目：

  • 用 Terraform 自动化部署 AWS 三层架构
  • 利用 GitHub Actions 将 Flask 项目打包镜像并部署
  • 编写 Ansible Playbooks 自动构建自定义镜像
  • 在 AWS ECS 上部署 API
  • 深入攻克 Kubernetes 的生产环境实践

04 蜕变：从挫败到 5 个 Offer最初的面试极其惨烈。我被问得哑口无言，那些只有资深 DevOps 才会遇到的场景题让我原形毕露。但我没允许自己沮丧。我把每次失败的题目记下来，回去钻研、实验，直到把它变成自己的技能。在第 4 个月，量变终于引起质变。我连续收到了 5 家公司的 Offer，其中不乏业内知名企业。最终，我入职了一家薪资直接翻了 2.5 倍 的公司，还拿到了一笔丰厚的签字费。

05 写在最后现在的我，生活彻底变了样：

  • 告别了夜班，拥有了规律的作息
  • 周末双休，终于能有时间陪妻子去旅游
  • 那些折磨我的胃病和焦虑症，竟然不药而愈

如果你也觉得自己被困在了毫无前途的岗位上，请记住：迈出第一步永远是最难的，但也是最重要的。不要再在短视频里消磨时间了，去学习、去实验、去犯错。改变，就从今天开始。
