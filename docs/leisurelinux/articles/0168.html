⚡ Linux 7.1 合入 AMD Dynamic EPP 修复与 Intel Bartlett Lake 缩放修复

Linux 7.1 合入了关键的电源管理修正。针对 AMD 平台，此前用于动态调整能量性能偏好（Energy Performance Preference）的Dynamic EPP功能因在部分场景下存在缺陷，已从 Kconfig 编译期硬编码中移除，现变更为通过内核启动参数amd_pstate=dynamic_epp=1手动启用。针对 Intel 平台，紧急修复了 P-State 驱动在 Bartlett Lake（纯大核架构）上错误报告7GHz主频的 Bug，并修正了 Raptor Lake E 系列 CPU 的缩放因子（Scaling Factor）。

🔮 AMD PMC 驱动为 Zen 6 做准备

AMD 针对下一代Zen 6架构的指令基于采样（IBS, Instruction-Based Sampling）以及电源管理控制器（PMC, Power Management Controller）进行了早期前瞻性代码提交。此次更新主要聚焦于新型硬件中断处理及低功耗状态（S2Idle）下的挂起/唤醒行为优化，确保新架构在 Linux 下的开箱即用表现。

🎮 AMDGPU 支持更完善的 GPU 计算挂起恢复（管道复位）

在 Linux 7.1 中，AMDGPU 驱动针对高性能计算（HPC）及机器学习加速场景，对SDMA（系统直接内存访问）引擎进行了多轨并行优化。重点强化了在 GPU 计算任务挂起或遭遇硬件异常时的管道复位（Pipe Reset）能力，避免单次计算崩溃导致整个操作系统内核挂起，提升了无头服务器（Headless Server）环境的鲁棒性。

🚀 LLVM 提出 Multi-Thread Parallel Compilation (MTPC) 方案

LLVM 社区发布了关于ThinLTO的重要 RFC。传统的模块内（Intra-module）优化与代码生成基本是单线程串行的，这导致在分布式编译体系中，超大文件的编译往往成为木桶效应中的最长板。MTPC 方案通过调用图感知（CallGraph-aware）切分算法，将单个超大模块在 IR（中间表示）层面切分为多个 SCC 子模块进行多线程并行后端优化（Opt）与代码生成（CodeGen），极大榨干高核数编译服务器的算力。

🏭 系统 & 软件

🏗️ systemd 261-rc1 发布

作为重量级测试版本，261-rc1 引入了多项颠覆性的底层子系统：

  • systemd-sysinstall：一个原生的文本模式 OS 安装器，深度封装了 systemd 的分区管理和凭据分发机制。
  • systemd-imdsd：实例元数据服务守护进程，内置主流公有云（AWS, Azure, GCP, Oracle 等）的硬件数据库，用于运行环境的自动识别。
  • storagectl：全新的存储控制 CLI 工具，包含对软 vTPM 的回退支持。
  • 内核热更新支持：PID 1 增加了对 Linux 内核 Live Update Orchestrator 和 Kernel Handover（内核交接）的直接原生支持。

💎 OpenCL 3.1.1 发布

主要为维护与修正版本，重点修复了此前版本中因某些特定的内存屏障（Memory Barrier）和缓冲区同步逻辑导致的计算性能回退（Performance Regression）Bug，确保了异构计算的稳定性。

🦊 Firefox 修复 Intel Raptor Lake CPU 上的崩溃问题

Firefox 官方终于合并了针对 Intel Raptor Lake（第 13/14 代）处理器上持续了一年多的特定指令集执行崩溃补丁。该问题多发于长周期垃圾回收（GC）及密集型 JIT 编译时，本次修复通过调整底层内存对齐和特定线程挂起机制彻底平息了该故障。

🔧 硬件 & 芯片

💻 HP 承诺支持 LVFS（Linux 固件服务）

继 Lenovo 和 Dell 长期支持之后，HP 终于宣布全面接入LVFS（Linux Vendor Firmware Service）。这意味着未来的 HP 企业级服务器、工作站以及部分商用 PC 的 BIOS 和组件固件，均可通过 Linux 原生的fwupd工具链进行安全的生产环境在线更新。

🧠 Nvidia Vera CPU 预计在 FY2027 出货 400 万颗

根据华尔街证券分析师的最新简报，NVIDIA 独立Vera CPU（基于 88 核自研 Olympus ARM 架构）的市场潜力巨大。NVIDIA 官方表示此款专为智能体 AI（Agentic AI）和长上下文状态管理打造的处理器将切入一个价值 2000 亿美元的全新市场（TAM）。目前第一批主机架已手递手交付至 OpenAI 和 Anthropic 等巨头，预计其出货量和高达 \$5000--\$8000 的客单价将直接冲击传统 x86 在 AI 算力中心的主机控制权。

🔬 ASML High-NA EUV 仍未就绪大规模量产

供应链消息指出，ASML 售价达 3.8 亿美元的High-NA EUV（高数值孔径极紫外光刻机）在晶圆吞吐量（Throughput）及光源稳定性上仍需调优，目前的缺陷率（Yield Impact）尚未达到晶圆厂全面切入主流节点大规模量产（HVM）的标准，2nm 以下工艺的全面铺开节点恐将顺延。

🇨🇳 中国 CXMT DDR5 进入 Corsair 内存条

面对全球服务器及消费级 LPDDR5/DDR5 的严重短缺（尤其由于 NVIDIA Vera 处理器对高带宽、大容量 SoCAMM 内存的虹吸效应），长鑫存储（CXMT）的高品质 DDR5 颗粒已成功切入美商海盗船（Corsair）的供应链。这不仅缓解了 DRAM 供应链的全面吃紧，也标志着国产存储在高频高密度内存市场的商业化合规更进一步。

🤖 AI 动态

⚔️ Anthropic & OpenAI 72 小时内密集发布

两大 AI 头部阵营在过去 72 小时内连续对轰，密集发布了新一代大模型能力更新以及开发者工具链更新。资本市场高度关注其在 Agent 落地、工具调用（Tool-calling）以及多模态推理成本方面的红海竞争。

🛠️ JetBrains 主打 AI 编码工具独立性

在最新的战略发布中，JetBrains 强调了其 AI 编码辅助工具的基础设施独立性（Vendor Agnosticity），支持企业客户在本地或合规云端自由切换底座大模型（LLM Backend），以此规避单一云厂商的数据泄露风险。

🔁 AI/LLM 驱动的修复大批涌入 Linux 网络和声音子系统

由于 LLVM、网络栈以及音频驱动（如 ALSA/Soundwire）涉及大量的长尾静态缺陷，近期由 AI 自动生成的内核补丁（经工程重构与静态分析验证）呈现井喷态势。尽管由于代码质量参差不齐引起了内核社区维护者的严格审视，但智能化静态修复（Automated Patching）已实质性深度介入 Linux 核心子系统的演进。
