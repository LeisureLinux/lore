📰 Phoronix

核心亮点深度解读

  • •Google ANGLE 成功合并 Wayland 原生支持，彻底扫清 Chromium 生态在 Linux 下的运行障碍
  • • Google 的 ANGLE（用于将 OpenGL ES 调用转换为其他硬件 API 的转换层）现已正式合并了 Wayland 后端代码。这意味着基于 Chromium Embedded Framework (CEF) 运行的成千上万款 Linux 桌面应用（如 Spotify、Discord 等），未来无需再通过缓慢且容易产生渲染瑕疵的 XWayland 兼容层，即可在现代 Linux 桌面（如 GNOME、KDE 的 Wayland 会话）中实现原生、零延迟的硬件加速渲染。
  • •NVIDIA \"Vera\" 数据中心 CPU 基准测试流出：Olympus 架构斩获 ARM 史上最强性能
  • • 最新曝光的测试数据显示，NVIDIA 代号为 \"Vera\" 的下一代数据中心 CPU（采用自研 Olympus ARM 核心）在多线程服务器基准测试中展现出惊人的吞吐量。该芯片不仅刷新了 ARM 架构的单核与多核性能上限，其每瓦特性能更是直接对标并部分超越了 Intel 与 AMD 最新的顶级 x86 数据中心处理器，标志着英伟达在完全摆脱 x86 依赖、构建自研算力闭环上迈出关键一步。
  • •后量子加密（PQC）补丁提交 Linux 内核：Google 密码学专家推动 ML-KEM 与 X-Wing 落地
  • • 由 Google 顶尖密码学专家 Eric Biggers 主导，ML-KEM（基于格的密钥封装机制）和 X-Wing（混合后量子密码学组合）的算法补丁已正式提交至 Linux 内核邮件列表。这一举措旨在为 Linux 内核层提供抵御未来量子计算机攻击的能力。随着这些补丁并入，Linux 将在底层网络和存储加密中率先具备"抗量子"的安全防护。

  • •Pavona 开源芯片生态启航：由 GlobalPlatform 发起，Meta、高通、Tenstorrent 及牛津大学等业界巨头联合参与的 Pavona 项目正式宣告成立。该项目旨在打造一个"认证就绪"的开源硅片（Open-source Silicon）生态系统，降低定制化芯片的合规与设计门槛。
  • •NVIDIA 发布 610.43.02 Linux 驱动：新版驱动重点改进了 Vulkan 扩展支持，并初步引入了对 Linux DRM Color Pipeline API 的兼容，为 Linux 桌面用户带来更完善的 HDR 颜色管理支持。
  • •Intel 推出 pmtctl 工具：该工具专门用于在 Linux 环境下读取和管理 Intel 处理器的"平台遥测数据"（Platform Telemetry），方便数据中心运维人员更精准地监控硬件 health 与能耗。
  • •Btrfs 文件系统将支持 Huge Folios：该特性已准备就绪，预计将随 Linux 7.2 内核一同发布，能够显著减少大文件读写时的内存页表开销，提升大容量存储的 I/O 性能。
  • •Meta 时隔两年重启 CacheLib 更新：面对近年来高企的 DRAM 内存价格，Meta 重新激活了开源缓存引擎 CacheLib 的版本迭代，重点通过"缓存卸载（Cache Offloading）"技术，将内存数据智能转移到更便宜的非易失性存储（如 NVMe SSD）中，以降低数据中心成本。
  • •Labwc 0.20 Wayland 合成器发布：这款基于 wlroots、主打轻量且神似 Openbox 的合成器迎来了 0.20 迭代，修复了大量多显示器管理 Bug 并增强了配置文件的灵活度。
