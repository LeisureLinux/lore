Libvirt 12.0 正式发布：全面加强 BSD 虚拟化！附保姆级 libvirt 进阶视频全集

发布于 · 分类 Linux/运维

摘要： 开源虚拟化管理利器 Libvirt 迎来 12.0 大版本更新！除了 Bhyve ARM64 支持和快照上限突破，我们还为你整理了 LeisureLinux 频道的硬核 libvirt 系列教程。\

\

正文：\

就在今日（2026年1月15日），作为开源社区最核心的虚拟化管理 API 库，Libvirt 正式发布了 12.0 版本。

Libvirt 一直是连接不同虚拟化技术（如 KVM, QEMU, Xen, Virtuozzo, VMware ESX 等）的"通用接口"。而在最新的 12.0 版本中，开发团队将大量的精力投入到了 FreeBSD Bhyve 管理器的增强以及 QEMU 管理的优化上。

\

以下是本次更新的核心亮点：

1. Bhyve 虚拟化：ARM64 时代开启

对于使用 FreeBSD 作为宿主机的用户来说，Libvirt 12.0 带来了里程碑式的更新：

* 支持 ARM64： 现在可以在 ARM64 宿主机上启动 ARM64 架构的虚拟机域。

* 网络与存储增强： 引入了对 SLIRP 网络的支持，并增加了 VirtIO-SCSI 设备支持，显著提升了 Bhyve 在 BSD 环境下的易用性。

\

2. QEMU 管理：告别"25个快照"上限

在之前的版本中，受限于 json-c 库在解析 JSON 时的某些限制，管理拥有超过 25 个外部快照（External Snapshots）的虚拟机时常会出现启动失败的问题。

* 200层镜像链： Libvirt 12.0 成功攻克了这一难题，目前已支持处理深达 200 层的镜像链，极大增强了大规模快照管理的能力。

* 固件选择优化： 改进并修复了 QEMU 的固件选择逻辑，确保引导过程更加稳定。

* 网络代码优化： 为 DNS 转发器添加了专用端口支持。

\

3. 其他关键改进

* 依赖库更新： 持续优化与底层库（如 json-c）的协作，提升解析效率。

* Bug 修复： 修复了多项涉及网络代码、状态保存及跨平台兼容性的已知问题。

\
