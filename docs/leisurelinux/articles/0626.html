【Github项目】 Zaku API 测试客户端

发布于 · 分类 Linux/运维

Zaku（https://github.com/buildzaku/zaku）是一个开源的、跨平台的桌面API 客户端，主打"快"和轻量级体验，slogan 是 \"with fangs\"（带点獠牙的感觉，暗示比较锋利/迅猛）。简单来说，它就是又一个桌面版的 HTTP/API 测试工具，类似 Postman / Insomnia / Hoppscotch 的桌面替代品，但使用更现代的技术栈，体积更小、启动更快。核心特点

  • 跨平台：macOS（Apple Silicon + Intel）、Windows、Linux 都有原生包
  • 技术栈：Tauri（Rust 后端 + Web 前端）+ Svelte + TypeScript + Vite
    • Rust 占比 ≈55%，Svelte ≈30%，非常典型的轻量 Tauri 应用
  • 开源协议：MIT
  • 定位：追求极致速度和简洁的 API 调试工具（yet another，但走轻量路线）

安装方式（最新版本 v0.8.1，2025年9月）

  • macOS：下载 .dmg（有 Arm 和 x86 两个版本），安装后要运行一次命令解除隔离：bash

    xattr -c /Applications/Zaku.app

  • Linux：

    • .deb 包（Ubuntu/Debian）：sudo apt install ./zaku-xxx.deb
    • Snap：sudo snap install zaku

  • Windows：直接双击 .exe 或 .msi 安装

当前状态（截至2026年1月）

  • Stars ≈ 248
  • Forks ≈ 10
  • 已经发了 9 个 release，开发还算活跃
  • 社区讨论和 issue 量都不算很大，属于小而美的个人/小团队项目

一句话总结：\ 如果你觉得 Postman 太重、Raycast/Insomnia 有些功能用不到，又想要一个启动快、体积小、原生感强的桌面 API 客户端，可以试试 Zaku。官网（如果有的话）一般会指向：https://zaku.app （但主要信息还是在 GitHub README 里）。想体验的话直接去 release 页面下对应系统的包最快：\ https://github.com/buildzaku/zaku/releases/latest
