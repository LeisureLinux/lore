别再叫它“世界上最好的语言”了，它是真的变强了

未知日期 开源/工具 阅读原文（微信）↗

WhyPHP.dev是一个由 Laravel 核心团队成员 Nuno Maduro 创建的宣传网站，旨在向开发者展示2026 年的现代 PHP（Modern PHP）究竟有多强大。

这个网站的核心观点是：PHP 已经今非昔比，现在的它不仅极其好用，而且非常现代。

以下是该网站内容的主要总结：

1. 核心主张：PHP 已经脱胎换骨

网站指出，现代 PHP 已经不再是人们印象中那个过时的脚本语言，它现在具备了许多现代编程语言的顶级特性：

  • 性能强劲：引入了 JIT（即时编译）。

  • 语言特性：支持只读属性（readonly）、枚举（Enums）、注解（Attributes）以及能够与 TypeScript 媲美的类型系统。

  • 开发体验（DX）：最大的"超能力"是无需构建步骤。没有转译（transpilation），没有打包（bundling），直接写代码，直接部署。

2. 生态系统：工具链极其完善

网站展示了一系列顶级的开源项目和工具，认为当前的 PHP 生态非常成熟：

  • 框架：Laravel（被称为 PHP 界的 Rails/Next.js）和 Symfony。

  • 包管理：Composer。

  • 静态分析与测试：PHPStan、Pest（现代测试框架）、PHPUnit。

  • 代码规范与重构：Pint、Rector。

3. 代码示例

网站通过三个简单的代码块展示了现代 PHP 的优雅：

  • 优雅的查询：展示了 Laravel 模型链式调用和分页。

  • 富有表现力的测试：展示了 Pest 框架的函数式测试写法。

  • 类型安全：展示了泛型注释（Generics via Docblocks）和精简的箭头函数。

4. 快速入门指南

网站提供了针对 macOS、Windows 和 Linux 的一键安装命令（通过php.new服务），鼓励开发者直接尝试创建一个 Laravel 项目：

[Bash]{ngcontent-ng-c2411640571=""}

# 例如 Linux/macOS
/bin/bash -c "$(curl -fsSL https://php.new/install/linux)"
laravel new my-app

总结

该网站更像是一个现代 PHP 的"安利页"。它试图打破旧有的偏见，告诉开发者：如果你正在寻找一个类型安全、表达力强、且能快速投入生产的环境，2026 年的 PHP 和 Laravel 是极佳的选择。
