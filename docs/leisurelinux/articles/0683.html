伊朗断网时刻：那些“消失”的流量去哪了？- 前卡巴斯基高管 Costin Raiu：DNS 数据里隐藏的数字抗争

发布于 · 分类 安全/漏洞

引言：深陷数字孤岛的 9000 万人\

2026年1月，当德黑兰大巴扎的罢工蔓延成席卷全国的浪潮，一场史上最严酷的"数字宵禁"随之降临。伊朗本币里亚尔汇率崩溃、通胀高企，而与之对应的，是全境网络流量暴跌至正常水平的 1% 以下。

在这片近乎死寂的数字荒原上，前卡巴斯基顶级安全研究员 Costin Raiu 通过分析微弱的 DNS（域名系统）解析信号，为我们推开了观察这场"断网生存战"的一扇窗。

\

一、 NIN：一座精心设计的"国家局域网"

伊朗官方正在加速推进其**国家信息网（NIN）**的完全体。这不仅仅是简单的封锁，而是一次网络空间的"移魂大法"：

* 逻辑熔断：通过 BGP 协议控制网关，将国际流量精准切断，仅保留国内金融、医疗等基础设施的运行。

* 镜像替代：当用户试图寻找外界信息时，DNS 劫持会将请求导向官方受控的镜像服务。

* 流量清洗：DPI（深度包检测）实时扫描，识别并阻断任何具有加密混淆特征的非标准流量。

\

二、 裂缝中的光：那些异常的 DNS 指纹

即便在如此严密的封锁下，Costin 依然从 Cloudflare 等数据源中捕捉到了数个极具生命力的"异常高峰"。这些数据揭示了伊朗民众如何利用技术韧性穿越黑暗：

* 卫星链路与硬件博弈：

MikroTik 路由器解析量的激增，暗示了大量用户正通过开源工具（如 NASNET Connect）将网络流量导向 Starlink（星链） 等非对称卫星链路。

* 通信协议的混淆战：

TeamViewer 等远程工具的查询高峰，反映出用户正在利用"远程桌面"或特定的隧道技术，在受限的端口中寻找侧信道。

* 最后的习惯：Duolingo 的坚持：

最令人动容的细节是，语言学习应用 Duolingo 的 DNS 查询依然活跃。在极端动荡中，民众仍在尝试通过这些轻量级的、尚未被完全封杀的 UDP 心跳，维持与正常生活的微弱连接。

\

三、 结语：协议即防线，数据即真相

Costin Raiu 的这份报告没有煽情的口号，只有冷静的技术解析。它告诉我们：在现代冲突中，DNS 不仅仅是地址簿，更是网络主权与通信韧性博弈的最前线。

\

这种基于流量特征的分析，展现了网络空间中"猫鼠游戏"的最高形态。对于我们这些技术观察者而言，这不仅是一次局势分析，更是一场关于网络协议安全性与鲁棒性的深刻检讨。
