谁说 OS 只能大厂造？这个大学生靠“敲氛围感”，用 AI 徒手撸出一个 ARM64 操作系统！

未知日期 AI/Agent 阅读原文（微信）↗

导语 在 Linux 圈混久了，你是否也曾有过"自己写个操作系统"的冲动？但面对中断处理、内存管理、文件系统......往往是"从入门到放弃"。 今天，我们要安利一个最近在 GitHub 上爆火的项目：VibeOS。它不仅仅是一个操作系统，更是一场关于"AI + 底层开发"的疯狂实验。 什么是 VibeOS？ VibeOS 是由都灵理工大学学生 Kaan Şenol 开发的一个针对 Aarch64 (ARM64) 架构的操作系统。 它最硬核的地方在于：这几乎是一个完全由人类引导、AI（Claude）生成的操作系统。 作者通过 64 个极长且深入的 AI 对话 Session，硬生生从零构筑起了一套完整的 OS 体系。这不是简单的代码补全，而是真正意义上的**"氛围编程"（Vibe Coding）**。 它到底有多酷？ 如果你觉得 AI 写的 OS 只是个简单的"Hello World"，那你就大错特错了。VibeOS 的完成度高到令人发指： * 复古 GUI 界面： 瞬间把你带回 90 年代 macOS 的视觉风格。它有完善的窗口管理系统、Dock 栏、甚至还有精致的点阵字体。 * 麻雀虽小，五脏俱全： * 内核层： 支持协作式多任务、FAT32 文件系统、动态内存分配。 * 网络栈： 拥有完整的 TCP/IP 协议栈，能跑 HTTP/HTTPS。 * 多媒体： 内置音乐播放器，甚至能流畅运行 DOOM。 * 不仅是 OS，更是开发平台： * 它集成了 TCC (Tiny C Compiler)。 * 内置了 MicroPython 解释器。 * 这意味着，你可以在这个"AI 生成的 OS"里，继续编写运行你的 C 或 Python 代码。 既然有 Linux，为什么我们还要关注它？ 作为 Linux 的死忠粉，我们深知内核的复杂。VibeOS 给了我们三个全新的视角： * ARM 开发的新教材： 它完美适配 树莓派 Zero 2W。如果你想学习 ARM64 裸机开发，VibeOS 简洁的代码比庞大的 Linux 内核更适合作为"活教材"。 * AI 协作的极限： 项目仓库里记录了详细的 CLAUDE.md 对话日志。它向我们展示了：当开发者掌握了正确的架构思维，AI 能爆发出多么惊人的工程效率。 * 极客的情怀： 看着这种像素风的窗口在树莓派上跳动，这种纯粹的、"没啥大用但巨酷"的极客精神，不正是我们折腾 Linux 的初心吗？

怎么玩？ * 真机： 准备一块 Raspberry Pi Zero 2W。 * 模拟器： 直接在你的 Linux 机器上通过 QEMU 启动，感受那股清新的"Vibe"。
