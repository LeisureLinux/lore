李逵变李鬼！那个号称 Claude 亲兄弟的插件，其实是来偷家的

发布于 · 分类 AI/Agent

各位LeisureLinux的老铁，大家好。

最近 AI 编程火得不行，大家在 VS Code 里装插件的热情简直比我更新 Debian 内核还高。但就在前两天，网络安全圈的大佬John Hammond爆出了一个让人后背发凉的瓜：

\

有人在 VS Code 市场里演了一出"真假李逵"。

🔍 案情回顾：谁是"李鬼"？

黑客利用大家对 Claude AI 的信任，发布了一个名为"Clawdbot Agent"的插件。

  • 外表：偷了 Claude 的 Logo，写了天花乱坠的 README，看起来就像官方正品。

  • 内在：它根本不会写代码，它是一个地地道道的RAT（远程访问木马）。

一旦你点击"安装"，它就会利用 VS Code 这种 Electron 应用的特性，在你的 Linux 或 Windows 系统后台偷偷运行恶意 Node.js 代码。

🛠️ 它是怎么"偷家"的？

根据 John Hammond 的逆向分析，这个"李鬼"的手段相当老练：

  1. 侧向加载（Side-loading）：它会下载一个用 Rust 写的恶意 DLL 或共享库，这种方式能绕过很多基础杀毒软件。

  2. 定点清除：它的目标极其明确------翻你的浏览器记录，偷你的SSH Key，甚至扫描你的加密货币钱包。

  3. 远程控制：它还会尝试安装远程管理工具，让黑客能像操作自己电脑一样，远程翻看你操作系统里的文件。

\

最逗的是，博主发现这届黑客也有点"草台班子"，代码里 Bug 不少，属于典型的"氛围感编程"（Vibe Coding）。但即便如此，只要你点了一下安装，你的系统防线就从内部崩塌了。

\

💡 LeisureLinux 避雷指南

作为开发者，咱们得养成几个习惯：

  • 看蓝标：没认证（Verified Publisher）的 AI 插件，一律按"李鬼"处理。

  • 查官宣：这种大模型工具，如果官网上没写有扩展，市场里搜出来的 99% 都是假货。

  • 物理隔离：涉及敏感密钥的操作，尽量在独立的隔离环境或容器中运行。

\

🎁 彩蛋：博主的折腾近况

写这篇文章的时候，我正给我的Debian 13 Stable做一次"大手术"。

为了压榨 Intel 集显的性能，我手动更新了GRUB配置，把内核参数切到了全新的xe 驱动（取代了老旧的 i915）。

  • i915：就像老当益壮的绿林好汉，稳，但老了。

  • xe：则是 Intel 专门为新架构（Tiger Lake 及以后）打造的新兵，代码更现代，性能上限更高。

顺便，我还装了systemd-coredump，专门用来抓那些不听话的进程崩溃现场。作为一个 Linux Blogger，折腾系统是乐趣，但防范"李鬼"是底线。

\
