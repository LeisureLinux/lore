📰 Phoronix 焦点

  1. Ubuntu 发布 CIX P1 AI CPU 概念 ISO 继高通骁龙 X Elite 之后，Canonical 又为 CIX P1 AI 处理器提供了\"Ubuntu Concept\"专用 ISO。国产 AI 芯片的 Linux 支持在加速。

  3. Claude Code 帮了大忙：Adobe Lightroom CC 终于能在 Linux 上跑了 一位开源开发者靠着 Claude Code 的帮助，成功让 Adobe Lightroom CC 在 Wine 上跑起来了。（AI + Wine = 神组合）

  4. FFmpeg 支持 Apple ProRes RAW Vulkan 加速 去年 FFmpeg 引入了 ProRes 的 Vulkan shader 加速，现在更进一步——ProRes RAW 视频解码也能走了。

  5. Framework Laptop 13 Pro (Panther Lake) 麦克风驱动修复 这款搭载 Intel Panther Lake 的新笔记本即将在 6 月发货，周末内核里已合入了音频麦克风修复补丁。

  6. FluidX3D 3.7 发布：OpenCL CFD 加速飞跃 计算流体力学软件 FluidX3D 迎来 3.7 版本，基于 OpenCL 的 CPU/GPU 加速又提速了。

  7. FreeBSD 15.1 Beta 3 发布 离 6 月初的稳定版又近一步，更新了 OpenZFS，确保云镜像首次启动即为最新。
