【Github项目】 跟朋友对个旅行行程还要在微信群里刷几百条消息？这哥们一怒之下自己写了个工具

发布于 · 分类 开源/工具

开源，自托管，3 个月 8,000 星。免费替代 TripIt、Wanderlog 的那种。

你有没有经历过这种场景：拉了个七八人的旅行群，花了一周时间，刷了 600 条消息，最后连「去哪个城市」都没定下来。

A 发了个小红书截图，B 回了条 59 秒语音，C 说「都行」，D 又扔了个抖音链接。

最后你在备忘录里手动整理了四个版本，因为「三个朋友同时改」这件事在微信里是不可能完成的。

━━━ ━━━ ━━━

这位老哥也受够了

他叫 Maurice Bøe。某天在 GitHub 上丢了一个项目：TREK。

一个自托管的旅行规划工具，实时协作，交互地图，PWA 离线可用。

三个月，8,270 星。没有融资，没有 PR，全靠一个字------好用。

⚠️ 注意：这人不是两年写出来的。他 3 月 19 日 才创建仓库，6 月底就已经 8,000+ 星了。可以说是 2026 年 GitHub 上增长最快的旅行项目。

━━━ ━━━ ━━━

TREK 能做什么🧑‍🤝‍🧑 多人实时在线编辑

像腾讯文档一样，你们几个人同时打开一个旅行计划，谁加了一个景点、谁改了一家餐厅，所有人同步看到。

不需要群里接龙，不需要等某人汇总。

🗺️ 地图即行程

在地图上点一个地方，它直接变成你行程中的一个站点，路线和时间自动排出来。

不用在地图 App 和备忘录之间来回切。点哪去哪，所见即所得。

📡 没网也能看

内置 PWA 支持。出发前加载一次，到山里、地铁里、国外没信号的地方，行程单和地图照样能打开。

同行的朋友不需要装什么客户端，点个链接加到桌面就行。

🧾 账本 + 打包清单

谁垫了多少钱、买了什么东西、该谁付下一顿------内置记账。

带什么衣服、什么装备、每个人的行李箱重量------内置打包清单。

一整套，不需要另外找工具。

🔐 SSO 单点登录

如果你自己家里已经跑了 Authentik、Authelia、Keycloak 这类身份服务，TREK 可以直接对接。

跟你的 NAS、Nextcloud、Jellyfin 共用同一个账号。不需要再建一套用户。

🐳 Docker 一键部署

docker run -d -p 3000:3000 ghcr.io/mauriceboe/trek

有手就行。一台 \$5/月的 VPS 就能跑。

━━━ ━━━ ━━━

它比现成的 App 好在哪

市面上不是没有旅行规划软件：

  • TripIt --- 要同步行程得付 \$49/年
  • Wanderlog --- 协作功能要 Pro 订阅
  • Google Trips --- 直接停服了

它们有一个共同的问题：你的旅行数据在别人的服务器上。

TREK 是自托管的。数据库在你手里。今天想部署、明天想加功能、后天想对接自己的日历系统，随便改。AGPL-3.0，全开放。

━━━ ━━━ ━━━

适合谁

说实话，这东西不是给所有人准备的。

它适合自己会搭服务器、又想跟朋友好好出去玩的人。

配置不算复杂（Docker 一行搞定），但维护得自己来。作为回报，你得到的是一个：

  • 🚫 没有广告
  • 🚫 没有订阅费
  • 🚫 没有数据上云
  • ✅ 完全掌控

的旅行工具。

周末没事，跟搭档往沙发上一躺，一台电脑接个大屏，半小时把下个月的川西环线就盘清楚了。
