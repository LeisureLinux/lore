NexPhone 的新型三系统智能手机

发布于 · 分类 Linux/运维

1. 核心亮点：三系统运行

这不是一个愚人节玩笑，这款手机最大的卖点是可以在一台设备上运行三种系统：

  • Android 16：作为原生系统（NexOS），保持纯净、无预装软件。

  • Debian Linux：以应用程序的形式运行，并支持 GPU 加速。

  • Windows 11：支持双启动（Dual-boot），需要重启后进入。

  • 桌面模式：通过 USB-C 或 HDMI 连接显示器、键盘和鼠标，可变身为桌面工作站。

\

2. 硬件配置

NexPhone 定位于"备份机"或"备用机"，而非顶级旗舰：

  • 处理器：高通 QCM6490（曾用于 Fairphone 5）。

  • 存储：12GB RAM + 256GB 存储（支持最高 512GB 扩展）。

  • 屏幕：6.58 英寸 LCD，支持 60-120Hz 刷新率。

  • 摄像头：后置 64MP 主摄 (Sony IMX787) + 13MP 超广角。

  • 耐用性：具备 IP68/IP69K 防尘防水等级，并通过军规级 MIL-STD-810H 认证。

\

3. 价格与发售

  • 售价：549 美元（约合人民币 4000 元左右）。

  • 预订：目前可以支付 199 美元定金进行预订。

  • 发货时间：预计于2026 年第三季度（7-9月）全球发货。

\

4. 背景意义

NexPhone 的概念早在 14 年前（2012年）就已提出，旨在实现"手机即电脑"的愿景。创始人 Emre Kosmaz 表示，这是他 14 年来一直梦寐以求的设备，希望将其打造为未来的行业标准。
