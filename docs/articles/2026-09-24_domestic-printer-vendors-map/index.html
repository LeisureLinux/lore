推广
国产打印机这两年从「能用」被逼到「好用」：政策端把信创采购从党政推向金融、能源、医疗，产品端也终于有人把 A3、把彩色、把中高速补了起来。

但市面上谈国产打印，多半只提「奔图」一个名字。实际上，从整机厂到主控芯片，这条链条已经长得相当完整：整机厂至少二十余家，主控芯片走出了龙芯、极海、众诺三条路线，另有一家整机厂（沧田）自己造主控。这篇把公开可查的厂商地图系统梳理一遍——谁在造整机、卖什么牌子、官网在哪，谁是龙芯外供、谁是自研，A3 与彩色到底集中在哪几家。

二、主控芯片：三条国产路线

打印机的主控 SoC 是整机里技术壁垒最高的零部件——它要做打印数据接收解析、引擎控制、扫描时序、图像处理、马达控制，等于整机的大脑。过去这块被国外厂商主导，现在公开可见的国产路线有三条，另加一家自研：

路线一：龙芯（LoongArch 自主指令集，外供）

龙芯中科是唯一把打印主控做成独立产品线并对外开放的 CPU 厂商。已公开两颗：

  • 龙芯 2P0500：2023-11-28 发布，国内首款基于自主指令系统的打印机主控。异构大小核（LA364 + LA132），主核 750MHz / 小核 400MHz，512KB 共享二级缓存，DDR3-800，USB 2.0×3 + GMAC×2，集成打印/扫描接口与图像单元，功耗 <1.8W。官方数据手册明确写「支持 A4 常用打印纸张幅面的图像处理」——定位就是 A4。
  • 龙芯 2P0300：2025 年新发，LA264 + LA132，256KB L2，DDR3/4，主频 1.2GHz，成本更优，官方定位「适合小型激光打印机」。
2023-11-28 大会上，12 家打印机厂商与龙芯签约共建生态：长城信息、中船汉光、上海汉图、西安电子科技大学、恒科科技、宁波华高、云南南天、北京辰光融信（立思辰）、北京高德品创、天津光电通信、浙江沧田、大连中盈。

路线二：极海微（RISC-V，奔图自用）

奔图的打印机主控来自关联方极海微电子（纳思达体系）。据民生证券研报披露，极海微有 HSP2210 / HSP2220 两颗打印主控 SoC，搭载平头哥玄铁 CPU 核，属于 RISC-V 路线，且仅供奔图体系使用、不外供。这是奔图「全系主控自研（覆盖 A4 到 A3、黑白到彩色）」的底座。

路线三：众诺北辰（RISC-V，2026 新入局）

2026-03-14，广州众诺微电子发布 北辰 BCV200 打印机主控 SoC：RISC-V 架构，大小核异构，主频 800MHz，内置独立安全子系统，集成 SCANIF / PRINTIF / ISP 硬件加速单元，主打「KIT-in-Delivery」一站式交付。发布会到场站台的整机厂包括：汉印、中船汉光、立思辰、沧田、光电通、汉图、恒科、中矗、紫光、中盈、爱胜品、影源、渺宏、小篆。

另有一家自研：沧田「田芯」

浙江沧田（嘉善）官网明确：2021 年推出自主研发的打印机主控芯片「沧田·田芯」。所以沧田是左手自研主控、右手签约龙芯生态的双重身份。

一个关键推论：既然众诺北辰的签约名单覆盖了汉光、立思辰、沧田、光电通、汉图、恒科、中矗、紫光、中盈等一大批厂，那么「某厂 = 龙芯主控」这个等式根本不成立——同一个整机厂可能同时挂龙芯和众诺两条线，具体机型用哪颗，要看该机型自己的说明。

三、A3 与彩色：资源集中在少数几家

把「A3 幅面」和「彩色」交叉起来看，公开可确认同时具备两者的厂商只有四家：

  • 奔图：A3 黑白（BM230ADN、BM320、M9005/9006DN）+ A3 彩色（CM230/250/270/310/410/420ADN、CM9705DN、CP9500DN），走自研极海主控，是产品线最全的一家；
  • 汉光联创（中船汉光）：A3 彩色复合机 HGFC5226i/5229/5366S/7756S、A3 黑白复合机 HGF6216/6266/6366/6286/6456S、A3 彩机 HGLP-C836；
  • 立思辰（辰光融信）：A3 黑白 GA5500DN（40ppm）、GM 系列 A3，彩色 GA9540cdn / GA3530cdn / GA7530cdn；
  • 中矗：ZC-CX7545/7555/7535 A3 彩色多功能一体机、ZC-CS7555 A3 彩色单功能。
而龙芯主控的公开机型清一色是 A4（紫光汉图十款、得力睿印、南天 BL353x/403x、汉图极印 35ppm）——这与 2P0500 官方「支持 A4 幅面」的定位一致。汉光、立思辰、光电通这些厂商的 A3 机型，主控属于「未公开」，不能默认是龙芯。

彩色方面另有一条：得力墨辰系列彩色激光与彩色喷墨（含国内首款龙芯主控彩色喷墨打印机），以及映美走喷墨路线的彩色——但它们都不是「A3 彩色激光复合机」。

四、认证与金融信创

2025-07-01 起，中国信息安全测评中心《安全可靠测评工作指南（V3.0）》把「激光或喷墨打印机搭载的主控芯片」列入测评品类（目前仅五个领域：CPU、AI 训练推理芯片、操作系统、数据库、打印机主控芯片）。龙芯 2P0500 与 2P0300 均为 II 级（当前最高级），极海 KP3701、SN2701 为 I 级。

金融信创可确认的碎片不多：

  • 中信银行：近 4000 台龙芯 2P0500 打印机，由云南南天提供（信创 A4 黑白激光 + 打印扫描一体机）；
  • 工商银行：得力公开表示已中标央采、省采、工商银行等大型采购（具体机型/数量未披露）；
  • 其余国有大行的打印机专项中标，几乎全在集采内网，公开渠道查不到确定性结论。

五、怎么读这张地图：三个结论

1. 主控已「三足」，且 RISC-V 正成为第二条主线。 龙芯走 LoongArch 并对外开放授权，极海走 RISC-V 玄铁但自用，众诺北辰 2026 年以 RISC-V 新入局。国产打印主控不再只有一条路。

2. A4 是龙芯系当前的天花板，A3 能力集中在非龙芯或主控未公开的厂商。 奔图（极海）明确打通 A4→A3 全幅面；汉光、立思辰、中矗的 A3 机型存在，但主控未公开。「龙芯 + A3」目前没有任何公开实锤。

3. 整机厂的芯片「签名」是复数。 中船汉光、立思辰、沧田、光电通、汉图、恒科、中矗、紫光、中盈——同时出现在龙芯和众诺北辰两条签约线上。评估一台国产打印机的自主可控程度，不能看厂商名字，要看具体机型的芯片型号 + 安全可靠测评等级。

一句话收尾：国产打印机已经不是「有没有」的问题，而是「谁在哪一层自主」的问题——主控有龙芯/极海/众诺三条国产路线，整机有二十余家厂商，A3 与彩色集中在少数几家。真正要挑刺的，是那些主控型号至今不公开的 A3 机型：在信创场景里，「说不清用谁的大脑」本身就是风险。
