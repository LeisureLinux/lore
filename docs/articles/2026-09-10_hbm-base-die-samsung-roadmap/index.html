HBM 的第二幕：当内存开始思考——三星 base die 三步走

译文半导体HBM三星先进封装
本文译自 SemiWiki 文章《HBM's Second Act: When Memory Starts Thinking》，2026 年 9 月 8 日发布。原文引述三星内存业务部门 Sangwook Han 在 Hot Chips 2026 的演讲《HBM Base Die: How HBM Will Evolve Using Advanced Logic Processes》（2026 年 8 月 23 日）。原文链接：https://semiwiki.com/events/372843-372843/
推广
三星在 Hot Chips 2026 上的演讲提出了一个判断：HBM 堆栈下方那颗 base die，即将远不止是一层通信层。传统上，HBM base die 主要负责把堆叠的 DRAM 裸片连到 GPU、TPU 或其他处理器，并提供测试功能。三星设想把它变成一个可定制的主动逻辑平台——先吸收来自处理器的功能，再加入新能力，最终实现内存与计算之间的直接三维集成。

驱动力：带宽、功耗与物理极限

这场转变由三重约束推动。AI 处理器需要越来越快地访问越来越大的内存，但传统缩放路径正在撞上多堵墙：

  • 晶体管改进在放缓
  • 处理器逼近最大光罩尺寸（reticle size）
  • 中介层（interposer）无法无限扩张
在 HBM 内部，硅通孔（TSV）的数量与间距限制了带宽；更宽更快的物理接口则要吃掉更多面积与功耗。尽管每个传输比特的能效在提升，但总接口功耗随着总带宽增长而持续上升。

HBM4：转折点与 cHBM

三星的关键转变始于 HBM4——它的 base die 改用先进的 4 纳米逻辑工艺，而非传统 DRAM 工艺。更好的逻辑晶体管降低了功耗、延迟与有源面积，也缩小了 base die 与处理器之间的技术代差。

这催生了定制 HBM（custom HBM，cHBM）：产品可以共用标准化的 DRAM 堆栈，同时针对特定处理器或工作负载定制 base die 的逻辑。

三阶段路线图

阶段名称核心动作目标
第一阶段回收处理器面积紧凑 die-to-die 接口替代传统大 HBM 物理接口；内存控制器从处理器迁入 base die；SRAM 修复逻辑替换缺陷 DRAM 行；引入散热通道块缩短信号路径、提升能效、改善良率与可用容量
第二阶段榨取路由用硅集成温度/电压/工艺/老化传感器；片上测试与图形生成；专用控制器与接口直连外部内存；处理单元迁入 base die实时 RAS 监控、更好故障覆盖、超越 PCIe 的扩展带宽与延迟
第三阶段zHBM 真三维处理器逻辑垂直置于 DRAM 堆栈之下；分布式连接；消除传统高功耗串行接口预估 HBM I/O 功耗降低约 70%

第一阶段回收宝贵的处理器面积。紧凑的 die-to-die 接口取代传统庞大的 HBM 物理接口，缩短信号路径、提升能效；内存控制器可以从处理器迁入 HBM base die。三星还提出基于 SRAM 的修复逻辑，可替换有缺陷的 DRAM 行，潜在提升可用容量与制造良率。不过接口缩小会推高功率密度，因此引入散热通道块（heat-path blocks）把热量导过堆栈，降低峰值温度。

第二阶段榨取那些原本主要用于布线的硅。base die 可集成温度、电压、工艺与老化传感器，用于实时的可靠性、可用性与可服务性（RAS）监控；片上测试与图形生成可提升故障覆盖与良率；专用控制器与接口可让 HBM 直连外部内存，相比基于 PCIe 的扩展方案提供更大容量与更好的带宽、延迟。处理单元也可迁入 base die，减少跨中介层的数据搬运。三星把这种计算增强形态称为高级 HBM（advanced HBM，aHBM）。

第三阶段提出 zHBM——一种真正的三维架构，处理器逻辑垂直置于 DRAM 堆栈之下。分布式连接缩短内部数据路径，并消除传统高功耗串行接口。三星估算，消除这部分开销可让 HBM I/O 功耗降低约 70%。实现 zHBM 需要晶圆对晶圆（wafer-on-wafer）组装、混合铜键合（hybrid copper bonding），以及一套横跨处理器逻辑、DRAM、封装、时序、功耗、信号完整性与测试的统一设计与验证流程。

为什么重要

现代 AI 性能越来越不只取决于算力，还取决于高效地搬运与存储数据。更长的上下文窗口、更大的 KV cache、内存密集型推理，让带宽、容量与能耗成为系统的核心约束。如果三星的路线图成功，HBM 将不再是处理器设计完成后才被选用的一个相对被动的组件，而会成为计算架构本身的一部分。

---

我们的解读：base die 是下一场战争的主战场

1. 这一步的逻辑非常清晰：把「被动互连」变成「主动逻辑」。 base die 长期被视为 HBM 的「底座 + 测试口」，价值密度极低。三星的洞察是——它恰恰是整个堆栈里唯一一块可以用先进逻辑工艺制造、又物理上紧贴内存的硅。一旦 base die 用上 4nm，它就不再是 DRAM 工艺的附属品，而是一块「长在内存脚下的逻辑芯片」。这是从「内存厂商」向「逻辑平台厂商」跨界的关键一步。

2. 三个阶段其实是三种不同的商业叙事，风险逐级递增。

  • 第一阶段（回收面积）：最务实、最快见效——本质是「把 PHY 和内存控制器从 GPU 搬到 base die」，卖点是给客户省面积。这一阶段对现有生态改动最小，落地概率最高。
  • 第二阶段（aHBM）：开始动真格。把传感器、测试、甚至处理单元塞进 base die，意味着内存厂商要具备逻辑设计与验证能力，并与处理器厂商深度协同。这一步是「定制 HBM」真正兑现价值的地方。
  • 第三阶段（zHBM）：彻底重构封装范式。垂直堆叠处理器逻辑 + 混合铜键合，几乎是「把 HBM 变成 3D 计算芯片」。70% 的 I/O 功耗降幅很诱人，但 wafer-on-wafer + 混合键合的良率与热管理难度是数量级的跨越。这一阶段更像是战略宣言，而非近期路线图。
3. 「70% I/O 功耗」这个数字值得单独记一笔。 在 AI 数据中心里，数据搬运的能耗早已超过计算本身，而 HBM 接口的串行 PHY 是能耗大户。zHBM 通过分布式连接取消串行接口，理论上直击痛点。但要拿到这 70%，前提是整个堆栈的时序、功耗、信号完整性、测试都能统一设计与验证——这恰恰是当前 EDA 工具链与产业分工最难覆盖的部分。

4. 产业关系的重构才是真正的「战略战场」。 原文 bottom line 说得直白：内存厂商、处理器设计方、代工厂、封装专家必须更早地共同设计产品。过去 HBM 是「处理器设计定了再挑内存」，未来变成「内存和处理器一起设计」。对国内产业而言，这意味着两件事：一是先进封装（混合键合、wafer-on-wafer）与 base die 逻辑工艺会成为新的卡点；二是设计与验证工具链的自主可控变得比以往更紧迫——因为统一设计流程本身就是竞争力。

5. 一句话总结： HBM 的「第二幕」不是把内存做得更快，而是让内存开始参与计算。base die 从通信层升级为逻辑层，谁掌握了它的逻辑、接口与集成，谁就可能影响下一代 AI 系统的构建方式——以及它扩展的效率。
